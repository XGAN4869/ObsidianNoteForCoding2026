# 头像 URL 转化笔记
## 1. 问题背景后端返回的头像字段有时不是完整图片地址，而是 COS 文件 
Key：travel/employee/photo/1780909577121_7560.jpeg

这种路径不能直接显示，需要前端拼接成完整 URL：

```
https://ims-saas-dev-1310497727.cos.ap-guangzhou.myqcloud.com/travel/employee/photo/1780909577121_7560.jpeg
```

---

## 2. 核心代码

```js
// 默认 COS 配置
const DEFAULT_COS_BUCKET = 'ims-saas-dev-1310497727'
const DEFAULT_COS_REGION = 'ap-guangzhou'

// 头像最终地址
const accountAvatar = computed(() => {
  return normalizeProfileAvatarUrl(accountStore.accountInfo?.avatar, accountStore)
})

// 转化头像地址
function normalizeProfileAvatarUrl(value, accountStore) {
  if (!value) {
    return ''
  }

  let avatar = String(value).trim()

  // 如果已经是完整地址，直接返回
  if (/^(https?:\/\/|data:|blob:)/.test(avatar)) {
    return avatar
  }

  // 去掉开头的 /
  avatar = avatar.replace(/^\/+/, '')

  const bucket = accountStore?.bucketName || DEFAULT_COS_BUCKET
  const region = accountStore?.cosRegion || DEFAULT_COS_REGION

  return `https://${bucket}.cos.${region}.myqcloud.com/${avatar}`
}
```

---

## 3. 逻辑说明

这个函数主要处理三种情况：

```
空值        → 返回 ''
完整 URL    → 原样返回
文件 Key    → 拼接 COS 域名
```

例如：

```js
normalizeProfileAvatarUrl('', accountStore)
// 返回：''

normalizeProfileAvatarUrl('https://xxx.com/avatar.png', accountStore)
// 返回：'https://xxx.com/avatar.png'

normalizeProfileAvatarUrl('travel/employee/photo/a.jpeg', accountStore)
// 返回：'https://ims-saas-dev-1310497727.cos.ap-guangzhou.myqcloud.com/travel/employee/photo/a.jpeg'
```

---

## 4. computed 的作用

```js
const accountAvatar = computed(() => {
  return normalizeProfileAvatarUrl(accountStore.accountInfo?.avatar, accountStore)
})
```

作用是根据 `accountStore.accountInfo.avatar` 自动计算最终头像地址。

模板里可以直接用：

```
<t-avatar :image="accountAvatar" />
```

或者：

```
<img :src="accountAvatar" />
```

---

## 5. 重点记忆

以后遇到图片回显，可以按这个思路处理：

```
后端返回完整 URL → 直接显示后端返回文件 Key → 前端拼接域名后端返回空值 → 返回空字符串
```

一句话：

> 头像回显的本质，就是把后端返回的图片标识，转换成前端能访问的完整图片地址。
