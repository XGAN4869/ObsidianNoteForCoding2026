| 场景                  | 列数             | 表现                     |
| ------------------- | -------------- | ---------------------- |
| 屏宽缩小（如 768~992）     | 展开3→2列，收起仍2列   | 列数自动减少，项自然下移           |
| 屏宽 < 768            | 全部 1 列         | 所有条件竖排                 |
| 总数 ≤ 3              | 大屏3列，中屏2列，小屏1列 | 无展开按钮，全部显示             |
| 总数 > 3，收起，屏宽 ≥ 1200 | 2 列            | 默认插槽显示（如2个占一行），show 隐藏 |
| 总数 > 3，展开，屏宽 ≥ 1200 | 3 列            | 所有项显示，多出的自动换到下一行       |
