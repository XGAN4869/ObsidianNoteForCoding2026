- 进程是 每个正在运行的程序
	一个进程通常拥有自己独立的：
	内存空间
	文件资源
	网络资源
	环境变量
	进程编号 PID

线程是 进程内部的一条执行路线
	线程共享所在进程的内存和资源
	多线程执行效率更高，所以线程有多条
- CPU 负责一条一条执行线程里的指令。
	并发：一个 CPU 核心快速切换多个任务，看起来像同时执行
	并行：多个 CPU 核心真正同时执行多个任务
- 程序是“放在 硬盘 = 磁盘 上的文件

| 计算机概念  | 做菜比喻            |
| ------ | --------------- |
| 程序     | 硬盘里的菜谱          |
| 进程     | 按这份菜谱开始做的一次做菜活动 |
| PID    | 这次做菜活动的编号       |
| 线程     | 真正动手干活的人        |
| CPU    | 干活的人使用的灶台       |
| 内存     | 厨房里的工作空间        |
| 操作系统内核 | 厨房管理员           |
- JS 运行时【NodeJs为例】：从 JS 被加载开始，到 V8 管理它的解析、解释、编译、内存和运行环境的整个软件系统。**V8、Node.js、浏览器 JavaScript 引擎、事件循环、堆、垃圾回收等组成的运行环境**
- 运行态：某个进程或线程当前正在被操作系统调度，使用 CPU 执行指令
👆关系：JS运行时中的某个线程处于运行态，CPU正在执行V8的机器码
