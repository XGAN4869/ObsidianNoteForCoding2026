# 个人博客项目：数据库设计与迁移

## 1. 表关系

~~~text
users 1 ─── N posts
users 1 ─── N comments
posts N ─── N tags（通过 post_tags）
categories 1 ─── N posts
posts 1 ─── N comments
users 1 ─── N refresh_tokens
~~~

## 2. users

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK | 用户 ID |
| username | VARCHAR(32) | UNIQUE NOT NULL | 登录名 |
| email | VARCHAR(255) | UNIQUE NOT NULL | 邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 |
| role | VARCHAR(16) | NOT NULL | user/admin |
| status | VARCHAR(16) | NOT NULL | active/disabled |
| avatar_url | VARCHAR(500) | NULL | 头像 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

## 3. posts

字段包括 id、author_id、category_id、title、slug、summary、content、status、view_count、published_at、created_at、updated_at 和 deleted_at。

status：draft、published、archived。slug 对已发布文章唯一。

## 4. categories、tags、post_tags

categories 保存 name、slug、description；tags 保存 name、slug；post_tags 使用 post_id + tag_id 联合主键，防止同一标签重复关联。

## 5. comments

字段包括 id、post_id、user_id、parent_id、content、status、created_at、updated_at、deleted_at。parent_id 为 NULL 表示顶级评论。查询树时先分页查平铺列表，再在 Service 中组装树。

## 6. refresh_tokens

保存 token_id、user_id、token_hash、expires_at、revoked_at、created_at。数据库不保存完整 Refresh Token，只保存哈希或不可逆标识。

## 7. users 迁移示例

~~~sql
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(32) NOT NULL UNIQUE,
  email VARCHAR(255) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  role VARCHAR(16) NOT NULL DEFAULT 'user',
  status VARCHAR(16) NOT NULL DEFAULT 'active',
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_users_status ON users(status);
~~~

PostgreSQL 需要把 AUTO_INCREMENT 改为 BIGSERIAL 或 GENERATED AS IDENTITY。

## 8. posts 迁移重点

~~~sql
CREATE TABLE posts (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  author_id BIGINT NOT NULL,
  category_id BIGINT NULL,
  title VARCHAR(200) NOT NULL,
  slug VARCHAR(220) NOT NULL,
  summary VARCHAR(500) NOT NULL DEFAULT '',
  content LONGTEXT NOT NULL,
  status VARCHAR(16) NOT NULL DEFAULT 'draft',
  view_count BIGINT NOT NULL DEFAULT 0,
  published_at TIMESTAMP NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  deleted_at TIMESTAMP NULL,
  FOREIGN KEY (author_id) REFERENCES users(id)
);

CREATE INDEX idx_posts_status_created ON posts(status, created_at, id);
CREATE INDEX idx_posts_author ON posts(author_id, created_at);
~~~

## 9. 事务边界

- 创建文章和标签关联：文章插入、关联表插入在一个事务内。
- 发布文章和审计记录：状态更新、发布时间、审计记录在一个事务内。
- 删除分类：先检查引用，再决定迁移文章或拒绝删除。
- 审核评论：状态更新和审核日志在一个事务内。

## 10. 种子数据

测试种子应包含一个管理员、一个普通用户、一个草稿、两个已发布文章、两个分类、三个标签以及不同状态的评论。密码必须由程序生成哈希。

## 11. 迁移命令

~~~powershell
migrate -path migrations -database "$env:DATABASE_URL" up
migrate -path migrations -database "$env:DATABASE_URL" version
migrate -path migrations -database "$env:DATABASE_URL" down 1
~~~

生产环境执行 down 前必须备份并经过审批。
