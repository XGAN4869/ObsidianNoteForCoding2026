# 变量、常量与基本类型

## 1. 学习目标

完成本章后，你能够：

- 根据数据含义选择合适的 Go 类型。
- 区分 var 声明、短变量声明和常量声明。
- 理解零值、类型转换和类型推断。
- 区分 byte、rune 和字符串长度。
- 为博客项目中的用户、文章和分页字段选择基础类型。

## 2. Go 的类型观

Go 是静态类型语言：变量的类型在编译时确定，编译器会尽早发现“把字符串当数字使用”一类错误。

类型选择时优先考虑三个问题：

1. 这个值表达的业务含义是什么？
2. 是否允许没有值，还是必须有零值？
3. 是否需要和数据库、JSON 或外部 API 保持特定格式？

博客项目中常见的选择：

| 场景 | 推荐类型 | 原因 |
| --- | --- | --- |
| 用户 ID | int64 或 uint64 | 数据库主键通常是 64 位整数 |
| 用户名 | string | 文本数据 |
| 是否管理员 | bool | 两种状态 |
| 文章浏览量 | int64 | 计数可能增长较大 |
| 创建时间 | time.Time | 需要时区和时间运算 |
| 可选简介 | string + 约定空字符串，或指针 | 需要区分“未填写”和“空文本”时使用指针 |
| 金额 | int64 表示最小货币单位 | 避免浮点误差 |

## 3. 变量声明

### 使用 var

~~~go
var name string
var age int = 18
var enabled = true
~~~

没有显式赋值时，变量会获得该类型的零值：

| 类型 | 零值 |
| --- | --- |
| 数字类型 | 0 |
| bool | false |
| string | 空字符串 |
| 指针、切片、Map、接口、函数 | nil |

### 短变量声明

函数内部最常用：

~~~go
func main() {
	name := "小明"
	age := 20
	fmt.Println(name, age)
}
~~~

短变量声明只能在函数内部使用，并且左侧至少要有一个新变量：

~~~go
a, b := 1, 2
a, b = b, a
~~~

### 变量遮蔽

下面的 code 在 if 内创建了一个新的 name，而不是修改外层变量：

~~~go
name := "outer"
if true {
	name := "inner"
	fmt.Println(name) // inner
}
fmt.Println(name) // outer
~~~

想修改外层变量，使用赋值而不是再次声明：

~~~go
name := "outer"
if true {
	name = "inner"
}
~~~

## 4. 常量与 iota

常量在编译时确定，不能在运行时重新赋值：

~~~go
const AppName = "go-blog"
const MaxPageSize = 100
~~~

使用 iota 定义连续的枚举值：

~~~go
const (
	StatusDraft = iota
	StatusPublished
	StatusArchived
)
~~~

iota 从 0 开始，每新增一行自动加 1。对外暴露的状态值最好配合字符串转换函数，避免直接向用户返回数字：

~~~go
func statusName(status int) string {
	switch status {
	case StatusDraft:
		return "draft"
	case StatusPublished:
		return "published"
	case StatusArchived:
		return "archived"
	default:
		return "unknown"
	}
}
~~~

## 5. 整数与浮点数

常见整数类型：

- int：适合循环下标和本机计算。
- int8、int16、int32、int64：需要明确位数时使用。
- uint：无符号整数，只有确定不需要负数时再使用。

常见浮点类型：

- float32：占用空间小，精度较低。
- float64：默认的浮点类型，适合科学计算。

不要用 float64 直接保存金额：

~~~go
// 可能出现 0.1 + 0.2 != 0.3 的精度问题
total := 0.1 + 0.2
fmt.Println(total)
~~~

如果项目有金额，使用“分”为单位的 int64，例如 1299 表示 12.99 元。

## 6. 布尔值与字符串

~~~go
isAdmin := false
title := "Go 入门"
empty := ""
~~~

字符串是不可变的字节序列。len 统计的是字节数，不一定是汉字个数：

~~~go
text := "Go语言"
fmt.Println(len(text)) // 8，UTF-8 字节数
fmt.Println(len([]rune(text))) // 4，字符数量
~~~

## 7. byte、rune 与字符

byte 是 uint8 的别名，适合处理 ASCII 字节或二进制数据。

rune 是 int32 的别名，适合表示 Unicode 码点：

~~~go
var first rune = '中'
var letter byte = 'A'
fmt.Println(first, letter)
~~~

遍历字符串时，如果关心字符而不是原始字节，使用 range：

~~~go
for index, r := range "博客" {
	fmt.Println(index, r)
}
~~~

index 是字节位置，r 是 rune。中文字符通常占 3 个 UTF-8 字节，因此 index 不一定连续加 1。

## 8. 类型转换与类型别名

Go 不会自动把 int 转成 int64：

~~~go
var page int = 2
var offset int64 = int64(page)
~~~

转换前要确认是否会溢出：

~~~go
var count int64 = 300
small := int8(count) // 超出 int8 范围时会丢失信息
fmt.Println(small)
~~~

类型别名与新类型不同：

~~~go
type UserID int64       // 创建新类型，需要显式转换
type StringList = []string // 别名，仍然是 []string
~~~

为业务 ID 创建新类型可以减少把文章 ID 和用户 ID 混用的风险。

## 9. 类型推断与格式化输出

编译器会根据右侧值推断类型：

~~~go
n := 10       // int
rate := 0.8   // float64
ok := true     // bool
~~~

格式化输出常用 fmt：

~~~go
fmt.Printf("name=%s age=%d active=%t\n", "小明", 18, true)
fmt.Printf("%v %#v %T\n", value, value, value)
~~~

%T 可以查看变量的实际类型，排查类型推断问题时很有用。

## 10. 博客项目中的基础类型设计

~~~go
type User struct {
	ID        int64
	Username  string
	IsAdmin   bool
	CreatedAt time.Time
}

type PostSummary struct {
	ID          int64
	Title       string
	Slug        string
	ViewCount   int64
	PublishedAt *time.Time
}
~~~

PublishedAt 使用指针，是因为草稿可能还没有发布时间。指针为 nil 表示“从未发布”，而不是一个假的时间。

## 11. 常见错误

### 在函数外使用短变量声明

~~~go
// 错误：函数外不能使用 :=
name := "blog"
~~~

包级变量应使用 var 或 const。

### 变量声明后未使用

Go 会拒绝编译未使用的局部变量：

~~~go
func main() {
	name := "小明"
	// 如果没有读取 name，编译失败
	fmt.Println(name)
}
~~~

### 把字符常量当字符串

单引号表示 rune，双引号表示 string：

~~~go
letter := 'A'
word := "A"
~~~

### 用 len 判断中文字符数量

len 对字符串统计字节数。需要字符数量时，转换为 []rune 或使用 utf8.RuneCountInString。

## 13. 小结

- 变量有明确类型，零值是 Go 简化初始化的重要机制。
- 短变量声明只适合函数内部。
- 常量和 iota 适合表示稳定的配置与状态。
- 字符串长度和字符数量不是一回事。
- 基础类型选择应结合业务含义、数据库和 JSON 契约。
