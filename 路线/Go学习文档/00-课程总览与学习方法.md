# Go 系统学习课程总览与学习方法

> 目标：从零开始掌握 Go 语言，并能够独立设计、开发、测试和部署一个分层架构的个人博客后端。

## 1. 学完之后能做什么

完成本套课程后，你应当能够：

- 读懂常见 Go 项目，理解包、模块、接口和依赖关系。
- 使用切片、Map、结构体、方法、接口和错误处理完成业务代码。
- 使用 Goroutine、Channel、Mutex 和 Context 编写可控的并发程序。
- 使用 `net/http` 和 Gin 编写 REST API。
- 使用 `database/sql` 连接数据库，完成 CRUD、分页和事务。
- 编写单元测试、集成测试，并使用 race detector 发现数据竞争。
- 按 Handler / Service / Repository 分层设计项目。
- 完成 `go-blog` 个人博客后端：用户认证、文章、分类、标签、评论、审核和部署。

## 2. 推荐学习顺序

```text
环境工具
   ↓
变量、类型、流程控制
   ↓
函数、指针、结构体、方法
   ↓
接口、错误、包和模块
   ↓
并发、文件、JSON、HTTP
   ↓
数据库、测试和工程规范
   ↓
博客需求与架构
   ↓
认证 → 文章 → 评论 → API → 测试 → 部署
```

不要跳过基础章节直接复制博客项目代码。博客项目中的 `struct`、接口、错误、Context、SQL 和测试，都会反复使用前面的知识。

## 4. 每章的学习闭环

每学一章，按下面的顺序完成：

1. **先读概念**：弄清楚解决什么问题，不急着背语法。
2. **复制并运行示例**：观察输出，再主动修改一个变量或分支。
3. **脱离文档重写**：关掉示例，凭理解重新写一遍。
4. **完成练习题**：至少完成基础题和一道开放题。
5. **连接博客项目**：记录这个知识点最终会落到 `go-blog` 的哪个目录。
6. **写学习记录**：用三句话回答“是什么、为什么、什么时候用”。

建议每次学习 60～90 分钟，其中编码时间至少占一半。遇到报错时，先保留完整错误信息，再定位到最小可复现代码，不要直接删除报错行。

## 5. 章节验收标准

### 基础阶段（00～08）

- 能独立写一个命令行记账程序。
- 能解释切片与数组、值接收者与指针接收者的区别。
- 能为一个业务对象设计结构体、方法和接口。
- 能用自定义错误表达参数错误、资源不存在和系统错误。

### 工程阶段（09～14）

- 能写一个带超时和取消的并发任务处理器。
- 能实现一个 JSON HTTP 接口。
- 能完成带事务的数据库写入。
- 能为核心业务编写表驱动测试，并通过 `go test -race`。

### 项目阶段（15～24）

- 能说明博客项目每个目录的职责和依赖方向。
- 能完成注册、登录、文章发布和评论审核流程。
- 能使用统一响应格式和错误码。
- 能通过 Docker Compose 启动 API、数据库和 Redis。
- 能用测试验证主要成功、失败和权限场景。

## 6. 博客项目能力对应表

| Go 能力 | 博客项目中的落点 |
| --- | --- |
| 结构体与方法 | `internal/model` 中的 User、Post、Comment |
| 接口 | `internal/repository` 和 `internal/service` 的依赖抽象 |
| 错误处理 | 统一业务错误、HTTP 状态码和错误响应 |
| Context | 请求取消、数据库超时、用户身份传递 |
| Goroutine | 异步日志、缓存预热或后台任务 |
| HTTP | 路由、中间件、请求校验、响应序列化 |
| SQL | 用户、文章、标签、评论的数据持久化 |
| 测试 | Handler、Service、Repository 和端到端测试 |
| 工具链 | `go mod`、格式化、静态检查和 Docker 部署 |
