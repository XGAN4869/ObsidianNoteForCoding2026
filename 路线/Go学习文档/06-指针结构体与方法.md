# 指针、结构体与方法

## 1. 学习目标

理解地址与指针，使用结构体建模业务数据，正确选择值接收者或指针接收者。

## 2. 指针基础

~~~go
value := 10
pointer := &value
fmt.Println(*pointer)
*pointer = 20
fmt.Println(value)
~~~

& 取得地址，* 读取或修改地址中的值。Go 不支持指针算术。

nil 指针不能解引用：

~~~go
var user *User
if user == nil {
	return errors.New("用户不存在")
}
~~~

## 3. 结构体

~~~go
type User struct {
	ID        int64
	Username  string
	Email     string
	IsAdmin   bool
	CreatedAt time.Time
}
~~~

建议使用字段名初始化，避免字段顺序变化造成错误：

~~~go
user := User{
	ID:       1,
	Username: "alice",
}
~~~

## 4. 方法

~~~go
func (u User) DisplayName() string {
	if u.Username == "" {
		return "匿名用户"
	}
	return u.Username
}

func (u *User) Rename(name string) {
	u.Username = strings.TrimSpace(name)
}
~~~

值接收者得到副本；指针接收者能修改原对象，并避免复制较大结构体。

选择原则：

- 方法需要修改对象：使用指针接收者。
- 结构体较大或包含锁：使用指针接收者。
- 小型不可变值：可以使用值接收者。
- 同一类型的方法尽量保持一致。

## 5. 构造函数惯用写法

Go 没有构造函数关键字，通常使用 NewXxx：

~~~go
func NewUser(username, email string) (*User, error) {
	username = strings.TrimSpace(username)
	if username == "" {
		return nil, errors.New("用户名不能为空")
	}
	return &User{
		Username:  username,
		Email:     strings.ToLower(strings.TrimSpace(email)),
		CreatedAt: time.Now(),
	}, nil
}
~~~

构造函数负责保证对象一创建就满足基本不变量。

## 6. 组合而不是继承

~~~go
type Timestamps struct {
	CreatedAt time.Time
	UpdatedAt time.Time
}

type Post struct {
	ID int64
	Timestamps
	Title string
}
~~~

匿名嵌入会提升字段和方法，但不等同于传统面向对象继承。业务结构体应优先清晰字段，避免多层嵌入。

## 7. 指针字段的语义

~~~go
type Post struct {
	PublishedAt *time.Time
	DeletedAt   *time.Time
}
~~~

nil 可以表达“尚未发布”或“没有删除”。但指针会增加判空成本，不要为所有基础字段盲目使用指针。

## 8. JSON Tag

~~~go
type UserResponse struct {
	ID       int64  `json:"id"`
	Username string `json:"username"`
	Email    string `json:"email,omitempty"`
}
~~~

数据库模型与 HTTP 响应字段需求不同，博客项目会使用 DTO 避免直接暴露密码哈希等内部字段。

## 9. 常见错误

- 返回局部变量指针本身不是错误，Go 会进行逃逸分析。
- 不要复制包含 sync.Mutex 的结构体。
- 方法修改对象却使用值接收者。
- 为了省事直接把数据库模型作为 API 响应。
- 指针链过深，导致到处判 nil。
