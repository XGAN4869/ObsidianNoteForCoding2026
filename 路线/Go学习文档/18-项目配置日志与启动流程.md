# 个人博客项目：配置、日志与启动流程

## 1. 配置结构

~~~go
type Config struct {
	App struct {
		Env  string
		Addr string
	}
	Database struct {
		DSN             string
		MaxOpenConns    int
		MaxIdleConns    int
		ConnMaxLifetime time.Duration
	}
	Redis struct {
		Addr     string
		Password string
		DB       int
	}
	JWT struct {
		Secret        string
		AccessMinutes int
		RefreshDays   int
	}
}
~~~

配置读取函数返回 Config 和 error，不在包级变量中隐藏初始化失败。

## 2. 环境配置

.env.example 只放变量名和示例，不放真实密钥：

~~~text
APP_ENV=development
APP_ADDR=:8080
DATABASE_DSN=user:password@tcp(db:3306)/goblog?parseTime=true
REDIS_ADDR=redis:6379
JWT_SECRET=replace-with-at-least-32-random-bytes
~~~

生产通过平台 Secret 注入 JWT_SECRET、数据库密码等值。

## 3. 日志字段

每条请求日志建议包含 time、level、request_id、method、path、status、latency、user_id（如果已认证）和 error_code（失败时）。密码、Authorization Header、完整 Cookie、数据库 DSN 不得记录。

## 4. 初始化伪代码

~~~go
func run(ctx context.Context) error {
	cfg, err := config.Load()
	if err != nil { return err }
	if err := cfg.Validate(); err != nil { return err }

	logger := newLogger(cfg.App.Env)
	db, err := database.Open(ctx, cfg.Database)
	if err != nil { return err }
	defer db.Close()

	cache, err := cache.Open(ctx, cfg.Redis)
	if err != nil { return err }
	defer cache.Close()

	repos := repository.New(db)
	services := service.New(repos, cache, cfg.JWT)
	handlers := handler.New(services)
	server := router.New(handlers, logger, cfg)

	return server.Run(ctx)
}
~~~

真实实现中可把这些依赖封装到 app.App，方便测试和关闭。

## 5. Gin 初始化

- 设置 ReleaseMode 或 DebugMode。
- 注册 Recovery、RequestID、Logger、CORS。
- 注册公开路由：health、文章列表、文章详情、登录注册。
- 注册认证路由：用户资料、评论、作者文章。
- 注册管理员路由：审核、用户和分类标签管理。
- 限制请求体大小。
- 统一 404 和错误响应。

## 6. 健康检查

GET /healthz 只表示进程存活；GET /readyz 检查数据库和 Redis 是否可用。负载均衡器应根据 readyz 决定是否转发流量。

## 7. 优雅关闭顺序

1. 停止接收新请求。
2. 等待进行中的请求，最多 5～10 秒。
3. 停止后台 worker。
4. 关闭 Redis。
5. 关闭数据库连接池。
6. 刷新日志。

## 8. 启动失败处理

- 配置缺失：打印明确字段名，退出码非 0。
- 数据库 Ping 失败：记录地址摘要和底层错误，不输出密码。
- Redis 失败：按配置选择退出或降级。
- 端口占用：返回清晰错误。
- 迁移失败：禁止启动接收业务流量。
