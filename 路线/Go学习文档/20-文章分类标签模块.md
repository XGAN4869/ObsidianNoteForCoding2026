# 文章、分类与标签模块

## 1. 领域模型

~~~go
type Post struct {
	ID          int64
	AuthorID    int64
	CategoryID  *int64
	Title       string
	Slug        string
	Summary     string
	Content     string
	Status      string
	ViewCount   int64
	PublishedAt *time.Time
	CreatedAt   time.Time
	UpdatedAt   time.Time
}
~~~

状态只允许 draft、published、archived。状态转换应集中在 Service，不允许 Handler 随意写入任意字符串。

## 2. 创建草稿

流程：

1. 验证标题、正文、摘要长度。
2. 生成或校验 slug。
3. 校验 category_id 存在。
4. 校验 tags 去重。
5. 插入 posts。
6. 在事务中写入 post_tags。
7. 返回 PostResponse。

草稿创建不设置 published_at，游客不可见。

## 3. 发布文章

发布时检查：

- 调用者已登录。
- 调用者是作者或管理员。
- 标题和正文不为空。
- 分类和标签仍然有效。
- slug 没有冲突。

同一个事务内更新 status、published_at 和审计记录。重复发布应幂等，或返回明确冲突，项目需统一规则。

## 4. Repository 接口

~~~go
type PostRepository interface {
	Create(ctx context.Context, post *Post, tags []int64) error
	FindByID(ctx context.Context, id int64) (*Post, error)
	FindPublished(ctx context.Context, filter PostFilter) (Page[PostSummary], error)
	Update(ctx context.Context, post *Post, tags []int64) error
	SoftDelete(ctx context.Context, id int64) error
}
~~~

Repository 只处理持久化；PostService 处理权限、状态和事务编排。

## 5. 文章列表过滤

PostFilter 可包含：

- page、page_size
- keyword
- category_slug
- tag_slug
- cursor 或 created_before
- sort

默认只查 status=published 且 deleted_at IS NULL。keyword 查询初版可使用 LIKE，数据增长后再接全文索引。

## 6. 详情与浏览量

详情查询返回文章、作者摘要、分类和标签。浏览量更新可以：

- 简单版：数据库原子加一。
- 优化版：Redis INCR，后台批量刷库。
- 防刷版：按 IP、用户和时间窗口去重。

浏览量不是权限关键数据，失败时可以记录日志并不阻塞文章展示。

## 7. 分类与标签

分类 slug 用于 URL，name 用于展示。删除分类前检查文章引用，可迁移到默认分类或拒绝删除。标签关联表使用联合唯一约束。

## 8. Markdown 内容

数据库保存原始 Markdown，响应时返回 content。若渲染 HTML：

- 使用可信 Markdown 渲染器。
- 清理危险 HTML，防止 XSS。
- 不把用户输入直接拼进模板。
- 为内容设置最大长度。

## 9. 缓存策略

文章详情缓存键示例：post:detail:{id}。

- 读：先 Redis，未命中查数据库并写入，设置过期时间。
- 写：更新数据库成功后删除详情缓存。
- 删除：软删除成功后删除缓存。
- Redis 故障：回源数据库，不影响核心读请求。

## 10. 测试场景

- 作者创建草稿。
- 非作者更新文章返回 403。
- 游客看不到草稿。
- 发布后 published_at 非空。
- 重复标签不会产生重复关联。
- Redis 命中和未命中结果一致。
- 文章删除后详情返回 404。
