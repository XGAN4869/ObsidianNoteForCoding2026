## flatMap
### 场景1，扁平化取出child
```js
//扁平化处理,把child 单独抽离出来  
const totalTabs = computed(() => {  
  return accountStore.menu.flatMap((item) => {  
    //如果有 children，就只返回children  
    if (item.child && Array.isArray(item.child)) {  
      return item.child  
    }  
    //否则直接返回 item 项  
    return item  
  })  
})
```
