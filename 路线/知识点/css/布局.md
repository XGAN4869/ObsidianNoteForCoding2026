## 经典高度占满剩余空间
```vue
<template>
  <!-- 最外层容器 flex纵向，占满可视窗口高度 -->
  <div class="page-wrap">
    <div class="chat-bar">
      <!-- t-row 筛选栏 -->
    </div>
    <!-- 这里占剩余全部高度 -->
    <div class="chat-body"></div>
  </div>
</template>

<style lang="less" scoped>
.page-wrap {
  height: 100vh;
  display: flex;
  flex-direction: column;
}
.chat-bar {
  /* 高度自动，不需要写死 */
}
.chat-body {
  flex: 1;
  overflow: auto; /* 内容多了内部滚动，不会把页面撑出去 */
}
</style>
```


## position: relative / absolute
position 我一般按参照物来记。
static 是默认文档流；
relative 是相对自己原位置偏移；
absolute 是相对最近的非 static 祖先元素定位；
fixed 是相对视口定位，滚动时不动；
sticky 则是到了指定阈值后产生吸顶效果。

P.S. 一个元素上同时有 relative 和 absolute，后面的属性覆盖前面的属性
