# MySQL 从入门到精通：完整教程目录

> **教程定位**：本教程面向零基础读者，从数据库基本概念讲起，逐步深入到事务、索引优化、主从复制等高级主题。每章配有可运行的 SQL 代码、常见错误分析、练习题，帮助你在实践中掌握 MySQL。

---

## 阅读指南

本教程共 38 章 + 3 个附录，按 11 个阶段组织。每个阶段聚焦一个核心主题，循序渐进：

| 阶段       | 章节范围    | 核心目标                       | 建议学习时间 |
| -------- | ------- | -------------------------- | ------ |
| Phase 1  | 第01-03章 | 建立数据库基本认知，安装 MySQL，跑通第一个查询 | 1-2 天  |
| Phase 2  | 第04-08章 | 掌握 DDL（数据定义语言），能独立建库建表     | 3-5 天  |
| Phase 3  | 第09-12章 | 掌握 DML（数据操作语言），增删改数据       | 2-3 天  |
| Phase 4  | 第13-18章 | 精通 DQL（数据查询语言），写出复杂查询      | 5-7 天  |
| Phase 5  | 第19-21章 | 熟练使用内置函数处理数据               | 2-3 天  |
| Phase 6  | 第22-25章 | 掌握视图、存储过程、触发器、事件等高级对象      | 3-5 天  |
| Phase 7  | 第26-28章 | 理解事务、锁机制、并发控制              | 3-4 天  |
| Phase 8  | 第29-31章 | 掌握用户权限管理、备份恢复、日志管理         | 3-4 天  |
| Phase 9  | 第32-34章 | 精通索引原理、SQL 优化、执行计划分析       | 4-5 天  |
| Phase 10 | 第35-36章 | 学习主从复制、分区表等高级主题            | 3-4 天  |
| Phase 11 | 第37-38章 | 综合实战：设计完整的业务数据库 + 常见面试题    | 3-5 天  |

### 学习建议

1. **按顺序学习**：MySQL 知识有很强的依赖关系，理解前几章的数据类型和 DDL，后面的 DML 和 DQL 才能学得顺利
2. **必须手敲代码**：每个 SQL 示例都要自己在电脑上敲一遍，看一遍和敲一遍的效果天差地别
3. **练习必须做**：每章末尾的练习题是巩固知识的关键，参考答案见附录 C
4. **理解原理比记住语法更重要**：比如 InnoDB 的索引为什么用 B+ 树而不是红黑树？理解背后的原理能让你举一反三
5. **遇到错误先自己排查**：不要一看到报错就急着问人，试着读懂错误信息，用搜索引擎搜索，排查的过程本身就是最好的学习
6. **搭建一个自己的数据库项目**：学完 Phase 6 后，尝试自己设计一个小型业务系统（比如学生管理系统、图书管理系统），把学到的知识串联起来
