# 05 - 综合实战练习

> 目标：完成一个小型 Docker 化项目，综合使用 Dockerfile、Compose、network、volume、logs 和 registry。

---

## 项目目标

完成一个：

```text
Flask Web 应用 + Redis 计数器 + Docker Compose
```

要求：

```text
1. app 使用 Dockerfile 构建。
2. redis 使用官方镜像。
3. app 通过服务名 redis 连接 Redis。
4. 浏览器访问 app，计数递增。
5. 能查看日志。
6. 能故意制造错误并排查。
7. 能给镜像打 tag。
```

---

## 2. app.py

```python
from flask import Flask
import redis
import os

app = Flask(__name__)
redis_host = os.getenv("REDIS_HOST", "redis")
r = redis.Redis(host=redis_host, port=6379, decode_responses=True)

@app.get("/")
def index():
    count = r.incr("hits")
    return f"Hello Docker Final Practice, hits={count}"

@app.get("/health")
def health():
    return "ok"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

## 5. Dockerfile

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]
```

---

## 6. compose.yml

```yaml
services:
  app:
    build: .
    image: final-practice-app:1.0
    ports:
      - "5000:5000"
    environment:
      REDIS_HOST: redis
    depends_on:
      - redis

  redis:
    image: redis:7-alpine
```

## 10. 故意制造错误并排查

### 错误 1：REDIS_HOST 写错

把 compose.yml 中：

```yaml
REDIS_HOST: redis
```

改成：

```yaml
REDIS_HOST: localhost
```

重启：

```powershell
docker compose up -d --build
```

访问页面，观察错误。  
排查：

```powershell
docker compose logs app
```

结论：容器里的 localhost 是 app 容器自己，不是 redis 容器。

---

### 错误 2：requirements.txt 删除 redis

把 `requirements.txt` 改成只剩：

```text
flask
```

重新构建：

```powershell
docker compose up -d --build
```

排查：

```powershell
docker compose logs app
```

应该看到 Python 依赖导入失败。

---

### 错误 3：端口冲突

如果本机 5000 被占用，把端口改成：

```yaml
ports:
  - "5001:5000"
```

访问：

```text
http://localhost:5001
```

## 12. 可选：推送本地 registry

```powershell

```

打标签：

```powershell
docker tag final-practice-app:1.0 localhost:5000/final-practice-app:1.0
```

推送：

```powershell

```

## 13. 清理

停止项目：

```powershell
docker compose down
```

如果启动了 registry：

```powershell
docker stop final-registry
docker rm final-registry
```

不要随便执行：

```powershell
docker compose down -v
```

除非你确认要删除 volume。
