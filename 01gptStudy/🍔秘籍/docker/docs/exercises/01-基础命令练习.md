# 01 - 基础命令练习

> 目标：通过重复练习掌握 Docker 最基础的容器和镜像命令。

---

## 练习前准备

确认 Docker 可用：

```powershell
docker version
docker info
```

如果报错，先回到：

```text
docs/02-Docker安装与环境检查.md
```

---

## 练习 1：运行 hello-world

执行：

```powershell
docker run hello-world
```

然后查看所有容器：

```powershell
docker ps -a
```

你要回答：

```text
hello-world 容器是否还在运行？
为什么 docker ps 看不到它？
```

参考理解：

```text
hello-world 执行完就退出，所以 docker ps 看不到，但 docker ps -a 能看到。
```

---

## 练习 2：运行 nginx

```powershell
docker run -d --name practice-nginx -p 8090:80 nginx
```

访问：

```text
http://localhost:8090
```

检查：

```powershell
docker ps
docker logs practice-nginx
```

---

## 练习 3：停止、启动、重启

```powershell
docker stop practice-nginx
docker ps
docker ps -a
docker start practice-nginx
docker restart practice-nginx
```

你要回答：

```text
docker stop 后容器是否被删除？
docker start 和 docker run 有什么区别？
```

---

## 练习 4：进入容器

```powershell
docker exec -it practice-nginx sh
```

进入后执行：

```sh
pwd
ls
ls /usr/share/nginx/html
cat /etc/os-release
exit
```

你要回答：

```text
exit 后容器是否还在运行？
```

---

## 练习 5：查看详细信息

```powershell
docker inspect practice-nginx
```

重点找：

```text
State
NetworkSettings
Mounts
Config
```

不用全部看懂，先练习找信息。

---

## 练习 6：删除容器

```powershell
docker stop practice-nginx
docker rm practice-nginx
docker ps -a
```

确认容器已经不存在。

---

## 练习 7：镜像操作

```powershell
docker pull nginx:alpine
docker images
docker history nginx:alpine
docker image inspect nginx:alpine
```

给镜像打标签：

```powershell
docker tag nginx:alpine practice-image:1.0
docker images
```

删除标签：

```powershell
docker rmi practice-image:1.0
```

---

## 练习 8：临时容器

```powershell
docker run --rm alpine echo "hello docker"
```

查看：

```powershell
docker ps -a
```

你要回答：

```text
为什么找不到刚才的 alpine 容器？
```

参考：

```text
因为使用了 --rm，容器运行结束后自动删除。
```

---

## 练习 9：交互式容器

```powershell
docker run -it --rm alpine sh
```

进入后：

```sh
hostname
ip addr
ps
exit
```

---

## 练习 10：清理检查

查看容器：

```powershell
docker ps -a
```

查看镜像：

```powershell
docker images
```

只清理你明确知道是练习创建的容器和镜像。不要乱用大清理命令。

- [ ] 能运行 hello-world

- [ ] 能查看容器
- [ ] 能停止、启动、重启容器

- [ ] 能查看日志
- [ ] 能删除容器
- [ ] 能查看镜像
