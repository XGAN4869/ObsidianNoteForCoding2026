# 04 - 网络排查练习

> 目标：通过故意制造网络错误，练习 Docker 网络排查。

---

## 练习 1：端口映射成功

```powershell
docker run -d --name net-nginx -p 8091:80 nginx
```

访问：

```text
http://localhost:8091
```

检查：

```powershell
docker ps
```

观察 `PORTS` 字段。

清理：

```powershell
docker stop net-nginx
docker rm net-nginx
```

---

## 练习 2：忘记端口映射

```powershell
docker run -d --name net-no-port nginx
```

尝试访问：

```text
http://localhost:80
```

大概率访问不到你期望的容器服务。

排查：

```powershell
docker ps
```

看 `PORTS` 是否有宿主机端口映射。

清理：

```powershell
docker stop net-no-port
docker rm net-no-port
```

---

## 练习 3：自定义网络和容器名解析

创建网络：

```powershell
docker network create practice-net
```

启动 nginx：

```powershell
docker run -d --name web --network practice-net nginx
```

用 curl 容器访问：

```powershell
docker run --rm --network practice-net curlimages/curl http://web
```

如果成功，说明容器名解析正常。

查看网络：

```powershell
docker network inspect practice-net
```

清理：

```powershell
docker stop web
docker rm web
docker network rm practice-net
```

## 练习 4：不在同一网络导致失败

创建网络：

```powershell
docker network create net-a
docker network create net-b
```

启动：

```powershell
docker run -d --name web-a --network net-a nginx
```

从另一个网络访问：

```powershell
docker run --rm --network net-b curlimages/curl http://web-a
```

预期：访问失败。

排查：

```powershell
docker network inspect net-a
docker network inspect net-b
```

清理：

```powershell
docker stop web-a
docker rm web-a
docker network rm net-a net-b
```

## 练习 5：Compose 服务名通信

`compose.yml`：

```yaml
services:
  redis:
    image: redis:7-alpine
  test:
    image: redis:7-alpine
    command: ["redis-cli", "-h", "redis", "ping"]
    depends_on:
      - redis
```

启动：

```powershell
docker compose up
```

观察是否输出：

```text
PONG
```

## 网络排查模板

```text
1. 容器是否运行？docker ps
2. 端口是否映射？看 PORTS
3. 是否写反 -p？宿主机端口:容器端口
4. 两个容器是否同一网络？docker network inspect
5. 是否错误使用 localhost？
6. 服务是否监听 0.0.0.0 而不是只监听 127.0.0.1？
7. DNS 名称是否正确？
8. 防火墙、代理、公司网络是否影响？
```
