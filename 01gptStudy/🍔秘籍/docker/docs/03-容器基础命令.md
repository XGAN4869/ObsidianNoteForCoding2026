# 03 - 容器基础命令

> 本章目标：掌握最常用的容器命令。学完后，你要能独立启动、查看、停止、删除、进入容器，并查看日志。

---

## 1. 本章核心命令

```powershell
docker run
docker ps
docker ps -a
docker stop
docker start
docker restart
docker rm
docker logs
docker exec
docker inspect
```

口诀：

```text
run 创建并运行
ps 查看运行中
ps -a 查看全部
stop 停止
start 启动
restart 重启
rm 删除
logs 看日志
exec 进入或执行命令
inspect 看详细信息
```

---

## 2. 容器生命周期

容器常见过程：

```text
创建 -> 运行 -> 停止 -> 再启动 -> 删除
```

对应命令：

```text
docker run      创建并启动
docker stop     停止
docker start    启动已有容器
docker rm       删除
```

注意：

```text
删除容器前通常先停止容器。
```

---

## 3. docker run：创建并启动容器

最简单示例：

```powershell
docker run hello-world
```

它会：

```text
1. 找 hello-world 镜像
2. 本地没有就拉取
3. 创建容器
4. 启动容器
5. 输出信息
6. 容器退出
```

运行 nginx：

```powershell
docker run nginx
```

这会前台运行，终端会被占住。按 `Ctrl + C` 可以停止。

---

## 4. 后台运行：-d

```powershell
docker run -d nginx
```

`-d` 表示 detached，后台运行。

---

## 5. 给容器取名：--name

```powershell
docker run -d --name web1 nginx
```

以后可以用名字操作：

```powershell
docker logs web1
docker stop web1
docker start web1
docker rm web1
```

如果不取名，Docker 会自动生成一个名字，但不方便学习。

---

## 6. 查看正在运行的容器：docker ps

```powershell
docker ps
```

常见字段：

| 字段 | 含义 |
|---|---|
| CONTAINER ID | 容器 ID |
| IMAGE | 使用的镜像 |
| COMMAND | 启动命令 |
| CREATED | 创建时间 |
| STATUS | 状态 |
| PORTS | 端口映射 |
| NAMES | 容器名称 |

---

## 7. 查看所有容器：docker ps -a

```powershell
docker ps -a
```

显示：

```text
正在运行的容器
已经停止的容器
运行完退出的容器
```

找不到容器时，先用这个命令。

---

## 8. 停止容器：docker stop

创建测试容器：

```powershell
docker run -d --name web-stop-demo nginx
```

停止：

```powershell
docker stop web-stop-demo
```

查看：

```powershell
docker ps
docker ps -a
```

你会发现：

```text
docker ps 看不到它。
docker ps -a 还能看到它。
```

---

## 9. 启动已停止容器：docker start

```powershell
docker start web-stop-demo
```

注意区别：

| 命令 | 含义 |
|---|---|
| `docker run` | 创建新容器并启动 |
| `docker start` | 启动已经存在的容器 |

---

## 10. 重启容器：docker restart

```powershell
docker restart web-stop-demo
```

它相当于：

```text
先 stop，再 start。
```

---

## 11. 删除容器：docker rm

先停止：

```powershell
docker stop web-stop-demo
```

再删除：

```powershell
docker rm web-stop-demo
```

如果确认要强制删除运行中的容器，可以：

```powershell
docker rm -f web-stop-demo
```

初学阶段建议少用 `-f`，养成习惯：

```text
先 stop，再 rm。
```

---

## 12. 查看日志：docker logs

启动 nginx：

```powershell
docker run -d --name web-logs-demo -p 8080:80 nginx
```

访问：

```text
http://localhost:8080
```

查看日志：

```powershell
docker logs web-logs-demo
```

持续查看日志：

```powershell
docker logs -f web-logs-demo
```

查看最后 20 行：

```powershell
docker logs --tail 20 web-logs-demo
```

退出持续日志：按 `Ctrl + C`。

---

## 13. 进入容器：docker exec

```powershell
docker exec -it web-logs-demo sh
```

解释：

| 参数 | 含义 |
|---|---|
| `exec` | 在运行中的容器里执行命令 |
| `-i` | 保持输入打开 |
| `-t` | 分配终端 |
| `sh` | 打开 shell |

进入后可以执行：

```sh
pwd
ls
cat /etc/os-release
```

退出：

```sh
exit
```

注意：退出 shell 不等于停止容器。

---

## 14. 不进入容器，直接执行命令

```powershell
docker exec web-logs-demo nginx -v
```

或者：

```powershell
docker exec web-logs-demo ls /usr/share/nginx/html
```

---

## 15. 端口映射：-p

容器里面的服务，宿主机默认不一定能直接访问。  
需要端口映射：

```powershell
docker run -d --name web-port-demo -p 8081:80 nginx
```

意思：

```text
宿主机 8081 端口 -> 容器 80 端口
```

访问：

```text
http://localhost:8081
```

一定记住顺序：

```text
-p 宿主机端口:容器端口
```

---

## 16. 查看详细信息：docker inspect

```powershell
docker inspect web-port-demo
```

它会输出很多 JSON 信息，包括：

```text
状态
环境变量
端口映射
网络信息
挂载信息
启动命令
```

初学阶段重点看：

```text
State
NetworkSettings
Mounts
Config
```

---

## 17. 临时容器：--rm

有些容器只想运行一次，结束后自动删除：

```powershell
docker run --rm hello-world
```

或：

```powershell
docker run --rm alpine echo "hello docker"
```

`--rm` 删除的是容器，不是镜像。

---

## 18. 交互式容器：-it

```powershell
docker run -it --rm alpine sh
```

解释：

```text
-it   可以交互
--rm  退出后删除容器
alpine 一个很小的 Linux 镜像
sh    进入 shell
```

进入后：

```sh
uname -a
cat /etc/os-release
exit
```

---

## 19. 环境变量：-e

例如 MySQL 容器需要 root 密码：

```powershell
docker run -d --name mysql-demo -e MYSQL_ROOT_PASSWORD=123456 mysql
```

`-e` 表示设置环境变量。

提醒：

```text
真实工作中不要把重要密码直接写在命令里。
初学练习可以。
```

---

## 20. 重启策略：--restart

```powershell
docker run -d --name web-restart-demo -p 8082:80 --restart unless-stopped nginx
```

常见策略：

| 策略 | 含义 |
|---|---|
| `no` | 不自动重启，默认 |
| `always` | 总是自动重启 |
| `unless-stopped` | 除非手动停止，否则自动重启 |
| `on-failure` | 失败时重启 |

---

## 21. 容器名字冲突

如果执行两次：

```powershell
docker run -d --name web1 nginx
```

可能报错：

```text
Conflict. The container name is already in use
```

原因：容器名已经被占用。

解决：

```powershell
docker stop web1
docker rm web1
```

或者换名字：

```powershell
docker run -d --name web2 nginx
```

---

## 22. 清理本章实验容器

查看：

```powershell
docker ps -a
```

逐个清理更安全：

```powershell
docker stop web-logs-demo
docker rm web-logs-demo

docker stop web-port-demo
docker rm web-port-demo

docker stop web-restart-demo
docker rm web-restart-demo
```

如果容器不存在，命令可能报错，忽略即可。

---

## 23. 初学阶段不要乱用

```powershell
docker system prune -a
docker system prune --volumes
docker rm -f $(docker ps -aq)
```

这些命令可能清掉大量资源，甚至影响数据。等你理解清楚后再用。

## 24. 常见问题排查

### 24.1 容器找不到

先看运行中：

```powershell
docker ps
```

再看全部：

```powershell
docker ps -a
```

如果容器退出，查日志：

```powershell
docker logs 容器名
```

---

### 24.2 localhost 访问失败

检查：

```powershell
docker ps
```

看 `PORTS` 是否有类似：

```text
0.0.0.0:8080->80/tcp
```

如果没有，说明没有正确加：

```powershell
-p 8080:80
```

---

### 24.3 删除失败

先停止：

```powershell
docker stop 容器名
```

再删除：

```powershell
docker rm 容器名
```

---

### 24.4 docker run 每次都多一个容器

因为：

```text
docker run = 创建新容器并启动
```

如果只是启动旧容器：

```powershell
docker start 容器名
```

## 26. 必须背下来的区别

### run 和 start

| 命令 | 作用 |
|---|---|
| `docker run` | 创建新容器并启动 |
| `docker start` | 启动已经存在的容器 |

### stop 和 rm

| 命令 | 作用 |
|---|---|
| `docker stop` | 停止容器，容器还在 |
| `docker rm` | 删除容器 |

### ps 和 ps -a

| 命令 | 作用 |
|---|---|
| `docker ps` | 查看正在运行的容器 |
| `docker ps -a` | 查看所有容器，包括停止的 |

## 27. 本章总结

记住：

```text
1. docker run 会创建并启动新容器。
2. docker ps 查看正在运行的容器。
3. docker ps -a 查看所有容器。
4. docker stop 停止容器。
5. docker start 启动已存在容器。
6. docker rm 删除容器。
7. docker logs 查看日志。
8. docker exec -it 可以进入容器。
9. -p 宿主机端口:容器端口 用来做端口映射。
10. --name 可以给容器取名字。
```
