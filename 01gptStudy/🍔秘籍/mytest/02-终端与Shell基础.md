## 1. 概述

### 1.1 从图形界面到命令行

在上一章中，你成功安装并启动了 Ubuntu 24.04 LTS，看到了一个漂亮的图形化桌面。你通过鼠标点击图标、拖拽窗口来完成操作，这和 Windows 的使用体验非常相似。然而，图形界面（Graphical User Interface，简称 GUI）只是 Linux 的"外表"——真正能让你高效操控 Linux 的，是命令行界面（Command-Line Interface，简称 CLI）。

在 Linux 的世界里，几乎一切操作都可以通过命令来完成：安装软件、管理文件、配置网络、编写脚本。许多服务器甚至根本不安装图形界面，管理员完全通过命令行来管理它们。掌握命令行，是从"Linux 使用者"进阶为"Linux 操控者"的关键一步。

### 1.2 本章学习目标

完成本章后，你将能够：

- 理解终端（Terminal）、Shell 和操作系统内核（Kernel）之间的关系
- 独立打开 Ubuntu 终端并使用 Bash Shell
- 使用 `echo` 命令输出文本和环境变量
- 使用 `clear` 和 `exit` 管理终端会话
- 使用 `alias` 和 `unalias` 创建和管理命令别名
- 使用 `history` 查看和复用历史命令
- 熟练使用 Tab 自动补全、Ctrl+R 反向搜索等效率快捷键
- 掌握 Ctrl+C/Z/D/R/L/A/E/U/K/W 等行编辑快捷键

## 2. 核心概念

### 2.1 终端（Terminal）、Shell 与内核（Kernel）的关系

在深入命令之前，必须先理清三个容易混淆的概念：

```
用户  ←→  终端（Terminal）  ←→  Shell  ←→  内核（Kernel）  ←→  硬件
```

| 概念 | 角色 | 通俗理解 |
|------|------|----------|
| **终端（Terminal）** | 用户与 Shell 之间的"窗口界面" | 就像微信的聊天窗口——它负责显示消息（输出）和接收你的打字（输入），但不负责"理解"你说的话 |
| **Shell** | 命令的解释器（Command Interpreter） | 就像翻译官——你输入的是人类可读的命令，Shell 把它翻译成内核能理解的指令。Shell 还负责把内核的返回结果翻译成人类可读的文本 |
| **内核（Kernel）** | 操作系统的核心 | 就像公司的 CEO——所有的实际工作（读写磁盘、分配内存、调度进程）都由它来执行，但它不直接与普通员工（用户）沟通 |

**比喻理解：** 把操作系统比作一家公司：
- **终端**是前台接待窗口——你在这里提交请求和接收结果
- **Shell**是总裁秘书——你告诉秘书你想做什么，秘书把它整理成正式文件递交给总裁
- **内核**是总裁——最终拍板、调度资源、执行实际操作

### 2.2 什么是 Bash

Bash 的全称是 **B**ourne **A**gain **SH**ell，由 Brian Fox 于 1989 年为 GNU 项目开发。它是绝大多数 Linux 发行版的默认 Shell，也是 Ubuntu 24.04 LTS 的默认交互式 Shell。

验证你当前使用的 Shell：

```bash
echo $SHELL
```

预期输出：

```
/bin/bash
```

查看 Bash 版本：

```bash
bash --version
```

预期输出（版本号可能略有不同）：

```
GNU bash, version 5.2.21(1)-release (x86_64-pc-linux-gnu)
```

**常见 Shell 一览：**

| Shell | 全称 | 特点 |
|-------|------|------|
| **sh** | Bourne Shell | Unix 上最早的 Shell，功能最基础 |
| **bash** | Bourne Again SHell | sh 的增强版，Linux 默认 Shell |
| **zsh** | Z Shell | bash 的超集，插件系统强大，macOS 默认 Shell（自 Catalina 起） |
| **fish** | Friendly Interactive SHell | 开箱即用，智能语法高亮和自动补全，无需配置 |
| **dash** | Debian Almquist Shell | 轻量级，启动速度快，Debian/Ubuntu 的系统脚本 Shell |
| **ksh** | Korn Shell | 商业 Unix 常见，融合了 sh 和 csh 的特性 |

### 2.3 Bash 的启动模式

Bash 在不同场景下以不同模式启动。理解这些模式有助于排查 .bashrc / .bash_profile 配置不生效等问题。

**登录 Shell（Login Shell）vs 非登录 Shell（Non-login Shell）：**

| 属性 | 登录 Shell | 非登录 Shell |
|------|-----------|-------------|
| **何时触发** | 通过 `Ctrl+Alt+F2~F6` 切换到虚拟控制台登录、SSH 远程登录、`su -` 切换用户 | 在桌面环境中打开终端程序、在已登录的 Shell 中输入 `bash` 启动子 Shell |
| **加载的配置文件** | `/etc/profile` → `~/.bash_profile` → `~/.bashrc` | 仅 `~/.bashrc` |
| **典型场景** | 开机后第一次登录系统 | 在 GNOME 中按 `Ctrl+Alt+T` 打开终端 |

**交互式 Shell（Interactive Shell）vs 非交互式 Shell（Non-interactive Shell）：**

| 属性 | 交互式 Shell | 非交互式 Shell |
|------|-------------|----------------|
| **特征** | 有提示符，等用户输入并执行，执行完继续等待 | 从文件或管道读取命令，执行完自动退出 |
| **是否支持作业控制** | 支持（`Ctrl+Z`、`jobs`、`fg`、`bg`） | 默认不支持 |
| **典型场景** | 你打开的终端窗口 | 运行 Shell 脚本（如 `bash script.sh`） |

**快速判断当前 Shell 模式：**

检查是否为登录 Shell：
```bash
shopt -q login_shell && echo "登录 Shell（Login Shell）" || echo "非登录 Shell（Non-login Shell）"
```

检查是否为交互式 Shell：
```bash
[[ $- == *i* ]] && echo "交互式 Shell（Interactive Shell）" || echo "非交互式 Shell（Non-interactive Shell）"
```

> **小结：** 你在 Ubuntu 桌面上按 `Ctrl+Alt+T` 打开的终端，运行的是**交互式非登录 Shell**。这意味着配置文件 `~/.bashrc` 会在每次打开新终端窗口时被自动加载。

### 2.4 命令提示符（Command Prompt）解读

打开终端后，你会看到类似下面这样的提示符：

```
zhangsan@ubuntu:~$
```

| 组成部分 | 示例值 | 含义 |
|----------|--------|------|
| `zhangsan` | 当前用户名 | 你登录系统时使用的用户名（Who am I） |
| `@` | 分隔符 | 固定字符，无特殊含义，表示"在…上" |
| `ubuntu` | 主机名（Hostname） | 这台计算机的名字（Where am I） |
| `:` | 分隔符 | 固定字符 |
| `~` | 当前目录 | `~`（波浪号）是当前用户家目录（Home Directory）的简写，等价于 `/home/zhangsan` |
| `$` | 提示符结尾 | `$` 表示当前是普通用户；`#` 表示当前是 root（超级用户） |

完整展开后等价于："用户 zhangsan 在机器 ubuntu 上的家目录中，正在等待输入命令"。

### 2.5 标准输入、标准输出与标准错误

Linux 中每个进程默认打开三个"通道"：

| 通道 | 英文名称 | 文件描述符（File Descriptor） | 默认目标 |
|------|----------|------------------------------|----------|
| **标准输入** | Standard Input（stdin） | 0 | 键盘 |
| **标准输出** | Standard Output（stdout） | 1 | 终端屏幕 |
| **标准错误** | Standard Error（stderr） | 2 | 终端屏幕 |

这三个概念将在后续章节（管道、重定向）中反复出现。现在你只需要知道：你敲键盘输入的是 stdin，命令正常执行的结果输出到 stdout，命令执行失败的错误提示输出到 stderr。

## 3. 命令详解

### 3.1 打开终端

在 Ubuntu 中可以这样打开终端：

| 方法 | 操作 |
|------|------|
| **快捷键（推荐）** | 按下 `Ctrl + Alt + T` |
| **应用菜单** | 点击左下角"显示应用程序"图标（九宫格），搜索"终端"（Terminal），点击打开 |
| **右键菜单** | 在桌面空白处右键，选择"在终端中打开"（Open in Terminal） |

现在请打开终端，你将在其中运行本章的所有命令。

### 3.2 echo —— 输出文本到屏幕

`echo` 是最简单的命令之一，它将你输入的文本回显（输出）到屏幕上。

#### 基础用法

```bash
echo Hello World
```

输出：

```
Hello World
```

输出包含变量的内容：

```bash
echo "我的用户名是 $USER，我的家目录是 $HOME"
```

输出：
```
我的用户名是 zhangsan，我的家目录是 /home/zhangsan
```

输出当前 Shell 路径：

```bash
echo $SHELL
```

输出：

```
/bin/bash
```

#### 常用选项

```bash
echo -n "不换行输出"
```

```bash
echo -e "第一行\n第二行\n第三行"
```

```bash
echo -e "制表符\t分隔\t的内容"
```

```bash
echo -E "反斜杠不会被转义 \n \t"
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `-n` | 输出后不追加换行符（newline） | 可选 | 追加换行符 |
| `-e` | 启用反斜杠转义序列（escape sequences）的解释 | 可选 | 不启用（`-E`） |
| `-E` | 禁用反斜杠转义序列的解释（默认行为） | 可选 | 已启用 |

#### `-e` 模式下的常用转义序列

| 转义序列 | 含义 |
|----------|------|
| `\n` | 换行（Newline） |
| `\t` | 水平制表符（Tab） |
| `\\` | 反斜杠自身 |
| `\"` | 双引号 |

> **注意：** 在 `echo` 中使用变量时，建议使用**双引号**包裹字符串（如 `"$USER"`），而不是单引号。单引号内的所有字符都会被当作字面值处理，变量不会被替换。

验证单引号与双引号的区别：

```bash
echo '$USER 不会展开'
echo "$USER 会被展开"
```

输出：

```
$USER 不会展开
zhangsan 会被展开
```

### 3.3 clear —— 清空终端屏幕

`clear` 命令将终端屏幕上的所有内容清空，光标回到左上角。它不删除任何历史记录，只是让你的屏幕变得整洁。

```bash
clear
```

执行后，屏幕被清空，提示符出现在最左上角。你可以向上滚动（鼠标滚轮或 Shift+PageUp）查看之前的输出——它们仍然存在，只是被推到了屏幕可见区域之外。

**等效快捷键：** `Ctrl + L`，效果与 `clear` 完全相同，且不需要回车，按完即执行。

### 3.4 exit —— 退出 Shell 会话

`exit` 命令用于结束当前的 Shell 会话并关闭终端窗口。

```bash
exit
```

也可以指定退出码（Exit Code）：

```bash
exit 0
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `[n]` | 退出码，0 表示正常退出，非 0 表示异常退出。该值可供调用者（如脚本）读取 | 可选 | 上一条命令的退出码 |

**等效快捷键：** `Ctrl + D`，向 Shell 发送 EOF（End of File，文件结束）信号。在大多数场景下，`Ctrl + D` 的效果与 `exit` 等同——关闭当前 Shell 会话。

> **注意：** 如果在最后一个终端窗口中执行 `exit`，该窗口会关闭。如果你只有一个终端窗口打开，`exit` 会直接关闭它。

### 3.5 alias —— 创建命令别名

`alias` 让你为长命令创建简短的别名，大幅减少打字量。

#### 基础用法

定义别名：

```bash
alias ll='ls -l'
```

现在输入 `ll` 就等于输入 `ls -l`。

查看某个别名：

```bash
alias ll
```

输出：

```
alias ll='ls -l'
```

查看所有已定义的别名：

```bash
alias
```

#### 实用示例

```bash
alias update='sudo apt update && sudo apt upgrade -y'
```

```bash
alias c='clear'
```

```bash
alias ..='cd ..'
```

```bash
alias ...='cd ../..'
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `name=value` | 定义别名，格式为 `别名='命令'`。等号两边不能有空格 | 可选 | 无 |
| `-p` | 以 `alias name=value` 格式打印当前所有别名 | 可选 | 无参数时打印所有别名（格式化稍有不同） |

> **重要：** 通过 `alias` 直接定义的别名仅在当前 Shell 会话中有效。关闭终端后别名即消失。要让别名**永久生效**，需要将其写入 `~/.bashrc` 文件中。详见第 3.7 节。

验证别名只在当前会话有效：
```bash
# 定义一个临时别名
alias hi='echo 你好！'
# 验证
hi
# 关闭终端后重新打开，再次输入 hi，系统会提示"command not found"
```

### 3.6 unalias —— 删除命令别名

`unalias` 用于删除已定义的别名。

```bash
unalias ll
```

删除后，`ll` 不再等于 `ls -l`。

```bash
unalias -a
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `name` | 要删除的别名名称 | 可选（不提供名称时，若也未指定 `-a`，命令报错） | 无 |
| `-a` | 删除当前 Shell 会话中的**全部**别名 | 可选 | 否 |

### 3.7 永久保存别名

要在每次打开终端时自动加载你的别名，需要将它们写入 `~/.bashrc` 文件。

**步骤：**

1. 用文本编辑器打开 `~/.bashrc`（使用 `nano`，Ubuntu 自带）：

```bash
nano ~/.bashrc
```

2. 在文件末尾添加你的别名（每行一个）：

```bash
alias ll='ls -l'
alias update='sudo apt update && sudo apt upgrade -y'
alias c='clear'
```

3. 按 `Ctrl + X` 退出，按 `Y` 确认保存，按 `Enter` 确认文件名。

4. 让修改立即生效（无需关闭终端）：

```bash
source ~/.bashrc
```

现在你定义的别名在所有终端中都会生效。

### 3.8 history —— 查看命令历史

`history` 命令用于查看你运行过的命令列表。

#### 基础用法

查看最近执行的命令：

```bash
history
```

输出（示例）：

```
1  echo Hello World
2  clear
3  alias ll='ls -l'
4  history
```

默认显示最近的 1000 条命令（由 `HISTSIZE` 环境变量控制）。

#### 常用选项

只显示最近 10 条：

```bash
history 10
```

清除当前会话的命令历史记录：

```bash
history -c
```

删除历史记录中指定编号的命令（例如删除第 42 条）：

```bash
history -d 42
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `[n]` | 仅显示最近 n 条命令 | 可选 | 显示全部（受 `HISTSIZE` 限制） |
| `-c` | 清除当前 Shell 会话的历史记录列表 | 可选 | 否 |
| `-d offset` | 删除历史列表中指定偏移量（编号）的那条记录 | 可选 | 无 |

#### 快速执行历史命令

| 操作 | 含义 |
|------|------|
| `!!` | 重复上一条命令（也称为"bang bang"） |
| `!n` | 执行历史记录中编号为 n 的命令（如 `!42`） |
| `!string` | 执行最近一条以 string 开头的命令（如 `!echo` 执行最近一条 echo 开头的命令） |

示例：

```bash
echo Hello
!!              # 重复执行 echo Hello
!ec            # 执行最近一条以 ec 开头的命令
```

运行确认：

```bash
echo Hello
```

输出：`Hello`

```bash
!!
```

输出：`Hello`（因为重复执行了上一条命令）

#### 反向搜索历史：Ctrl+R

在终端中按下 `Ctrl + R`，你会看到：

```
(reverse-i-search)`':
```

此时输入关键词（如 `echo`），Shell 会在历史记录中**实时反向搜索**（从旧到新），显示最近一条包含该关键词的命令。如果这不是你要找的命令，可以**再次按 `Ctrl + R`** 查看更早的匹配项。

找到目标命令后：
- 按 `Enter` 直接执行它
- 按 `Esc` 或 `Ctrl + G` 退出搜索（命令保留在提示符中，可以编辑后再执行）
- 按 `Ctrl + C` 取消搜索，回到空提示符

**实践：** 依次执行以下示例来体验 Ctrl+R：

```bash
echo 第一行
echo 第二行
echo 第三行
```

然后按 `Ctrl + R`，输入 `echo`，观察匹配结果。再按一次 `Ctrl + R`，观察它跳转到更早的匹配项。

### 3.9 Tab 自动补全

Tab 是命令行的"提词器"——它可以补全命令名、文件名、目录名、环境变量名甚至命令参数。

#### 补全命令名

```bash
his<Tab>
```

系统自动补全为 `history`。如果有多个匹配项，快速连按两次 Tab，系统会列出所有候选。

尝试：

```bash
ech<Tab>
```

自动补全为 `echo`（如果没有 `ech` 开头的其他命令）。

#### 补全文件路径

```bash
ls /etc/hos<Tab>
```

自动补全为 `ls /etc/hosts`。

尝试：

```bash
# 输入后按 Tab（先不用回车）
ls /etc/net<Tab><Tab>
```

如果 `/etc/` 下有多个以 `net` 开头的文件或目录，连按两次 Tab 会显示所有候选。

#### 补全环境变量

```bash
echo $HO<Tab>
```

自动补全为 `echo $HOME`。

#### 什么可以被补全

| 补全对象 | 示例 |
|----------|------|
| 命令名称 | `sys<Tab>` → `systemctl` |
| 文件路径 | `cat /etc/ho<Tab>` → `cat /etc/hosts` |
| 目录路径 | `cd /usr/lo<Tab>` → `cd /usr/local` |
| 环境变量 | `echo $PA<Tab>` → `echo $PATH` |
| 用户名（`~` 前缀） | `cd ~zh<Tab>` → `cd ~zhangsan` |

### 3.10 键盘快捷键速查

掌握以下快捷键，你的终端操作效率将成倍提升。建议在阅读时逐一在终端中尝试。

#### 进程控制快捷键

| 快捷键 | 全称 / 含义 | 作用 |
|--------|------------|------|
| `Ctrl + C` | **C**ancel / Interrupt | 终止（中断）当前正在运行的前台程序。这是最常用的快捷键之一——当你运行了一个不该运行或卡住的命令时，用它来中止 |
| `Ctrl + D` | End of File (EOF) | 发送 EOF（文件结束）信号。在空白命令行上按下会关闭终端（等同于 `exit`）。在交互式程序中（如 `cat`、`python`）可用于表示输入结束 |
| `Ctrl + Z` | Suspend（挂起） | 暂停当前前台程序，将其放入后台，回到 Shell 提示符。被暂停的程序可以用 `fg` 恢复到前台，或用 `bg` 让它在后台继续运行 |

**实践 Ctrl+C：**

```bash
# 下面这条命令会无限输出"hello"，直到你按 Ctrl+C
yes hello
```

按下 `Ctrl+C`，程序立即终止，提示符重新出现。

**实践 Ctrl+D：**

```bash
# 输入 cat 后回车，cat 等待你输入内容
cat
# 输入任意文字，然后按 Ctrl+D 结束输入
hello world<Ctrl+D>
```

`cat` 会把你输入的内容回显出来，然后退出。

**实践 Ctrl+Z（及 fg/bg）：**

```bash
# 启动一个长时间运行的程序
sleep 300
```

按下 `Ctrl+Z`，你会看到类似输出：

```
[1]+  Stopped    sleep 300
```

此时程序被暂停。输入 `fg` 将它恢复到前台继续运行，或输入 `bg` 让它在后台运行。恢复后等待它自行结束，或按 `Ctrl+C` 终止。

#### 行编辑快捷键

这些快捷键让你在输入命令时快速跳转和编辑，无需使用方向键。

| 快捷键 | 作用 | 记忆方法 |
|--------|------|----------|
| `Ctrl + A` | 将光标移动到行首 | **A** 是字母表的开头，所以光标跳到行**首** |
| `Ctrl + E` | 将光标移动到行尾 | **E**nd（末尾），所以光标跳到行**尾** |
| `Ctrl + U` | 删除（剪切）从光标位置到**行首**的内容 | 想象把光标**前面**的内容"剪"掉 |
| `Ctrl + K` | 删除（剪切）从光标位置到**行尾**的内容 | 想象把光标**后面**的内容"砍"掉（**K**ill / **k**ut） |
| `Ctrl + W` | 删除（剪切）光标**左边**的一个单词 | **W**ord（单词），按单词为单位删除 |
| `Ctrl + Y` | 粘贴被 `Ctrl+U`、`Ctrl+K` 或 `Ctrl+W` 剪切的内容 | **Y**ank（拽回）——把之前剪切的东西"拽"回来 |

**组合演练：**

在一个很长的命令行中：

```bash
echo 第一段 第二段 第三段 第四段 第五段
```

1. 按 `Ctrl+A` 跳转到行首
2. 按 `Ctrl+K` 删除整行（光标在行首时，删除到行尾 = 删除整行）
3. 按 `Ctrl+Y` 粘贴回来

或者：

1. 输入一段长命令（不要回车）
2. 按 `Ctrl+A` 回到行首，按 `Ctrl+W` 删除第一个词
3. 按 `Ctrl+E` 跳转到行尾
4. 按 `Ctrl+Y` 将刚才删除的词粘贴到行尾

### 3.11 bash —— 启动一个新的 Bash 实例

执行后，你会进入一个新的 Bash Shell。输入 `exit` 或按 `Ctrl+D` 可以返回上一层。

### 练习 4.2：echo 综合练习

**题目：** 使用 `echo` 命令完成以下 4 项输出，并解释每项使用的参数作用。

（2）输出带换行的三行诗句

（4）简易表格：

`\t` 插入水平制表符，实现列对齐效果。

## 5. 常见错误与排错

### 5.1 "command not found"（命令未找到）

**现象：** 输入命令后提示 `command not found`。

```bash
lau
```

```
lau: command not found
```

**原因与解决：**

| 原因 | 解决方法 |
|------|----------|
| 命令拼写错误 | 检查单词拼写。可使用 Tab 补全避免拼写错误 |
| 别名未定义或已过期 | 检查 `alias \| grep 别名` 确认别名是否存在。如果别名只在当前会话中定义过且终端已关闭，需要重新定义或写入 `~/.bashrc` |
| 命令实际安装在系统中但不在 PATH 路径中 | 使用 `which 命令名` 检查命令是否存在。如 `which la` 无输出表示该命令不存在 |

### 5.2 终端无响应或"卡死"

**现象：** 终端光标闪烁但不接受任何输入，或你有输入但屏幕无反馈。

**原因与解决：**

| 原因 | 解决方法 |
|------|----------|
| 有程序在前台运行 | 按 `Ctrl+C` 尝试终止。若无反应，尝试 `Ctrl+Z` 挂起，再按 `Ctrl+C` |
| 程序等待输入但你没注意到 | 观察提示符——某些程序（如 `passwd`、`sudo`）会等待你输入密码。输入密码时屏幕**不会有任何显示**（连星号也没有），这是正常的安全设计。输完密码后按回车即可 |
| 终端真正卡死 | 关闭当前终端窗口重新打开。如果需要强制退出：在终端菜单中点击"终端" > "关闭" |

### 5.3 别名定义中等号两侧有空格

**现象：**

```bash
alias la = 'ls -la'
```

```
bash: alias: la: not found
bash: alias: =: not found
bash: alias: ls -la: not found
```

**原因：** `alias` 语法要求等号两侧**不能有空格**。`alias la='ls -la'` 是正确的；`alias la = 'ls -la'` 是错误的。

**解决方法：**

```bash
alias la='ls -la'
```

### 5.4 看到 `^C`、`^Z` 等待号显示在屏幕上

**现象：** 屏幕上了出现 `^C` 或 `^Z` 这样的字符，但没有触发预期操作。

**原因：**
- `^` 符号在终端中代表 `Ctrl` 键。`^C` 就是 `Ctrl+C`，以此类推。
- 出现这种情况通常是因为你在没有程序正在运行时按了 `Ctrl+C`，或者终端捕捉到了按键但没有程序来处理它。

**解决方法：** 这些只是屏幕显示，不影响操作。按 `Enter` 即可获得新的干净提示符。也可以用 `clear` 或 `Ctrl+L` 清屏。

### 5.5 误把 `Ctrl+C` 用于复制

**现象：** 终端中选中了一段文本，按 `Ctrl+C` 想复制，结果正在运行的程序被终止了。

**原因：** 在终端中，`Ctrl+C` 的历史含义是"中断进程"（最早可追溯到 20 世纪 70 年代的 Unix），远早于图形界面中"复制"的快捷键约定。终端保留了这一传统。

**解决方法：** 终端中复制文本请使用：
- `Ctrl + Shift + C`：复制
- `Ctrl + Shift + V`：粘贴
- 或者直接用鼠标选中文本（自动复制），然后右键粘贴或鼠标中键粘贴

### 5.6 `history` 显示的编号不连续

**现象：** 执行 `history` 后发现编号有跳号。

**原因：** 这是完全正常的。`history` 的编号是一个**永久递增计数器**，即使历史记录被清理（`history -c`）也不会重置编号。每条新命令占用一个新编号，旧编号不会复用。

**示例验证：**

```bash
history -c    # 清除历史
echo test1    # 编号 N
echo test2    # 编号 N+1
history 5     # 显示从 N 开始的两条记录，编号依然是大数字
```

## 6. 进阶延伸

### 6.1 Zsh 与 Fish —— 更现代的 Shell

Bash 功能强大但略显"古老"。如果你想让终端更美观、更智能，可以尝试以下替代品。

#### Zsh（Z Shell）

Zsh 是 Bash 的"超集"——绝大部分 Bash 命令和脚本在 Zsh 中可以直接运行。它最著名的特性是丰富的插件系统和可定制的提示符主题。

**在 Ubuntu 上安装 Zsh：**

```bash
sudo apt install zsh -y
```

**Oh My Zsh 框架（推荐）：**

Oh My Zsh 是 Zsh 的社区配置框架，提供了数百个插件和主题，只需一行命令即可安装：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

流行的 Zsh 特性包括：
- 自动补全更智能（如部分匹配、大小写不敏感）
- 命令语法高亮
- Git 分支状态显示在提示符中
- 大量现成主题（如 Powerlevel10k）

#### Fish（Friendly Interactive SHell）

Fish 的口号是"开箱即用"——无需 `.bashrc`、无需插件、无需配置，安装后直接拥有语法高亮、智能补全和历史建议。

**在 Ubuntu 上安装 Fish：**

```bash
sudo apt install fish -y
```

**启动 Fish：**

```bash
fish
```

**Fish 的独特功能：**
- 输入历史记录时自动弹出灰色建议（按 `→` 接受）
- 语法高亮——输入正确时显示为蓝色，错误时显示为红色
- 基于 man page 的自动补全描述
- 无需 `$` 前缀即可引用变量

**注意：** Fish 的脚本语法与 Bash 不兼容。如果你主要学习 Linux 管理系统和编写脚本，仍建议以 Bash 为地基。Fish 适合作为日常交互式终端使用。

### 6.2 自定义 Shell 提示符（PS1）

Bash 的提示符由 `PS1` 环境变量控制。你可以完全自定义它的外观。

查看当前 PS1 设置：

```bash
echo $PS1
```

输出形如：

```
\[\e]0;\u@\h: \w\a\]${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$
```

初学者不需要理解这个复杂的字符串。一个简单的自定义提示符示例：

```bash
PS1='\u@\h:\w\$ '
```

| 转义序列 | 含义 |
|----------|------|
| `\u` | 当前用户名 |
| `\h` | 主机名（短格式） |
| `\w` | 当前工作目录的完整路径 |
| `\W` | 当前工作目录的末尾目录名 |
| `\$` | 普通用户显示 `$`，root 用户显示 `#` |
| `\n` | 换行 |
| `\t` | 当前时间（24 小时制，HH:MM:SS） |
| `\d` | 当前日期（"星期 月 日"格式） |

带颜色和时间戳的提示符示例：

```bash
PS1='\[\033[0;33m\]\t\[\033[0m\] \[\033[0;32m\]\u@\h\[\033[0m\]:\[\033[0;34m\]\w\[\033[0m\]\$ '
```

这会在提示符的最前面加上黄色的时间戳。要使这个修改永久生效，将 `PS1=...` 写入 `~/.bashrc` 末尾。

### 6.3 用 `script` 命令录制终端会话

当你需要向他人演示或记录自己的操作过程时，`script` 命令可以将整个终端会话录制到文件中。

**开始录制：**

```bash
script my-session.log
```

之后你的所有输入和输出都会被记录。结束时输入 `exit` 或按 `Ctrl+D`。

**查看录制内容：**

```bash
cat my-session.log
```

| 参数 | 说明 | 必选/可选 | 默认值 |
|------|------|----------|--------|
| `filename` | 录制输出的文件名 | 可选 | `typescript` |
| `-a` | 追加模式，追加到已有文件末尾而不是覆盖 | 可选 | 否 |
| `-q` | 安静模式，不显示开始和结束提示 | 可选 | 否 |
| `--timing=file` | 同时记录每条命令的时间戳，可用于 `scriptreplay` 回放 | 可选 | 无 |

**录制并回放示例：**

```bash
# 录制（含时间戳）
script --timing=timing.log session.log
# 执行一些命令...
ls
echo "Hello Terminal Recording"
# 停止录制
exit

# 回放录制
scriptreplay --timing=timing.log session.log
```

### 6.4 `.bashrc` 中可以配置的更多内容

除了别名，你还可以在 `~/.bashrc` 中配置许多有用的设置。

**历史记录设置：**

```bash
# 历史记录文件
export HISTFILE="$HOME/.bash_history"
# 历史文件最大行数
export HISTFILESIZE=2000
# 内存中保存的历史记录条数
export HISTSIZE=1000
# 不记录重复命令
export HISTCONTROL=ignoredups:erasedups
# 不记录以空格开头的命令
export HISTCONTROL=ignorespace
```

**实用的别名合集：**

```bash
# 安全操作（覆盖前确认）
alias cp='cp -i'
alias mv='mv -i'
alias rm='rm -i'

# 让 ls 更直观
alias ls='ls --color=auto'
alias ll='ls -alF'
alias la='ls -A'

# 让 grep 高亮匹配内容
alias grep='grep --color=auto'

# 快速进入常用目录
alias docs='cd ~/Documents'
alias desk='cd ~/Desktop'

# 查看公网 IP
alias myip='curl -s ifconfig.me'
```

### 6.5 终端多路复用器 —— tmux

当你需要在一个终端窗口中同时管理多个 Shell 会话时，终端多路复用器（Terminal Multiplexer）是非常强大的工具。

**安装 tmux：**

```bash
sudo apt install tmux -y
```

**基本用法：**

| 操作 | 快捷键 / 命令 |
|------|--------------|
| 启动 tmux | `tmux` |
| 水平分割窗口 | `Ctrl+B` 然后按 `"`（双引号） |
| 垂直分割窗口 | `Ctrl+B` 然后按 `%`（百分号） |
| 在窗格之间切换 | `Ctrl+B` 然后按方向键 |
| 新建窗口 | `Ctrl+B` 然后按 `c` |
| 切换窗口 | `Ctrl+B` 然后按 `n`（下一个）或 `p`（上一个） |
| 断开会话（Detach） | `Ctrl+B` 然后按 `d` |
| 重新连接会话 | `tmux attach` |
| 退出并关闭 | `exit` 或在 tmux 中按 `Ctrl+D` |

**典型使用场景：** 通过 SSH 连接到远程服务器编译大项目时，启动 tmux 后即使网络断开（SSH 连接中断），tmux 中的编译任务仍在继续运行。重新连接后执行 `tmux attach` 即可回到之前的会话。
