# 附录：命令速查表

> 本文档为 Ubuntu Linux 全栈课程（42 章）中涉及的全部命令的快速参考。按类别分组，每条命令给出最常用参数和一句话说明。
>
> **适用版本：** Ubuntu 24.04 LTS (Noble Numbat)，Bash 5.x

---

## 1. 文件操作

| 命令 | 常用参数 | 说明 |
|------|---------|------|
| `ls` | `-l` 长格式, `-a` 含隐藏文件, `-h` 人类可读大小, `-t` 按时间排序, `-r` 逆序, `-R` 递归, `-S` 按大小排序, `-i` 显示 inode, `-d` 只看目录本身, `--color=auto` | 列出目录内容 |
| `tree` | `-L N` 限制深度, `-d` 仅目录, `-a` 含隐藏, `-h` 人类可读, `-f` 全路径 | 树形显示目录结构 |
| `pwd` | `-P` 物理路径（无符号链接）, `-L` 逻辑路径（默认） | 打印当前工作目录 |
| `cd` | `-` 回到上一个目录, `~` 家目录, `..` 上级目录 | 切换工作目录 |
| `stat` | `-c FORMAT` 自定义输出, `-f` 文件系统信息 | 显示文件/文件系统详细状态 |
| `file` | `-i` MIME 类型, `-b` 简洁输出, `-z` 穿透压缩文件 | 识别文件类型 |
| `readlink` | `-f` 递归解析所有符号链接到最终真实路径, `-e` 同 -f 但要求存在 | 读取符号链接指向的目标 |
| `realpath` | `-s` 不解析符号链接, `-m` 允许路径缺失 | 将路径转换为绝对路径 |
| `du` | `-h` 人类可读, `-s` 汇总总计, `-d N` 或 `--max-depth=N` 限制深度, `-a` 含文件, `--time` | 估算文件/目录占用磁盘空间 |
| `df` | `-h` 人类可读, `-i` inode 使用, `-T` 显示文件系统类型, `-t TYPE` 过滤 | 报告文件系统磁盘空间使用 |
| `mkdir` | `-p` 递归创建父目录, `-v` 显示过程, `-m MODE` 指定权限 | 创建目录 |
| `rmdir` | `-p` 递归删除空目录链, `--ignore-fail-on-non-empty` | 删除空目录 |
| `touch` | `-a` 仅改访问时间, `-m` 仅改修改时间, `-t STAMP` 指定时间, `-r REF` 参照文件 | 创建空文件或更新时间戳 |
| `cp` | `-r` 递归复制目录, `-i` 覆盖前询问, `-u` 仅更新较新文件, `-v` 显示过程, `-p` 保留属性, `-a` 归档模式（等于 -dR --preserve=all） | 复制文件和目录 |
| `mv` | `-i` 覆盖前询问, `-u` 仅更新较新, `-v` 显示过程, `-n` 不覆盖已存在文件 | 移动/重命名文件和目录 |
| `rm` | `-r` 递归删除目录, `-f` 强制不提示, `-i` 逐一确认, `-v` 显示过程 | 删除文件或目录 |
| `ln` | `-s` 创建符号链接, `-f` 强制覆盖, `-n` 不跟随目标为链接的目录, `-T` 总视为文件 | 创建硬链接或符号链接 |
| `rename` | `'s/旧/新/'` Perl 正则替换, `-n` 预览不执行, `-v` 显示重命名 | 批量重命名文件 |
| `basename` | `-a` 多参数, `-s SUFFIX` 去除后缀 | 提取路径中的文件名部分 |
| `dirname` | — | 提取路径中的目录部分 |
| `mktemp` | `-d` 创建临时目录, `-p DIR` 指定目录, `-t` 模板 | 安全创建临时文件/目录 |
| `find` | `-name` 按名称, `-iname` 忽略大小写, `-type f/d/l` 按类型, `-size [+/-]N` 按大小, `-mtime [+/-]N` 修改天数, `-mmin N` 修改分钟数, `-perm MODE` 按权限, `-user USER` 按所有者, `-exec CMD {} \;` 对每个结果执行命令, `-exec CMD {} +` 批量执行, `-delete` 删除, `-prune` 跳过目录, `-maxdepth N` 限制深度, `-print0` null 分隔输出, `-o` 或, `-not` 非 | 在目录树中搜索文件 |
| `locate` | `-i` 忽略大小写, `-c` 仅计数, `-l N` 限制结果数, `-r REGEX` 正则, `-b` 仅匹配文件名 | 从预建数据库中快速按名搜索文件 |
| `updatedb` | `-o FILE` 指定数据库, `-U DIR` 仅扫描指定目录 | 更新 locate 数据库（通常由 cron 每日执行） |
| `which` | `-a` 显示所有匹配, `-s` 静默（仅返回码） | 在 PATH 中查找可执行文件位置 |
| `whereis` | `-b` 仅二进制, `-m` 仅手册, `-s` 仅源码, `-B/M/S DIRS` 指定搜索目录 | 查找命令的二进制、手册和源码文件位置 |
| `type` | `-a` 所有匹配, `-t` 仅类型 (alias/builtin/file), `-p` 仅路径 | Bash 内置 — 判断命令的真实身份（别名/内建/函数/外部） |

### 1.1 压缩与归档

| 命令 | 常用参数 | 说明 |
|------|---------|------|
| `tar` | `-c` 创建, `-x` 解压, `-t` 列出内容, `-f FILE` 指定归档文件, `-v` 详细, `-z` gzip 压缩, `-j` bzip2 压缩, `-J` xz 压缩, `--zstd` zstd 压缩, `-C DIR` 切换目录, `--exclude=PATTERN`, `--strip-components=N` | 归档工具 — 创建、解压和列出 tar 包 |
| `gzip` / `gunzip` | `-1..9` 压缩级别（默认 6）, `-c` 输出到 stdout, `-d` 解压, `-k` 保留原文件, `-l` 列出信息, `-t` 测试完整性 | GNU zip 压缩/解压（DEFLATE 算法） |
| `bzip2` / `bunzip2` | 同 gzip 参数体系 | bzip2 压缩/解压（压缩率更高，速度较慢） |
| `xz` / `unxz` | `-0..9` 压缩级别, `-T N` 线程数（0=自动）, `-e` 极限模式, `-k` 保留原文件 | xz 压缩/解压（LZMA2 算法，最高压缩率） |
| `zstd` / `unzstd` | `-1..19` 压缩级别（默认 3）, `--ultra` 级别 20-22, `-T N` 线程, `--fast` 快速模式 | Zstandard 压缩/解压（极速，现代首选） |
| `zip` / `unzip` | `-r` 递归, `-e` 加密, `-P PASS` 密码, `-s SIZE` 分割, `-q` 安静; `-d DIR` 解压到指定目录 | Info-ZIP 压缩/解压（跨平台兼容） |
| `7z` / `7za` | `a` 添加, `x` 解压（含路径）, `e` 解压（扁平）, `l` 列出, `-mx=N` 压缩级别, `-pPASS` 加密, `-mhe=on` 加密文件头, `-vSIZE` 分卷 | 7-Zip 压缩/解压（最高压缩率，AES-256 加密） |
| `zcat` / `zless` / `zgrep` | 同 cat/less/grep 参数 | 无需手动解压，直接查看/搜索 .gz 压缩文件 |

## 3. 进程管理

| 命令 | 常用参数 | 说明 |
|------|---------|------|
| `ps` | `aux` BSD 风格所有进程, `-ef` Unix 风格全格式, `-eo PID,CMD,%CPU,%MEM` 自定义列, `--sort=-%mem` 按内存排序, `-C CMD` 按命令名过滤, `-p PID` 按 PID | 查看当前进程快照 |

| `kill` | `-l` 列出所有信号, `-9` 或 `-KILL` 强制杀死, `-15` 或 `-TERM` 优雅终止, `-HUP` 挂起重读配置, `-STOP` 暂停, `-CONT` 继续 | 向进程发送信号 |

| `nice` | `-n N` 设置 nice 值（-20 最高优先级~19 最低）, 默认 +10 | 以调整后的优先级启动进程 |
| `renice` | `-n N` 新的 nice 值, `-p PID`, `-u USER`, `-g PGID` | 修改运行中进程的优先级 |
| `nohup` | 默认输出重定向到 `nohup.out` | 使进程忽略挂起信号（SIGHUP），离开终端后继续运行 |
| `disown` | `-h` 标记作业不受 SIGHUP, `-a` 所有作业, `-r` 仅运行中的作业 | 从 Shell 作业列表中移除作业 |
| `jobs` | `-l` 含 PID, `-p` 仅 PID, `-r` 仅运行中, `-s` 仅已停止 | 列出当前 Shell 的后台作业 |
| `fg` | `%N` 作业号, `%STRING` 按名称 | 将后台作业调到前台 |
| `bg` | `%N` 作业号, `%STRING` 按名称 | 恢复已停止的作业在后台运行 |
| `wait` | `PID` 等待特定进程, `-n` 等待任意一个完成 | 等待子进程结束并返回其退出码 |
| `times` | — | 显示当前 Shell 及其子进程的累计用户/系统时间 |
| `&` | 命令末尾加 `&` | 在后台启动进程 |
| `Ctrl+Z` | — | 挂起（暂停）当前前台进程 |
| `Ctrl+C` | — | 中断（发送 SIGINT）当前前台进程 |
| `timeout` | `-s SIGNAL` 指定信号（默认 TERM）, `-k DURATION` 二次强杀延迟 | 在指定时间后终止命令 |
| `stty` | `-a` 显示所有终端设置, `sane` 恢复终端, `intr/quit/susp CHAR` 设置信号键, `raw/-raw` 切换原始/规范模式, `echo/-echo` 开关回显 | 查看和修改终端行规程设置 |
| `pstree` | `-p` 显示 PID, `-u` 显示用户, `-a` 显示完整命令行, `-h` 高亮当前进程, `-s PID` 显示指定进程的父链 | 以树形结构显示进程父子关系 |
| `watch` | `-n SEC` 刷新间隔（默认 2s）, `-d` 高亮变化部分, `-t` 不显示标题 | 周期性执行命令并全屏显示输出 |
| `lsof` | `-i` 按网络连接, `-i :PORT` 按端口, `-p PID` 按进程, `-u USER` 按用户, `-c CMD` 按命令, `+D DIR` 按目录 | 列出打开的文件（一切皆文件） |

| `ss` | `-t` TCP, `-u` UDP, `-l` 监听, `-p` 进程信息, `-n` 不解析名称, `-a` 所有, `-s` 统计摘要, `-4/-6` IPv4/IPv6 | 探索套接字统计信息（替代 netstat） |
| `netstat` | `-t` TCP, `-u` UDP, `-l` 监听, `-p` 进程, `-n` 不解析, `-r` 路由表, `-i` 接口统计 | 网络连接、路由表、接口统计（已被 ss/ip 取代） |
