## 1. 概述

### 1.1 什么是 Ubuntu Linux

Ubuntu 是目前世界上最流行的 Linux 发行版（Linux Distribution，简称 Distro）之一，由 Canonical 公司主导开发。它的名字来源于非洲祖鲁语，意为"对他人的仁慈"（humanity to others）。Ubuntu 每两年发布一个长期支持版本（Long Term Support，简称 LTS），LTS 版本提供长达 5 年（付费可达 10 年）的安全更新和技术支持。本书使用的 Ubuntu 24.04 LTS（代号 Noble Numbat）于 2024 年 4 月发布，是目前最新的 LTS 版本。

### 1.2 为什么在虚拟机中学习 Linux

对于初学者而言，直接在物理机上安装 Linux 存在一定风险——操作失误可能导致硬盘数据丢失或 Windows 系统无法启动。虚拟机（Virtual Machine，简称 VM）软件可以在你现有的 Windows 系统中"模拟"出一台完整的计算机，让你在不影响宿主机（Host Machine）的前提下，自由地安装、使用甚至"折腾" Ubuntu。即使虚拟机里的系统崩溃了，也只需删除重建，完全不会影响你的 Windows。

### 1.3 本章学习目标

完成本章后，你将能够：

- 独立下载并安装 VMware Workstation
- 下载 Ubuntu 24.04 LTS 的 ISO 镜像文件
- 创建一台配置合理的 Ubuntu 虚拟机
- 完成 Ubuntu 的完整安装流程
- 安装 VMware Tools / open-vm-tools 以优化虚拟机体验
- 使用快照（Snapshot）功能保存和恢复系统状态

## 2. 核心概念

### 2.1 虚拟机（Virtual Machine）

虚拟机是一台由软件模拟出来的"假"计算机。它运行在宿主机内部，拥有自己的虚拟 CPU、内存、硬盘和网络接口。虚拟机内部的操作系统称为"客户机操作系统"（Guest OS），它和宿主机操作系统相互隔离。常见的虚拟机软件包括 VMware Workstation、VirtualBox 和 Hyper-V。

**比喻理解：** 如果把你的 Windows 电脑比作一栋大楼，虚拟机就像大楼里用墙隔出来的一个独立办公室。办公室里的一切活动（安装软件、修改配置、甚至砸坏东西）都不影响大楼的其他部分。

### 2.2 VMware Workstation

VMware Workstation 是 VMware 公司出品的一款商业虚拟机软件，以稳定性和性能优异著称。对于个人学习用途，VMware 提供免费的 VMware Workstation Player（功能精简版）和 30 天试用的 VMware Workstation Pro（功能完整版）。本书以 VMware Workstation Pro 17 为例进行讲解，但大部分操作在 Player 版本中同样适用。

### 2.3 ISO 镜像文件

ISO 文件（ISO Image）是一种光盘映像文件格式，它将整张光盘（CD、DVD 或蓝光）的内容打包成一个独立的 `.iso` 文件。Ubuntu 安装镜像就是以 ISO 格式发布的。在虚拟机中安装系统时，我们直接把 ISO 文件"挂载"到虚拟机的虚拟光驱上，虚拟机就会像从光盘启动一样开始安装流程。

### 2.4 快照（Snapshot）

快照是虚拟机软件提供的一项强大功能。它能够在某个时刻记录下虚拟机的完整状态——包括内存数据、磁盘内容、CPU 寄存器等。创建快照后，无论你在虚拟机里做了什么操作（安装软件、删除文件、修改配置），都可以随时"还原"到快照创建时的状态。

**比喻理解：** 快照就像游戏中的"存档点"。在尝试危险操作之前存个档，搞砸了就读档重来。这在学习 Linux 时特别有用——你可以在安装一个不熟悉的软件包之前拍一个快照，出了问题一键恢复。

### 2.5 Linux 发行版（Linux Distribution）

Linux 严格来说只是一个操作系统内核（Kernel），而不是一个完整的操作系统。一个"Linux 发行版"是将 Linux 内核与 GNU 工具集、包管理器、桌面环境等软件打包在一起，形成的可供安装使用的完整操作系统。常见的发行版包括 Ubuntu、Debian、Fedora、Arch Linux、CentOS 等。不同发行版的区别主要在于：包管理方式（软件安装方式）、桌面环境、软件版本策略（激进更新 vs 稳定保守）以及社区文化。

## 3. 命令详解

> **说明：** 本章聚焦于图形化安装过程，涉及的命令较少。以下命令是安装成功后在终端中需要执行的关键步骤。请在你的虚拟机中逐个运行它们。

### 3.1 系统更新命令

安装完成后，第一件事就是更新系统软件包列表并升级所有可更新的软件包。

```bash
sudo apt update
```

```bash
sudo apt upgrade -y
```

**命令拆解：**

| 组成部分 | 含义 |
|----------|------|
| `sudo` | 以超级用户（Superuser）权限执行命令。类似于 Windows 中的"以管理员身份运行" |
| `apt` | Ubuntu 的包管理器（Advanced Package Tool），负责安装、更新、删除软件 |
| `update` | 从软件源服务器获取最新的软件包列表（但不实际安装任何软件） |
| `upgrade` | 根据最新的软件包列表，升级系统中已安装的所有可更新软件包 |
| `-y` | 自动对"是否继续？"的提示回答"是"（yes），省去手动确认 |

**运行截图描述：** 执行 `sudo apt update` 后，终端会逐行输出"Hit"（命中缓存）、"Get"（正在下载）等字样，最后显示"N packages can be upgraded."。执行 `sudo apt upgrade -y` 后，你会看到进度条逐步推进，最后显示升级完成。

### 3.2 安装 open-vm-tools

open-vm-tools 是 VMware Tools 的开源版本，安装后可以实现宿主机与虚拟机之间的剪贴板共享、文件拖拽、自适应分辨率调整等功能。

```bash
sudo apt install open-vm-tools-desktop -y
```

**参数说明：**

| 参数 | 是否必需 | 默认值 | 说明 |
|------|----------|--------|------|
| `open-vm-tools-desktop` | 必需 | 无 | 要安装的软件包名称。`-desktop` 后缀表示包含桌面环境所需的所有组件 |
| `-y` | 可选 | 否 | 自动确认安装，跳过交互式确认 |

**运行截图描述：** 执行后终端会列出将要安装的软件包及其依赖，包的总数量和下载大小。安装完成后命令行提示符重新出现，没有报错信息即表示安装成功。

### 3.3 重启系统

安装 open-vm-tools 后需要重启以使其生效。

```bash
sudo reboot
```

**运行截图描述：** 执行后虚拟机会自动重启。你会看到 Ubuntu 的关机动画，约 10-30 秒后重新出现登录界面。

### 3.4 VMware 快照命令行（在宿主机 PowerShell 中运行）

如果你使用的是 VMware Workstation Pro，可以通过命令行管理快照。以下命令在 Windows 宿主机上的 PowerShell 或命令提示符中运行（需要将 VMware 安装路径加入系统 PATH 环境变量，或使用完整路径）。

> **注意：** 这些命令是可选内容，初学者可以用图形界面操作快照，无需记忆这些命令。

创建快照：

```powershell
& "C:\Program Files (x86)\VMware\VMware Workstation\vmrun.exe" snapshot "C:\Users\你的用户名\Documents\Virtual Machines\Ubuntu24.04\Ubuntu24.04.vmx" "快照名称"
```

还原快照：

```powershell
& "C:\Program Files (x86)\VMware\VMware Workstation\vmrun.exe" revertToSnapshot "C:\Users\你的用户名\Documents\Virtual Machines\Ubuntu24.04\Ubuntu24.04.vmx" "快照名称"
```

列出所有快照：

```powershell
& "C:\Program Files (x86)\VMware\VMware Workstation\vmrun.exe" listSnapshots "C:\Users\你的用户名\Documents\Virtual Machines\Ubuntu24.04\Ubuntu24.04.vmx"
```

## 4. 安装步骤详解

本章的核心内容是用 VMware Workstation 安装 Ubuntu 24.04 LTS 的完整操作流程。请按顺序逐步操作。

### 4.1 下载 VMware Workstation

**步骤 1：** 打开浏览器，访问 VMware 官方网站：
```
https://www.vmware.com/products/workstation-pro.html
```

**截图描述：** 页面顶部有"VMware Workstation Pro"的大标题和"Download"按钮。页面上会展示产品的核心特性，包括支持 Windows 和 Linux 宿主机、虚拟网络配置、快照管理等。

**步骤 2：** 点击"Download"按钮（或"Download Now"、"Try Workstation Pro"等字样），进入下载页面。根据你的 Windows 版本选择对应的安装包（通常选择"VMware Workstation Pro for Windows"）。文件大小约 500 MB，请耐心等待下载完成。

**截图描述：** 下载页面会列出不同操作系统平台的安装包，Windows 版本通常排在最前面。旁边显示文件大小和版本号（如 17.5.x）。

**步骤 3（备用方案）：** 如果你不需要 Workstation Pro 的高级功能（如快照命令行工具、虚拟网络编辑器等），可以下载免费的 VMware Workstation Player：
```
https://www.vmware.com/products/workstation-player.html
```

Player 版本对于学习 Linux 已经完全够用。两版的安装步骤基本相同。

### 4.2 安装 VMware Workstation

**步骤 1：** 双击下载的 `.exe` 安装程序，如果出现"用户账户控制"（UAC）提示，点击"是"。

**截图描述：** 弹出 Windows 用户账户控制窗口，标题为"你要允许此应用对你的设备进行更改吗？"，显示发布者为"VMware, Inc."。点击"是"继续。

**步骤 2：** 安装向导启动后，点击"Next"继续。

**截图描述：** VMware Workstation Pro 安装向导的欢迎页面。蓝色背景，显示产品图标和版本号。底部有"Next >"和"Cancel"按钮。

**步骤 3：** 阅读并接受许可协议（勾选"I accept the terms in the License Agreement"），点击"Next"。

**截图描述：** 页面显示 VMware 最终用户许可协议（EULA）的全文。左侧有滚动条可向下阅读。底部是"I accept the terms..."单选按钮和"I do not accept..."单选按钮。

**步骤 4：** 选择安装路径。建议使用默认路径（`C:\Program Files (x86)\VMware\VMware Workstation\`），除非 C 盘空间紧张。点击"Next"。

**截图描述：** 页面显示"Destination Folder"，有一个文本输入框显示默认安装路径，旁边有"Change..."按钮用于修改路径。

**步骤 5：** 配置用户体验设置。建议两个复选框都勾选：
- "Check for product updates on startup"（启动时检查产品更新）
- "Join the VMware Customer Experience Improvement Program"（加入用户体验改进计划——可选）

点击"Next"。

**截图描述：** 页面标题为"User Experience Settings"，下方有两个复选框，分别对应更新检查和改进计划。

**步骤 6：** 选择快捷方式创建位置。默认勾选桌面和开始菜单，可以保持不变。点击"Next"。

**截图描述：** "Shortcuts"页面，列出"Desktop"和"Start Menu Programs Folder"两个复选框，均已勾选。

**步骤 7：** 确认安装设置，点击"Install"开始安装。

**截图描述：** "Ready to Install"页面，列出前面所有选择的摘要：安装路径、快捷方式等。点击"Install"按钮。

**步骤 8：** 等待安装进度条完成。这个过程可能需要 3-5 分钟。

**截图描述：** 页面显示绿色进度条，上方有"Installing..."字样。进度条下方显示正在安装的组件名称。

**步骤 9：** 安装完成后，点击"Finish"。如果页面提示需要重启计算机，请保存当前工作后重启。

**截图描述：** "Installation Complete"页面，显示"VMware Workstation Pro has been successfully installed."字样。底部有"Finish"按钮。

### 4.3 下载 Ubuntu 24.04 LTS ISO 镜像

**步骤 1：** 打开浏览器，访问 Ubuntu 官方网站：
```
https://ubuntu.com/download/desktop
```

**截图描述：** Ubuntu 官网下载页面，以橙色和深色为主色调。页面中间有 Ubuntu 24.04 LTS 的大标题和"Download"按钮。旁边展示版本号"Noble Numbat"和 LTS 标识。

**步骤 2：** 点击绿色的"Download 24.04 LTS"按钮开始下载。ISO 文件大小约 5.7 GB，下载时间取决于你的网络速度。

**截图描述：** 浏览器底部出现下载提示，显示文件名（`ubuntu-24.04-desktop-amd64.iso`）、文件大小和预计剩余时间。

**步骤 3（备用方案）：** 如果官网下载速度较慢，可以尝试国内镜像源（Mirror Site），例如：
- 清华大学开源软件镜像站：`https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/24.04/`
- 阿里云开源镜像站：`https://mirrors.aliyun.com/ubuntu-releases/24.04/`

在镜像站中找到 `ubuntu-24.04-desktop-amd64.iso` 文件下载即可。

### 4.4 创建 Ubuntu 虚拟机

**步骤 1：** 启动 VMware Workstation。在桌面上双击 VMware Workstation 图标，或从开始菜单启动。

**截图描述：** VMware Workstation 主界面。顶部是菜单栏（File、Edit、View、VM、Tabs、Help）。主区域中央有一个"Create a New Virtual Machine"大按钮，右侧面板显示"Open a Virtual Machine"等选项。

**步骤 2：** 点击"Create a New Virtual Machine"按钮，或通过菜单 File > New Virtual Machine 创建新虚拟机。选择"Typical (recommended)"安装类型，点击"Next"。

**截图描述：** "New Virtual Machine Wizard"对话框。两个选项："Typical (recommended)"（典型推荐）和"Custom (advanced)"（自定义高级）。Typical 选项被默认选中。

**步骤 3：** 选择"Installer disc image file (iso)"，点击"Browse..."按钮，找到你下载的 `ubuntu-24.04-desktop-amd64.iso` 文件并选中。VMware 会自动检测到操作系统类型为"Ubuntu 64-bit"。点击"Next"。

**截图描述：** 文件选择对话框中，你定位到 ISO 文件所在的下载目录，选中文件后点击"打开"。回到向导页面后，ISO 路径显示在文本框中，下方显示"Ubuntu 64-bit detected"。

**步骤 4：** 设置虚拟机名称和存储位置。建议：
- **虚拟机名称（Virtual machine name）：** `Ubuntu 24.04`
- **存储位置（Location）：** 选择一个剩余空间 > 50 GB 的磁盘分区（推荐 D 盘或其他非系统盘）

点击"Next"。

**截图描述：** 页面有两个输入框。上面是虚拟机名称，下面是通过"Browse..."选择的存储路径。路径默认指向 C 盘"我的文档"下的 Virtual Machines 文件夹。

**步骤 5：** 设置虚拟磁盘容量。建议配置：
- **最大磁盘大小（Maximum disk size）：** 30 GB（如果你有充足的硬盘空间，可以设置为 40-50 GB）
- **存储方式：** 选择"Store virtual disk as a single file"（将虚拟磁盘存储为单个文件）。如果你希望虚拟机文件便于迁移拷贝，也可以选择"Split virtual disk into multiple files"（拆分为多个文件）

点击"Next"。

**截图描述：** 页面显示磁盘容量滑块和一个数值输入框（默认 20 GB）。下方有两个单选按钮对应两种存储方式。右侧面板显示配置摘要。

**步骤 6：** 在最终确认页面点击"Customize Hardware..."按钮，对虚拟机硬件进行优化调整。

**截图描述：** "Ready to Create Virtual Machine"页面，列出虚拟机名称、位置、操作系统类型、磁盘大小等摘要信息。下方有"Customize Hardware..."和"Back"、"Finish"、"Cancel"按钮。

**步骤 7：** 在硬件自定义对话框中，根据你的物理机配置进行以下调整：

| 硬件 | 推荐设置 | 说明 |
|------|----------|------|
| **Memory (内存)** | 4 GB（4096 MB） | 如果你的物理机有 16 GB 及以上内存，可设置为 8 GB。最少不低于 2 GB |
| **Processors (处理器)** | 2 个核心 | 如果你的物理 CPU 核心数较多（6 核及以上），可分配 4 核。但不要超过物理机总核心数的一半 |
| **Network Adapter (网络适配器)** | NAT | NAT 模式让虚拟机通过宿主机的 IP 地址访问网络，是最简单的联网方式 |
| **USB Controller** | USB 3.1 | 默认即可 |
| **Sound Card** | 自动检测 | 默认即可 |
| **Printer** | 可移除 | 一般不需要，移除可节省资源 |
| **Display** | 不勾选"Accelerate 3D graphics" | 学习用途不需要 3D 加速，保持默认 |

调整完成后点击"Close"，然后点击"Finish"创建虚拟机。

**截图描述：** "Hardware"对话框，左侧列出所有硬件设备（Memory、Processors、Hard Disk、CD/DVD、Network Adapter、USB Controller、Sound Card、Printer、Display）。右侧是当前选中设备的详细设置面板。内存面板有一个滑块和数值显示（单位 MB）。处理器面板有"Number of processors"和"Number of cores per processor"两个下拉选择框。

### 4.5 安装 Ubuntu 操作系统

虚拟机创建完成后，就可以启动它并开始安装 Ubuntu 了。

**步骤 1：** 在 VMware Workstation 主界面，选中你新建的虚拟机，点击"Power on this virtual machine"（或点击绿色三角形播放按钮）。

**截图描述：** 虚拟机启动后，屏幕先短暂显示 VMware Logo，然后出现 GNU GRUB 引导菜单。黑色背景上显示白色和蓝色文字，第一个选项是"Try or Install Ubuntu"，已被默认高亮选中。底部有倒计时提示。

**步骤 2：** 等待几秒（或者直接按 Enter 键），系统进入 Ubuntu 安装界面。左侧是语言列表，默认选中"English"。上下滚动找到"中文（简体）"，点击选中它。

**重要提醒：** 建议你选择"中文（简体）"作为安装语言，这样安装后的系统界面默认为中文。但本书后续章节的所有命令和输出示例仍然以英文界面为准（因为 Linux 终端的输出默认为英文），这一点请知悉。

**截图描述：** 安装向导左侧面板列出数十种语言（按字母排序），"中文（简体）"大约在列表中间偏下的位置。右侧面板显示"欢迎"字样和两个按钮："试用 Ubuntu"和"安装 Ubuntu"。

**步骤 3：** 点击右侧的"安装 Ubuntu"按钮，进入键盘布局选择页面。保持默认的"Chinese"即可，点击"继续"。

**截图描述：** 左侧面板按语言分组列出键盘布局选项。右侧有两个输入框，下方有一个文本框提示您可以在此处输入文字以测试布局。

**步骤 4：** 在"更新和其他软件"页面，选择安装类型：
- **正常安装（Normal installation）：** Web 浏览器、工具、办公软件、游戏和媒体播放器。推荐选择此项。
- **最小安装（Minimal installation）：** 仅 Web 浏览器和基本工具。适合磁盘空间紧张的情况。

另外两个复选框：
- **"安装 Ubuntu 时下载更新"（Download updates while installing Ubuntu）：** 强烈建议勾选，可以省去安装后手动更新的步骤。
- **"为图形和无线硬件安装第三方软件"（Install third-party software for graphics and Wi-Fi hardware）：** 建议勾选，可以自动安装显卡驱动和 Wi-Fi 驱动。

点击"继续"。

**步骤 5：** 在"安装类型"页面，选择"清除整个磁盘并安装 Ubuntu"（Erase disk and install Ubuntu）。由于我们是在虚拟机中安装，这里的"磁盘"指的是虚拟磁盘，不会影响你的物理硬盘数据。点击"现在安装"（Install Now）。

**截图描述：** 页面标题为"安装类型"。上面的大区域显示"这台计算机目前没有检测到操作系统。您想怎么做？"（因为是新建的空白虚拟磁盘）。下方有几个选项："清除整个磁盘并安装 Ubuntu"、"交互式分区"、"手动分区"。

**步骤 6：** 系统弹出确认对话框，内容是"将以下变更写入磁盘？"并列出将要执行的分区操作。点击"继续"确认。

**截图描述：** 页面显示一张世界地图，地图上标有城市点。上海时间用红点高亮显示。下方文本框显示"Shanghai (China)"。右侧显示时区信息"Asia/Shanghai"。

- **您的姓名（Your name）：** 输入你的名字（可以是中文，如"张三"）
- **计算机名（Your computer's name）：** 保持自动生成的即可（如"zhangsan-Virtual-Machine"），也可以自定义

- **密码（Choose a password）：** 设置一个你容易记住但不易被猜到的密码。**务必牢记此密码**，后续操作会频繁使用
- **确认密码（Confirm your password）：** 再输入一遍

登录方式建议选择"自动登录"（Log in automatically），这样可以省去每次开机输入密码的步骤（学习用途）。如果你担心安全问题，可以选择"登录时需要密码"（Require my password to log in）。

点击"继续"。

**截图描述：** 页面顶部标题为"您是谁？"。从上到下依次排列：姓名输入框、计算机名输入框、用户名输入框、密码输入框、确认密码输入框。下方有两个单选按钮对应登录方式。最下面是"继续"按钮。

**步骤 9：** 现在是等待时间！Ubuntu 开始安装，进度条缓慢前进。安装过程通常需要 10-20 分钟，具体取决于你的电脑性能。在此期间，你可以浏览安装界面中循环展示的 Ubuntu 功能介绍。

**截图描述：** 安装界面上方显示一个大进度条，下方是一个不断切换的轮播展示区，逐个介绍 Ubuntu 的功能：文件管理器、LibreOffice 办公套件、Ubuntu Software 应用商店、Firefox 浏览器等。每个画面都配有说明文字。

**步骤 10：** 安装完成后，系统弹出对话框提示"安装完毕，您需要重新启动计算机以使用新安装的系统"。点击"现在重启"（Restart Now）。

**截图描述：** 弹出对话框，标题为"安装完毕"。内容提示重启。底部有"现在重启"按钮。

### 4.6 首次启动与初始配置

**步骤 1：** 系统重启后，如果选择了"自动登录"，会直接进入 Ubuntu 桌面；如果选择了"需要密码"，则先输入密码登录。

**截图描述：** Ubuntu 24.04 的登录界面（GDM）。屏幕正中显示你设置的用户名，下方是密码输入框。输入框右侧有一个眼睛图标（点击可查看密码）。右下角有电源和设置图标。

**步骤 2：** 进入桌面后，你可能会看到一个"在线账户"（Online Accounts）引导对话框，提示连接 Google、Microsoft 等账户。这些不是必需的，可以点击右上角的"跳过"（Skip）按钮，或直接关闭窗口。

**截图描述：** 首次启动的欢迎引导界面，标题为"在线账户"。列出 Google、Microsoft、Nextcloud 等选项，每个旁边有"连接"按钮。右上角有"跳过"按钮。

**截图描述：** Ubuntu Pro 介绍页面，说明 Ubuntu Pro 提供的服务（10 年安全维护、合规工具等）。有"启用 Ubuntu Pro"和"跳过"两个选项。

**步骤 4：** 最后可能出现"帮助改进 Ubuntu"页面，询问是否愿意发送匿名的系统使用数据。选择你偏好的选项，点击"下一步"或"完成"。

**截图描述：** 页面标题为"帮助改进 Ubuntu"，有一个复选框问是否发送技术数据给 Canonical。底部有"下一步"按钮。

**步骤 5：** 恭喜！你现在看到了 Ubuntu 24.04 LTS 的完整桌面。桌面左侧是 Dock（任务栏），顶部有一条面板栏。默认壁纸是"Noble Numbat"——一只可爱的袋食蚁兽（这是 Ubuntu 24.04 的吉祥物）。

### 4.7 安装后更新

首次进入桌面后，建议立即更新系统。虽然安装时可能已经下载了更新，但安装完成后可能又有新的更新发布。

**步骤 1：** 按下键盘上的 `Ctrl + Alt + T` 组合键打开终端（Terminal）。这是一种类似 Windows 命令提示符的工具，后续章节会对它做深入介绍。

**截图描述：** 弹出一个深紫色背景的窗口，标题为"终端"或"Terminal"。窗口内显示一行提示符，形如 `用户名@计算机名:~$`，后面是闪烁的光标。

**步骤 2：** 在终端中输入以下命令并回车（注意：输入密码时屏幕不会显示任何字符，这是正常的安全设计，继续输入完毕回车即可）：

```bash
sudo apt update
```

**截图描述：** 提示符后显示已输入的 `sudo apt update`。按回车后系统提示 `[sudo] password for 用户名:`，输入密码时屏幕无任何显示。密码输入完毕后回车，终端逐一显示软件包索引的下载进度。

**步骤 3：** 执行系统升级：

```bash
sudo apt upgrade -y
```

**截图描述：** 终端显示"Reading package lists..."、"Building dependency tree..."等字样，然后列出可升级的软件包及其大小。最后显示下载和安装的进度。

**注意：** 首次更新可能需要下载数百 MB 的文件，请确保网络畅通并耐心等待。

### 4.8 安装 open-vm-tools

open-vm-tools 是确保虚拟机体验流畅的关键软件，它替代了旧版的 VMware Tools，建议立即安装。

**截图描述：** 在 Ubuntu 终端中右键粘贴 Windows 复制的内容，应能看到文字成功粘贴。拖动 VMware 窗口边缘改变大小，Ubuntu 桌面分辨率随之自动调整，两侧没有黑边。

### 4.9 快照管理

VMware 的快照功能是学习的"后悔药"。养成在重要操作前创建快照的好习惯。

**创建快照：**

| 操作步骤 | 截图描述 |
|----------|----------|
| 1. 确认虚拟机已开机并处于你希望保存的状态 | Ubuntu 桌面正常显示，所有需要的窗口和程序均已关闭或调整到合适状态 |
| 2. 在 VMware 菜单栏点击 VM > Snapshot > Take Snapshot | 菜单路径高亮显示，Snapshots 子菜单展开 |
| 3. 在弹出的对话框中输入快照名称（如"刚安装好的干净系统"）和描述（如"系统已安装 open-vm-tools 并已完成首次更新"） | 对话框标题为"Take Snapshot"，有两个输入框：Name（名称）和 Description（描述），底部有"Take Snapshot"按钮 |
| 4. 点击"Take Snapshot"按钮 | 虚拟机短暂暂停（屏幕可能卡顿约 1 秒），然后恢复正常。VMware 状态栏显示"Creating snapshot..."进度后消失 |

**还原快照：**

| 操作步骤 | 截图描述 |
|----------|----------|
| 1. 在 VMware 菜单栏点击 VM > Snapshot > Snapshot Manager（或直接按 Ctrl+M） | 弹出"Snapshot Manager"窗口 |
| 2. 在快照列表中选择想要还原的快照 | 左侧树形列表显示所有快照，你创建的快照名称显示在其中 |
| 3. 点击"Go to"按钮 | 弹出确认对话框，提示当前状态将会丢失 |
| 4. 确认操作 | 虚拟机开始还原，过程可能需要 10-60 秒，完成后回到快照创建时的状态 |

**截图描述（Snapshot Manager）：** 窗口左侧显示快照树形列表，"You are here"标记指示当前位置。右侧有"Go to"按钮。窗口底部有"Take Snapshot..."、"Delete"、"Clone..."、"Protect"等按钮。

**建议的快照策略：**

1. **系统安装完成 + 首次更新 + open-vm-tools 后：** 创建快照"01-干净系统"
2. **每学完一章并完成所有练习后：** 创建快照"02-第X章完成"（X 为章节号）
3. **执行有风险的操作前（如修改系统配置文件、安装来源不明的软件）：** 临时创建快照，操作成功后删除

### 练习 5.3：验证 open-vm-tools 功能

**题目：** 列出 open-vm-tools 安装后应该生效的 3 个功能，并逐一验证它们是否正常工作。

### 练习 5.4：解决 ISO 未自动断开的问题

### 练习 5.5：系统更新实践

**题目：** 在终端中依次执行以下操作，并记录每个命令的输出结果（取前 5 行即可）：
1. 检查磁盘剩余空间
2. 更新软件包列表
3. 查看有多少个可更新的软件包（不实际升级）
4. 执行系统升级

**答案：**
```bash
# 1. 查看磁盘剩余空间

# 2. 更新软件包列表

# 3. 查看可更新的软件包数量（仅列出，不安装）

```

| 命令 | 预期输出要点 |

| `sudo apt upgrade -y` | 下载进度条 + 安装进度条，最后显示升级完成摘要 |

## 6. 常见错误与排错

### 6.1 虚拟机启动时黑屏

**现象：** 点击"Power on this virtual machine"后，屏幕保持黑屏，没有出现任何画面。

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|----------|
| ISO 文件未正确挂载 | 检查虚拟机设置（VM > Settings > CD/DVD），确认"Use ISO image file"已正确指向 ISO 文件路径，且"Device status"中"Connect at power on"已勾选 |
| 虚拟机引导顺序错误 | 检查虚拟机设置中的 Firmware 类型（BIOS 或 UEFI），重新创建虚拟机时确认 ISO 选择了正确的 Ubuntu 64-bit 类型 |
| 系统资源不足 | 关闭其他占用大量内存的程序，减少虚拟机的内存分配（最低 2 GB），然后重试 |
| VMware 显示驱动问题 | 关闭虚拟机，在 VMware 主界面编辑虚拟机设置，Display 选项中取消"Accelerate 3D graphics" |

### 6.2 安装过程中卡住不动

**现象：** 安装进度条长时间不动（超过 30 分钟），或一直显示某个步骤没有进展。

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|----------|
| 网络下载更新速度过慢 | 如果你勾选了"安装 Ubuntu 时下载更新"，且网络速度很慢，会导致此问题。尝试：断掉物理机的网络连接（拔网线或关闭 Wi-Fi），让安装程序跳过网络下载，安装完成后再用更快的网络手动更新 |
| 磁盘空间不足 | 确认虚拟磁盘设置 >= 25 GB，物理磁盘剩余空间 >= 虚拟磁盘大小。检查 C 盘或其他存储路径是否有足够空间 |
| ISO 文件损坏 | 重新下载 ISO 文件，并用校验工具验证 SHA256 校验值是否与官网公布的一致 |

### 6.3 "Please remove the installation medium, then press ENTER"

**现象：** 安装完成后重启，停留在黑色屏幕，显示移除安装介质的提示。

**解决方法（已在 5.4 练习中涉及，此处汇总）：**

1. 首选方法：VM > Removable Devices > CD/DVD > Disconnect，然后按 Enter
2. 备用方法：直接按 Enter（VMware 有时会自动处理），如果系统正常启动则无需额外操作
3. 彻底方法：虚拟机断电重启，VMware 通常在断电重启时会自动取消 ISO 挂载

### 6.4 虚拟机无法联网

**现象：** Ubuntu 桌面右上角网络图标显示问号或断开状态，无法访问互联网。

**可能原因与解决方法：**

| 原因 | 解决方法 |
|------|----------|
| 虚拟网络适配器未连接 | 检查 VM > Settings > Network Adapter，确认"Device status"中"Connected"和"Connect at power on"均已勾选 |
| NAT 服务未启动 | 在 Windows 服务管理器（services.msc）中，找到"VMware NAT Service"，右键启动，并将启动类型设为"自动" |
| 虚拟机网卡未启用 | 在 Ubuntu 终端中执行 `ip addr` 查看网卡状态。如果网卡状态为 DOWN，执行 `sudo ip link set ens33 up`（网卡名可能不同，以实际输出为准） |
| 防火墙或杀毒软件拦截 | 暂时关闭 Windows 防火墙或第三方安全软件，测试是否能联网。如果确认是防火墙问题，添加 VMware NAT 的例外规则 |

### 6.5 分辨率异常（桌面过大或过小）

**现象：** Ubuntu 桌面分辨率不匹配，要么太大（显示不全，需要滚动），要么太小（周围有大片黑边）。

**解决方法：**

1. 确认 open-vm-tools-desktop 已正确安装：`dpkg -l | grep open-vm-tools`
2. 如果未安装，执行 `sudo apt install open-vm-tools-desktop -y`，然后 `sudo reboot`
3. 如果已安装但仍不工作，尝试重启 open-vm-tools 服务：`sudo systemctl restart open-vm-tools`
4. 在 VMware 菜单中点击 View > Autosize > Autofit Guest，确保自动适配已启用

## 7. 进阶延伸

### 7.1 验证 ISO 文件完整性

下载大型 ISO 文件后，建议验证其 SHA256 校验值，确保文件未被篡改或损坏。Ubuntu 官方提供了每个版本的 SHA256SUMS 文件。

**步骤：**

1. 从 Ubuntu 官网下载 SHA256SUMS 文件（与 ISO 在同一目录下）
2. 在 Windows 中打开 PowerShell，切换到 ISO 下载目录
3. 执行以下命令计算 ISO 的 SHA256 值：

```powershell
Get-FileHash -Algorithm SHA256 ".\ubuntu-24.04-desktop-amd64.iso"
```

4. 对比 PowerShell 输出的哈希值与 SHA256SUMS 文件中的对应值，两者必须完全一致。

### 7.2 更换国内软件源（APT Mirror）

默认情况下，Ubuntu 的软件源（Software Repository）服务器位于国外，从国内访问速度可能较慢。更换为国内镜像源可以大幅提升软件下载和更新速度。

**步骤（可暂时跳过，等学到包管理相关章节时再操作）：**

1. 备份当前软件源配置：
```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
```

2. 编辑软件源文件：
```bash
sudo nano /etc/apt/sources.list
```

3. 将文件中的 `archive.ubuntu.com` 或 `security.ubuntu.com` 替换为国内镜像地址，例如：
   - 清华大学 TUNA：`mirrors.tuna.tsinghua.edu.cn`
   - 阿里云：`mirrors.aliyun.com`
   - 中科大 USTC：`mirrors.ustc.edu.cn`

4. 保存文件后更新软件源：`sudo apt update`

### 7.3 虚拟机克隆

VMware 允许你克隆（Clone）现有虚拟机，从而快速创建多个完全相同的 Ubuntu 环境。

**克隆与快照的区别：** 快照是同一台虚拟机在不同时间点的"存档"；克隆则是创建一台全新的、独立的虚拟机。克隆常用于需要多台相同配置虚拟机的场景（如搭建网络实验环境）。

**操作步骤：**
1. 在 VMware 菜单中点击 VM > Manage > Clone
2. 选择"Create a linked clone"（链接克隆，占用空间小但依赖原始虚拟机）或"Create a full clone"（完整克隆，完全独立但占用空间等于原始虚拟机）
3. 为新虚拟机命名并选择存储路径
4. 等待克隆完成

### 7.4 虚拟磁盘扩容

如果在使用过程中发现虚拟磁盘空间不足，VMware 支持对虚拟磁盘进行扩容（仅限没有快照的虚拟机）。

**操作步骤：**
1. 在 VMware 菜单中点击 VM > Settings > Hard Disk
2. 在右侧面板点击"Expand"按钮
3. 输入新的磁盘总容量（必须大于当前容量），点击"Expand"
4. 磁盘空间扩大后，还需要在 Ubuntu 内部调整分区以使用新增空间。这涉及到 GParted 等分区工具的使用，将在后续章节中介绍。

### 7.5 其他虚拟机软件简介

虽然本书使用 VMware Workstation，但了解其他虚拟机软件有助于你根据实际情况灵活选择：

| 软件 | 类型 | 特点 |
|------|------|------|
| **VirtualBox** | 免费开源 | Oracle 出品，功能齐全，跨平台（Windows/macOS/Linux）。对初学者友好，但 3D 性能略逊于 VMware |
| **Hyper-V** | Windows 内置 | Windows 10/11 专业版和企业版自带。性能优异，但启用后可能与 VMware 冲突。适合 Windows 重度用户 |
| **UTM** | 免费 | macOS 上的虚拟机软件，基于 QEMU。界面简洁优雅，适合 Apple Silicon（M1/M2/M3）Mac 用户 |
| **QEMU/KVM** | 开源 | Linux 原生虚拟化方案，性能接近物理机。本书后续章节会涉及在 Linux 中使用 KVM 运行虚拟机 |

### 7.6 UEFI 与 BIOS 启动模式

Ubuntu 24.04 默认使用 UEFI（Unified Extensible Firmware Interface，统一可扩展固件接口）模式启动，它是传统 BIOS（Basic Input/Output System，基本输入输出系统）的现代替代品。VMware Workstation 创建的 Ubuntu 虚拟机通常自动识别为 UEFI 模式。

**知识点：**
- UEFI 支持更大的磁盘（超过 2 TB）和更快的启动速度
- UEFI 使用 ESP（EFI System Partition，EFI 系统分区）存储引导文件
- 在 VMware 中，你可以通过 VM > Settings > Options > Advanced > Firmware type 查看和切换启动模式
- 一般无需手动修改此设置，VMware 的自动检测已足够准确
