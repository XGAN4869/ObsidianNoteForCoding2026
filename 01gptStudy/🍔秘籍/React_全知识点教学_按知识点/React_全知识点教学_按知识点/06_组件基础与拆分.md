# 6. 组件基础与拆分

## 6.1 本章要解决什么问题

组件是 React 的核心。一个页面如果全部写在 App.jsx 中，很快会变得又长又乱。

组件能解决：

- 页面结构太复杂；
- 相同 UI 重复写；
- 逻辑混在一起不好维护；
- 团队多人协作困难。

## 6.2 什么是组件

组件就是一个返回 JSX 的函数。

```jsx
function Welcome() {
  return <h1>欢迎学习 React</h1>;
}
```

使用组件像写标签一样：

```jsx
export default function App() {
  return (
    <div>
      <Welcome />
      <Welcome />
    </div>
  );
}
```

## 6.3 组件名必须大写开头

正确：

```jsx
function UserCard() {
  return <div>用户卡片</div>;
}
```

错误：

```jsx
function userCard() {
  return <div>用户卡片</div>;
}
```

小写开头会被 React 当成浏览器原生标签。

## 6.4 拆分组件示例

App.jsx：

```jsx
function Header() {
  return <header><h1>后台管理系统</h1></header>;
}

function Sidebar() {
  return (
    <aside>
      <ul>
        <li>首页</li>
        <li>用户</li>
        <li>设置</li>
      </ul>
    </aside>
  );
}

function MainContent() {
  return <main>这里是主要内容</main>;
}

export default function App() {
  return (
    <div>
      <Header />
      <Sidebar />
      <MainContent />
    </div>
  );
}
```

页面结构变清楚了：上面是 Header，中间有 Sidebar 和 MainContent。

## 6.5 一个文件一个组件

项目变大后，建议把组件放到单独文件。

```text
src/
  App.jsx
  components/
    Header.jsx
    Sidebar.jsx
    UserCard.jsx
```

Header.jsx：

```jsx
export default function Header() {
  return <header><h1>后台管理系统</h1></header>;
}
```

App.jsx：

```jsx
import Header from './components/Header.jsx';

export default function App() {
  return <Header />;
}
```

## 6.6 默认导出和命名导出

默认导出：

```jsx
export default function Header() {
  return <h1>标题</h1>;
}
```

导入时名字可以改：

```jsx
import MyHeader from './Header.jsx';
```

命名导出：

```jsx
export function Header() {
  return <h1>标题</h1>;
}
```

导入时要加花括号：

```jsx
import { Header } from './Header.jsx';
```

初学建议：一个文件一个主要组件时使用默认导出。

## 6.7 什么时候拆组件

可以按这些标准拆：

- 一段 UI 重复出现；
- 一个组件超过一屏，很难看懂；
- 某个区域有独立功能；
- 想让父组件更清晰；
- 需要单独测试或复用。

不要为了拆而拆。太小、太碎的组件也会增加理解成本。

## 6.8 组件必须保持纯净

组件渲染时不要直接修改外部变量，不要在渲染阶段做请求、定时器、DOM 监听。

错误示例：

```jsx
let count = 0;

function App() {
  count++;
  return <p>{count}</p>;
}
```

组件函数应该根据 props 和 state 返回 JSX。副作用放到事件或 useEffect 中。

## 6.9 常见错误

- 组件名小写；
- 忘记 export；
- import 路径写错；
- 默认导出和命名导出混用；
- 把所有组件都写在 App.jsx，不拆分；
- 拆得太碎，每个组件只有一行且没有复用意义。

## 6.10 小结与练习

- 组件是返回 JSX 的函数；
- 组件名大写开头；
- 页面复杂时要拆组件；
- 一个文件可以放一个主要组件；
- 组件渲染应该保持纯净。

练习：

1. 把 App 拆成 Header、Main、Footer 三个组件。
2. 把 Header 放到 components/Header.jsx。
3. 在 App 中导入并使用 Header。
