## 本教材的范围

本教材覆盖：

- React 核心思想：组件、JSX、props、state、事件、条件渲染、列表渲染。
- React 常用 Hooks：useState、useEffect、useRef、useMemo、useCallback、useContext、useReducer。
- 组件通信、组件组合、children、自定义 Hooks。
- 路由、状态管理、网络请求、表单、CRUD 项目。
- TypeScript、工程化、调试、性能、安全、测试和部署基础。
- React 18/19 中初学者容易遇到的能力和注意事项。

本教材不把某一个 UI 组件库当作 React 核心内容。Ant Design、MUI、Mantine 等属于生态库，需要在掌握 React 核心后再学习。

## 官方资料依据

内容以 React 官方文档、React DOM 官方文档、React Router 官方文档、Redux Toolkit 官方文档和 Vite 官方文档的推荐用法为基础。React 生态会升级，遇到具体版本差异时，应以项目安装版本和官方文档为准。

本教材默认使用函数组件和 Hooks。类组件不是新项目主线，但你在旧项目中可能会看到，本教材会在必要时说明。

## 最小学习方法

每个知识点至少做四步：

1. 看懂这个知识点解决什么问题。
2. 手动输入示例代码，不要只复制。
3. 修改数据、文字或条件，观察结果。
4. 用自己的话说出“什么时候用它”。

## 本教材默认项目形态

除非特别说明，本教材默认：

- 使用 React 当前官方稳定文档口径讲解核心知识，React 18/19 常见项目都能理解；
- 使用函数组件；
- 使用 Hooks；
- 使用 JSX；
- 使用 Vite 创建项目；
- 使用 React Router 的声明式路由作为入门主线；
- 状态管理优先讲 Redux Toolkit 的现代写法，并简单认识 Zustand。
