# 12. 表单与受控组件

## 12.1 本章要解决什么问题

表单是项目中最常见的功能之一：

- 登录；
- 注册；
- 搜索；
- 新增用户；
- 编辑商品；
- 评论提交。

React 中常用“受控组件”管理表单：输入框的值由 state 控制。

## 12.2 什么是受控组件

```text
input 的 value 来自 state
用户输入时 onChange 修改 state
state 变了，input 显示也变了
```

示例：

```jsx
import { useState } from 'react';

export default function NameInput() {
  const [name, setName] = useState('');

  return (
    <div>
      <input
        value={name}
        onChange={event => setName(event.target.value)}
      />
      <p>你输入的是：{name}</p>
    </div>
  );
}
```

## 12.3 多个输入框

```jsx
import { useState } from 'react';

export default function LoginForm() {
  const [form, setForm] = useState({
    username: '',
    password: '',
  });

  function handleChange(event) {
    const { name, value } = event.target;

    setForm({
      ...form,
      [name]: value,
    });
  }

  return (
    <form>
      <input
        name="username"
        value={form.username}
        onChange={handleChange}
        placeholder="用户名"
      />
      <input
        name="password"
        type="password"
        value={form.password}
        onChange={handleChange}
        placeholder="密码"
      />
    </form>
  );
}
```

关键点：

- input 的 name 对应 form 对象的字段名；
- `[name]: value` 是 JavaScript 的计算属性名；
- 更新对象时使用展开运算符保留其他字段。

## 12.4 textarea

```jsx
const [content, setContent] = useState('');

<textarea
  value={content}
  onChange={event => setContent(event.target.value)}
/>
```

React 中 textarea 也用 value，而不是把内容写在标签中间。

## 12.5 select

```jsx
const [city, setCity] = useState('beijing');

<select value={city} onChange={event => setCity(event.target.value)}>
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
  <option value="guangzhou">广州</option>
</select>
```

select 的当前选中值由 value 控制。

## 12.6 checkbox

单个复选框通常用 checked。

```jsx
const [agree, setAgree] = useState(false);

<label>
  <input
    type="checkbox"
    checked={agree}
    onChange={event => setAgree(event.target.checked)}
  />
  我同意协议
</label>
```

注意：checkbox 读取的是 `event.target.checked`，不是 value。

## 12.7 radio

```jsx
const [gender, setGender] = useState('male');

<label>
  <input
    type="radio"
    name="gender"
    value="male"
    checked={gender === 'male'}
    onChange={event => setGender(event.target.value)}
  />
  男
</label>

<label>
  <input
    type="radio"
    name="gender"
    value="female"
    checked={gender === 'female'}
    onChange={event => setGender(event.target.value)}
  />
  女
</label>
```

## 12.8 表单提交

```jsx
import { useState } from 'react';

export default function UserForm() {
  const [form, setForm] = useState({ username: '', age: '' });

  function handleChange(event) {
    const { name, value } = event.target;
    setForm({ ...form, [name]: value });
  }

  function handleSubmit(event) {
    event.preventDefault();
    console.log('提交数据：', form);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="username" value={form.username} onChange={handleChange} />
      <input name="age" value={form.age} onChange={handleChange} />
      <button type="submit">提交</button>
    </form>
  );
}
```

## 12.9 非受控组件简单认识

非受控组件是指表单值主要由 DOM 自己保存，React 通过 ref 获取。

```jsx
import { useRef } from 'react';

export default function SearchBox() {
  const inputRef = useRef(null);

  function handleSearch() {
    alert(inputRef.current.value);
  }

  return (
    <div>
      <input ref={inputRef} />
      <button onClick={handleSearch}>搜索</button>
    </div>
  );
}
```

初学和大多数业务表单，优先使用受控组件，因为数据更清楚。

## 12.10 常见错误

- 给 input 写了 value，却忘记 onChange，导致无法输入；
- checkbox 读取 value，而不是 checked；
- 表单提交忘记 preventDefault；
- 更新对象 state 时丢失其他字段；
- 把数字输入框的值误以为自动是 number，其实通常还是字符串；
- 前端校验当成唯一校验，忽略后端校验。

## 12.11 小结与练习

- 受控组件就是 value/checked 由 state 控制；
- 输入变化用 onChange 更新 state；
- 多字段表单可以用一个对象保存；
- checkbox 用 checked；
- 表单提交要阻止默认刷新。

练习：

1. 写一个登录表单，包含用户名和密码。
2. 写一个注册表单，包含用户名、性别、是否同意协议。
3. 提交时检查用户名不能为空，空则显示提示。
