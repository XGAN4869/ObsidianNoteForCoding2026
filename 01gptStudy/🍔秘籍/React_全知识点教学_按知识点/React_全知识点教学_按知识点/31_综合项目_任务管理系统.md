# 31. 综合项目：任务管理系统

## 31.1 本章要解决什么问题

前面每一章都是单个知识点。真正学会 React，需要把知识点放到一个完整小项目里。

本章做一个 **任务管理系统**，包含：

- 添加任务；
- 显示任务列表；
- 完成/取消完成；
- 编辑任务；
- 删除任务；
- 按全部/未完成/已完成筛选；
- 统计任务数量；
- 用 localStorage 保存到浏览器本地。

这个项目虽然小，但覆盖了 React 入门最常用能力。

---

## 31.2 项目会用到哪些知识点

本项目会用到：

| 知识点 | 用在哪里 |
|---|---|
| JSX | 写页面结构 |
| 组件 | 拆分页面区域 |
| props | 父组件给子组件传数据和函数 |

| key | 给每个任务稳定标识 |

| useMemo | 计算筛选结果和统计数据 |
| 表单 | 添加任务、编辑任务 |

## 31.3 项目数据结构

每一条任务长这样：

```jsx
{
  id: 1,
  text: '学习 React',
  done: false,
  createdAt: 1720000000000
}
```

字段说明：

| 字段 | 含义 |
|---|---|
| `id` | 唯一编号，用于 key、编辑、删除 |
| `text` | 任务内容 |
| `done` | 是否完成 |
| `createdAt` | 创建时间 |

初学项目中可以用 `Date.now()` 做 id。真实项目中，id 通常由后端数据库生成，也可以在前端使用 `crypto.randomUUID()`。

## 31.5 完整 App.jsx

把下面代码放到 `src/App.jsx`。

```jsx
import { useEffect, useMemo, useState } from 'react';
import './App.css';

const STORAGE_KEY = 'react-task-list';

function loadTasks() {
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved) : [];
  } catch (error) {
    console.error('读取本地任务失败：', error);
    return [];
  }
}

export default function App() {
  const [tasks, setTasks] = useState(loadTasks);
  const [text, setText] = useState('');
  const [filter, setFilter] = useState('all');
  const [editingId, setEditingId] = useState(null);
  const [editingText, setEditingText] = useState('');

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
  }, [tasks]);

  const filteredTasks = useMemo(() => {
    if (filter === 'active') {
      return tasks.filter((task) => !task.done);
    }

    if (filter === 'completed') {
      return tasks.filter((task) => task.done);
    }

    return tasks;
  }, [tasks, filter]);

  const stats = useMemo(() => {
    const total = tasks.length;
    const completed = tasks.filter((task) => task.done).length;
    const active = total - completed;

    return { total, completed, active };
  }, [tasks]);

  function handleAddTask(e) {
    e.preventDefault();

    const value = text.trim();
    if (!value) {
      alert('任务内容不能为空');
      return;
    }

    const newTask = {
      id: Date.now(),
      text: value,
      done: false,
      createdAt: Date.now(),
    };

    setTasks((prev) => [newTask, ...prev]);
    setText('');
  }

  function handleToggleTask(id) {
    setTasks((prev) =>
      prev.map((task) =>
        task.id === id ? { ...task, done: !task.done } : task
      )
    );
  }

  function handleDeleteTask(id) {
    const ok = window.confirm('确定删除这条任务吗？');
    if (!ok) return;

    setTasks((prev) => prev.filter((task) => task.id !== id));

    if (editingId === id) {
      setEditingId(null);
      setEditingText('');
    }
  }

  function handleStartEdit(task) {
    setEditingId(task.id);
    setEditingText(task.text);
  }

  function handleCancelEdit() {
    setEditingId(null);
    setEditingText('');
  }

  function handleSaveEdit(id) {
    const value = editingText.trim();
    if (!value) {
      alert('任务内容不能为空');
      return;
    }

    setTasks((prev) =>
      prev.map((task) =>
        task.id === id ? { ...task, text: value } : task
      )
    );

    setEditingId(null);
    setEditingText('');
  }

  function handleClearCompleted() {
    const ok = window.confirm('确定清空已完成任务吗？');
    if (!ok) return;

    setTasks((prev) => prev.filter((task) => !task.done));
  }

  return (
    <div className="app">
      <h1>任务管理系统</h1>

      <form className="task-form" onSubmit={handleAddTask}>
        <input
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="请输入任务，例如：学习 useEffect"
        />
        <button type="submit">添加任务</button>
      </form>

      <div className="stats">
        <span>全部：{stats.total}</span>
        <span>未完成：{stats.active}</span>
        <span>已完成：{stats.completed}</span>
      </div>

      <div className="filters">
        <button
          className={filter === 'all' ? 'active' : ''}
          onClick={() => setFilter('all')}
        >
          全部
        </button>
        <button
          className={filter === 'active' ? 'active' : ''}
          onClick={() => setFilter('active')}
        >
          未完成
        </button>
        <button
          className={filter === 'completed' ? 'active' : ''}
          onClick={() => setFilter('completed')}
        >
          已完成
        </button>
      </div>

      {filteredTasks.length === 0 ? (
        <p className="empty">暂无任务</p>
      ) : (
        <ul className="task-list">
          {filteredTasks.map((task) => (
            <li key={task.id} className="task-item">
              {editingId === task.id ? (
                <div className="edit-row">
                  <input
                    value={editingText}
                    onChange={(e) => setEditingText(e.target.value)}
                  />
                  <button onClick={() => handleSaveEdit(task.id)}>保存</button>
                  <button onClick={handleCancelEdit}>取消</button>
                </div>
              ) : (
                <div className="view-row">
                  <label>
                    <input
                      type="checkbox"
                      checked={task.done}
                      onChange={() => handleToggleTask(task.id)}
                    />
                    <span className={task.done ? 'done' : ''}>{task.text}</span>
                  </label>

                  <div className="actions">
                    <button onClick={() => handleStartEdit(task)}>编辑</button>
                    <button onClick={() => handleDeleteTask(task.id)}>删除</button>
                  </div>
                </div>
              )}
            </li>
          ))}
        </ul>
      )}

      {stats.completed > 0 && (
        <button className="clear" onClick={handleClearCompleted}>
          清空已完成
        </button>
      )}
    </div>
  );
}
```

## 31.7 代码一步一步解释

### 1）读取本地任务

```jsx
function loadTasks() {
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved) : [];
  } catch (error) {
    console.error('读取本地任务失败：', error);
    return [];
  }
}
```

这里做了两件事：

- 如果浏览器里有保存过的任务，就读取出来；
- 如果没有，返回空数组。

用 `try...catch` 是为了防止本地数据损坏导致页面崩掉。

---

### 2）初始化任务 state

```jsx
const [tasks, setTasks] = useState(loadTasks);
```

注意这里不是：

```jsx
useState(loadTasks())
```

而是：

```jsx
useState(loadTasks)
```

这样 React 只会在初始渲染时调用一次初始化函数。

---

### 3）保存到 localStorage

```jsx
useEffect(() => {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks));
}, [tasks]);
```

意思是：

```text
tasks 每次变化，都保存到浏览器本地。
```

刷新页面后，任务还在。

---

### 4）添加任务

```jsx
function handleAddTask(e) {
  e.preventDefault();

  const value = text.trim();
  if (!value) {
    alert('任务内容不能为空');
    return;
  }

  const newTask = {
    id: Date.now(),
    text: value,
    done: false,
    createdAt: Date.now(),
  };

  setTasks((prev) => [newTask, ...prev]);
  setText('');
}
```

关键点：

- `e.preventDefault()` 防止表单刷新页面；
- `trim()` 去掉前后空格；
- `setTasks((prev) => ...)` 使用函数式更新；
- 新任务放到数组最前面；
- 添加成功后清空输入框。

---

### 5）切换完成状态

```jsx
setTasks((prev) =>
  prev.map((task) =>
    task.id === id ? { ...task, done: !task.done } : task
  )
);
```

这句话的意思是：

```text
找到 id 相同的任务，复制它并修改 done。
其他任务原样返回。
```

不要直接改：

```jsx
task.done = true;
```

React state 应该用不可变更新方式。

---

### 6）删除任务

```jsx
setTasks((prev) => prev.filter((task) => task.id !== id));
```

`filter` 会返回一个新数组。  
这里保留所有 id 不等于目标 id 的任务。

---

### 7）编辑任务

编辑分三步：

```text
点击编辑 → 进入编辑模式
修改文本 → 暂存在 editingText
点击保存 → 写回 tasks
```

对应状态：

```jsx
const [editingId, setEditingId] = useState(null);
const [editingText, setEditingText] = useState('');
```

如果：

```jsx
editingId === task.id
```

就显示输入框。  
否则显示普通文本。

---

### 8）筛选任务

```jsx
const filteredTasks = useMemo(() => {
  if (filter === 'active') {
    return tasks.filter((task) => !task.done);
  }

  if (filter === 'completed') {
    return tasks.filter((task) => task.done);
  }

  return tasks;
}, [tasks, filter]);
```

筛选条件有三个：

- `all`：全部；
- `active`：未完成；
- `completed`：已完成。

`useMemo` 在这里不是必须，但它能帮助你练习“根据 state 计算结果”的写法。

## 31.8 如何拆分组件

当你理解完整代码后，可以拆成组件。

例如：

```text
TaskForm：添加任务表单
TaskStats：统计区域
TaskFilter：筛选按钮
TaskList：任务列表
TaskItem：单条任务
```

父组件 `App` 保存主要状态。  
子组件通过 props 接收数据和操作函数。

例如：

```jsx
<TaskForm text={text} setText={setText} onAddTask={handleAddTask} />
<TaskFilter filter={filter} onChangeFilter={setFilter} />
<TaskList tasks={filteredTasks} onToggle={handleToggleTask} />
```

这样父组件负责数据，子组件负责显示。

## 31.9 如果接入后端要改哪里

现在数据存在 localStorage。  
如果以后接入后端，可以这样改：

| 当前做法 | 后端做法 |
|---|---|
| `localStorage.getItem` | `GET /tasks` |
| `setTasks 添加` | `POST /tasks` |
| `setTasks 修改` | `PUT /tasks/:id` 或 `PATCH /tasks/:id` |
| `setTasks 删除` | `DELETE /tasks/:id` |
| `localStorage.setItem` | 后端数据库保存 |

也就是说：

```text
UI 结构基本不变，
主要是数据来源和保存方式改变。
```

## 31.10 常见错误

- 添加任务时忘记 `preventDefault`，页面刷新；
- `map` 渲染列表没有 `key`；
- 用数组下标当 key，编辑或删除时容易出问题；
- 删除任务时直接修改原数组；
- 编辑时没有单独的 `editingText`；
- localStorage 里保存对象时忘记 `JSON.stringify`；
- 读取 localStorage 时忘记 `JSON.parse`；
- 空任务也能提交；
- 完成状态和筛选条件混在一起，逻辑不清楚。
