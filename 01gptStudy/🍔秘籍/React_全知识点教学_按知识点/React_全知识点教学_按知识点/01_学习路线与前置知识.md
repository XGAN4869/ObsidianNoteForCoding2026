# 1. 学习路线与前置知识

## 1.1 React 不是替代 JavaScript

React 是建立在 JavaScript 之上的前端 UI 库。学习 React 时仍然需要会一点 JavaScript。

你不需要一开始就成为 JavaScript 高手，但至少要能看懂：

- 变量和常量：`const`、`let`；
- 函数和箭头函数；
- 对象、数组、解构、展开运算符；
- 数组方法：`map`、`filter`、`find`、`some`、`every`、`reduce`；
- Promise、`async/await`；
- 模块：`import`、`export`；
- DOM、事件、HTTP 请求的基本概念。

如果这些还不熟，不要害怕。学习 React 时遇到它们，再回到 JavaScript 文档补即可。

## 1.2 React 学习总路线

```text
第 1 阶段：会创建项目，认识 JSX 和组件
第 2 阶段：掌握 props、state、事件、条件、列表
第 3 阶段：掌握表单、Effect、Ref
第 4 阶段：掌握 Context、Reducer、自定义 Hooks
第 5 阶段：掌握 Router、状态管理、请求、表单项目
第 6 阶段：学习 TypeScript、性能、测试、部署
第 7 阶段：独立完成一个 CRUD 项目
```

正确顺序是：

```text
React 核心语法 → 组件通信 → Hooks → 路由 → 状态管理 → 请求与项目
```

不要一开始就学大量库。先能写出页面、能处理用户点击、能请求数据，再学习生态库。

## 1.3 React 中的常用词

| 词       | 简单解释                        |
| ------- | --------------------------- |
| 应用      | 整个 React 程序，例如渲染到页面根节点的 App |
| 根组件     | 最外层组件，通常叫 App               |
| 组件      | 可以重复使用的页面部件                 |
| JSX     | 在 JavaScript 中写类似 HTML 的语法  |
| props   | 父组件传给子组件的数据                 |
| state   | 组件自己记住的数据，变化后会重新渲染          |
| 渲染      | React 根据数据计算出页面应该长什么样       |
| Hook    | 以 use 开头的函数，用来使用 React 能力   |
| 副作用     | 访问外部系统的动作，例如请求、定时器、DOM 监听   |
| Context | 跨很多层组件传数据的工具                |
| Reducer | 用一个函数集中管理复杂 state 更新        |
| 路由      | URL 与页面组件之间的对应关系            |
| Store   | 保存共享状态的仓库                   |
| 构建工具    | 帮助开发、打包项目的工具，例如 Vite        |

## 1.4 初学者先记住一句话

React 的核心是：

```text
数据变了 → 组件重新运行 → 返回新的 JSX → 页面更新
```

你不需要手动写很多 DOM 操作。你主要做三件事：

1. 准备数据；
2. 用 JSX 描述页面；
3. 在用户操作后更新数据。

## 1.5 最小 JavaScript 前置示例

学习 React 前，建议你至少能独立看懂下面的普通 JavaScript：

```html
<button id="btn">点击</button>
<p id="text"></p>
```

```js
const btn = document.querySelector('#btn');
const text = document.querySelector('#text');
let count = 0;

btn.addEventListener('click', () => {
  count++;
  text.textContent = count;
});
```

React 会把这类“数据变化后更新页面”的工作变得更结构化。

## 1.6 React 项目中你会反复做的事

- 把页面拆成组件；
- 用 props 把数据传给子组件；
- 用 state 保存会变化的数据；
- 用事件处理用户操作；
- 用数组 map 渲染列表；
- 用 useEffect 做请求、监听、定时器等副作用；
- 用 Router 做多页面切换；
- 用状态管理工具保存跨页面共享数据。

## 1.7 本教材使用的默认风格

除非特别说明，本教材默认：

- 使用函数组件；
- 使用 Hooks；
- 使用 JSX；
- 使用 Vite；
- 使用现代 React 写法；
- 不以类组件作为主线。

旧项目中可能有 class component。你需要知道它存在，但新学习不建议先从类组件开始。

## 1.8 常见错误

- 以为学 React 就不用学 JavaScript；
- 只背 API 名称，不知道什么时候用；
- 不运行代码，只看教程；
- 一开始就学组件库，忽略 React 核心；
- 把所有数据都放到全局状态；
- 看见报错不读，只刷新页面。

## 1.9 小结与练习

React 学习主线不是背单词，而是理解：

```text
数据怎么来 → 页面怎么显示 → 用户怎么操作 → 数据怎么变化
```

练习：

1. 用一句话解释什么是组件。
2. 用一句话解释什么是 state。
3. 写出你准备按照什么顺序学习 React。
