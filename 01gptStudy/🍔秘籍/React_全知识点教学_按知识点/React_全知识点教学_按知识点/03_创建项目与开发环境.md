# 3. 创建项目与开发环境

## 3.1 本章要解决什么问题

学习 React，最怕只看代码不运行。本章教你创建一个能运行的 React 项目。

我们使用 Vite。它启动快，配置简单，适合学习和普通前端项目。

你需要准备：

- Node.js；
- npm；
- VS Code 或其他编辑器；
- 浏览器；
- React Developer Tools 浏览器插件。

## 3.2 检查 Node.js

在终端输入：

```bash
node -v
npm -v
```

如果能看到版本号，说明安装成功。

如果提示找不到命令，先安装 Node.js。建议安装 LTS 版本，不建议初学者安装过旧版本。

## 3.3 使用 Vite 创建 React 项目

在你想放项目的目录打开终端，输入：

```bash
npm create vite@latest my-react-app
```

按提示选择：

```text
Framework: React
Variant: JavaScript
```

如果你要使用 TypeScript，可以选择 React + TypeScript，但本教材前面先用 JavaScript。

进入项目：

```bash
cd my-react-app
npm install
npm run dev
```

浏览器打开终端提示的地址，常见是：

```text
http://localhost:5173
```

## 3.4 项目目录认识

一个常见 Vite React 项目大概长这样：

```text
my-react-app/
  index.html
  package.json
  vite.config.js
  src/
    main.jsx
    App.jsx
    App.css
    index.css
```

重要文件：

| 文件 | 作用 |
|---|---|
| index.html | 页面模板，里面有根节点 |
| src/main.jsx | React 应用入口 |
| src/App.jsx | 根组件 |
| package.json | 项目依赖和脚本 |
| vite.config.js | Vite 配置 |

## 3.5 package.json 认识

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  }
}
```

常用命令：

| 命令 | 作用 |
|---|---|
| npm run dev | 开发时启动本地服务 |
| npm run build | 打包生产文件 |
| npm run preview | 本地预览打包结果 |

注意：package.json 中的实际版本以你创建项目时安装的版本为准。

## 3.6 清理默认项目

可以把 App.jsx 改成最小示例：

```jsx
import { useState } from 'react';
import './App.css';

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <main>
      <h1>我的第一个 React 应用</h1>
      <button onClick={() => setCount(count + 1)}>
        点击次数：{count}
      </button>
    </main>
  );
}
```

## 3.7 main.jsx 最小入口

```jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import './index.css';
import App from './App.jsx';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

你现在先记住：

- createRoot 创建 React 根；
- render 把 App 渲染到页面；
- StrictMode 是开发时帮助发现问题的工具。

## 3.8 VS Code 建议插件

建议安装：

- ESLint：发现代码问题；
- Prettier：格式化代码；
- React Developer Tools：浏览器插件，不是 VS Code 插件。

## 3.9 常见错误

- 没有进入项目目录就运行 npm run dev；
- 创建项目后忘记 npm install；
- 把文件名写错，例如 App.jsx 写成 app.jsx；
- 浏览器打开了错误端口；
- 终端报错没有认真看第一行和最后一行。

## 3.10 小结与练习

- 推荐使用 Vite 创建 React 学习项目；
- src/main.jsx 是入口；
- src/App.jsx 是根组件；
- 开发运行用 npm run dev；
- 打包用 npm run build。

练习：

1. 创建一个 my-react-app 项目并运行。
2. 把页面标题改成你的名字。
3. 新增一个按钮，点击后 count 增加 2。
