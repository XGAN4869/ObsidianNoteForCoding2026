# 9. 事件处理

## 9.1 本章要解决什么问题

用户会点击按钮、输入文字、提交表单、移动鼠标。React 需要处理这些用户操作。

事件处理解决的问题是：

```text
用户做了某个动作 → 执行一个函数 → 更新 state 或执行业务逻辑 → 页面变化
```

React 事件写法和 HTML 有区别：

- HTML：`onclick="..."`；
- React：`onClick={函数}`。

## 9.2 最简单的点击事件

```jsx
export default function App() {
  function handleClick() {
    alert('你点击了按钮');
  }

  return <button onClick={handleClick}>点击</button>;
}
```

注意：这里写的是 `onClick={handleClick}`，不是 `onClick={handleClick()}`。

## 9.3 不要立即执行函数

错误写法：

```jsx
<button onClick={handleClick()}>点击</button>
```

这会在组件渲染时立刻执行，不是点击时执行。

正确写法：

```jsx
<button onClick={handleClick}>点击</button>
```

如果需要传参数，用箭头函数包一层：

```jsx
<button onClick={() => handleDelete(1)}>删除</button>
```

## 9.4 事件中更新 state

```jsx
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);

  function handleAdd() {
    setCount(count + 1);
  }

  return (
    <div>
      <p>点击次数：{count}</p>
      <button onClick={handleAdd}>加 1</button>
    </div>
  );
}
```

用户点击后，事件函数执行，setCount 修改 state，React 重新渲染页面。

## 9.5 事件对象 event

React 会把事件对象传给事件处理函数。

```jsx
export default function App() {
  function handleChange(event) {
    console.log(event.target.value);
  }

  return <input onChange={handleChange} />;
}
```

常用：

- `event.target.value`：输入框的值；
- `event.preventDefault()`：阻止默认行为；
- `event.stopPropagation()`：阻止事件冒泡。

## 9.6 表单提交事件

浏览器表单提交默认会刷新页面。React 项目通常要阻止这个默认行为。

```jsx
import { useState } from 'react';

export default function LoginForm() {
  const [username, setUsername] = useState('');

  function handleSubmit(event) {
    event.preventDefault();
    alert('提交用户名：' + username);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={username}
        onChange={event => setUsername(event.target.value)}
      />
      <button type="submit">登录</button>
    </form>
  );
}
```

## 9.7 传递参数

列表中经常要知道用户点了哪一项。

```jsx
export default function UserList() {
  const users = [
    { id: 1, name: '小明' },
    { id: 2, name: '小红' },
  ];

  function handleSelect(user) {
    alert('你选择了：' + user.name);
  }

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>
          {user.name}
          <button onClick={() => handleSelect(user)}>选择</button>
        </li>
      ))}
    </ul>
  );
}
```

箭头函数不会马上执行里面的 handleSelect，它会等点击时执行。

## 9.8 子组件事件：父传回调

React 中子组件通知父组件，常用回调函数。

```jsx
function TodoItem({ todo, onToggle }) {
  return (
    <li>
      <label>
        <input
          type="checkbox"
          checked={todo.done}
          onChange={() => onToggle(todo.id)}
        />
        {todo.text}
      </label>
    </li>
  );
}

export default function App() {
  const [todos, setTodos] = useState([
    { id: 1, text: '学习事件', done: false },
  ]);

  function handleToggle(id) {
    setTodos(todos.map(todo => (
      todo.id === id ? { ...todo, done: !todo.done } : todo
    )));
  }

  return (
    <TodoItem todo={todos[0]} onToggle={handleToggle} />
  );
}
```

父组件负责保存和修改数据，子组件负责触发事件。

## 9.9 React 事件命名

DOM 事件使用驼峰命名：

| HTML | React |
|---|---|
| onclick | onClick |
| onchange | onChange |
| onsubmit | onSubmit |
| onkeydown | onKeyDown |
| onmouseenter | onMouseEnter |

组件自定义回调也建议用 `onXxx`：

```jsx
<UserCard onSelect={handleSelect} />
```

## 9.10 常见错误

- 写成 `onclick` 而不是 `onClick`；
- 写成 `onClick={handleClick()}` 导致立即执行；
- 表单提交忘记 `event.preventDefault()`；
- 在事件中直接修改 state 对象或数组；
- 子组件想直接改父组件 state；
- 不传参数时也写很多不必要的箭头函数，代码变乱。

## 9.11 小结与练习

- React 事件使用驼峰命名；
- 事件属性接收函数；
- 传参数时用箭头函数包一层；
- 表单提交常用 preventDefault；
- 子组件通知父组件用回调函数。

练习：

1. 写一个按钮，点击后显示弹窗。
2. 写一个输入框，输入时把内容显示在下方。
3. 写一个用户列表，点击某个用户后显示“当前选中：用户名”。
