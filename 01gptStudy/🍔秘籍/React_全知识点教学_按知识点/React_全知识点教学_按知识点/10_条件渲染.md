# 10. 条件渲染

## 10.1 本章要解决什么问题

页面经常不是固定显示的，而是根据条件变化。

例如：

- 登录了显示用户名，没登录显示登录按钮；
- loading 为 true 显示加载中；
- error 有值显示错误提示；
- 列表为空显示暂无数据；
- 弹窗 open 为 true 才显示。

这就是条件渲染。

## 10.2 使用 if 提前 return

```jsx
function UserPanel({ user }) {
  if (!user) {
    return <button>请登录</button>;
  }

  return <p>你好，{user.name}</p>;
}
```

这种写法适合两个分支差别很大时使用。

## 10.3 使用三元表达式

```jsx
function LoginStatus({ isLogin }) {
  return (
    <div>
      {isLogin ? <p>已经登录</p> : <p>未登录</p>}
    </div>
  );
}
```

三元表达式适合“二选一”。

```text
条件 ? 条件为 true 显示 : 条件为 false 显示
```

## 10.4 使用 && 短路渲染

```jsx
function Message({ unreadCount }) {
  return (
    <div>
      <h1>消息中心</h1>
      {unreadCount > 0 && <p>你有 {unreadCount} 条未读消息</p>}
    </div>
  );
}
```

`&&` 适合“满足条件才显示，不满足就什么都不显示”。

## 10.5 注意数字 0 的问题

下面写法可能显示一个 0：

```jsx
{list.length && <p>有数据</p>}
```

当 `list.length` 是 0 时，React 可能把 0 渲染出来。

更清楚的写法：

```jsx
{list.length > 0 && <p>有数据</p>}
```

## 10.6 loading、error、data 三态渲染

这是项目中最常见的条件渲染结构。

```jsx
function UserInfo({ loading, error, user }) {
  if (loading) {
    return <p>加载中...</p>;
  }

  if (error) {
    return <p style={{ color: 'red' }}>出错了：{error.message}</p>;
  }

  if (!user) {
    return <p>暂无用户</p>;
  }

  return <p>用户名：{user.name}</p>;
}
```

这种写法比把所有条件塞进一个 return 更容易读。

## 10.7 控制弹窗显示

```jsx
import { useState } from 'react';

export default function App() {
  const [open, setOpen] = useState(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>打开弹窗</button>

      {open && (
        <div className="modal">
          <h2>提示</h2>
          <p>这是一个弹窗</p>
          <button onClick={() => setOpen(false)}>关闭</button>
        </div>
      )}
    </div>
  );
}
```

## 10.8 条件决定 className

```jsx
function Button({ active }) {
  return (
    <button className={active ? 'btn active' : 'btn'}>
      按钮
    </button>
  );
}
```

复杂项目可以使用 clsx 或 classnames 这类工具库，但初学先掌握三元表达式即可。

## 10.9 条件渲染和显示隐藏的区别

条件渲染：条件不满足时，组件不存在。

```jsx
{open && <Panel />}
```

CSS 隐藏：组件还在，只是看不见。

```jsx
<Panel style={{ display: open ? 'block' : 'none' }} />
```

如果组件内部 state 要保留，可能使用 CSS 隐藏。如果不需要保留，条件渲染更干净。

## 10.10 常见错误

- 在 JSX 花括号里直接写 if 语句；
- 三元表达式嵌套太多，难以阅读；
- `list.length &&` 导致页面出现 0；
- 没有处理 loading、error、empty 状态；
- 条件切换导致组件卸载，里面的输入内容丢失，却不知道原因。

## 10.11 小结与练习

- if + return 适合大分支；
- 三元表达式适合二选一；
- `&&` 适合满足条件才显示；
- 注意 0 可能被渲染；
- 项目中一定要处理 loading、error、empty。

练习：

1. 写一个登录状态组件，登录显示用户名，未登录显示登录按钮。
2. 写一个空列表提示：没有数据时显示“暂无数据”。
3. 写一个弹窗，点击按钮打开，再点击关闭。
