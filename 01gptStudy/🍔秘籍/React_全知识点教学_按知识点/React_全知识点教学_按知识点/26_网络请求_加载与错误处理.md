# 26. 网络请求、加载状态与错误处理

## 26.1 本章要解决什么问题

前面的示例大多使用写死的数据。真实项目中，数据通常来自后端接口。

你需要学会：

- 发起 GET 请求读取数据；
- 发起 POST 请求提交数据；
- 显示加载中；
- 显示错误信息；
- 防止组件卸载后还更新 state；
- 处理请求竞态问题；
- 写出清晰的请求代码。

---

## 26.2 网络请求的基本状态

一个请求通常有三类状态：

```text
data：成功拿到的数据
loading：是否正在加载
error：是否发生错误
```

最基本结构：

```jsx
const [data, setData] = useState(null);
const [loading, setLoading] = useState(false);
const [error, setError] = useState(null);
```

页面根据状态显示：

```jsx
if (loading) return <p>加载中...</p>;
if (error) return <p>出错了：{error}</p>;
if (!data) return <p>暂无数据</p>;
```

## 26.3 fetch 发送 GET 请求

```jsx
import { useEffect, useState } from 'react';

export default function App() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    async function loadUsers() {
      try {
        setLoading(true);
        setError(null);

        const response = await fetch('https://jsonplaceholder.typicode.com/users');

        if (!response.ok) {
          throw new Error(`请求失败：${response.status}`);
        }

        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }

    loadUsers();
  }, []);

  if (loading) return <p>加载中...</p>;
  if (error) return <p>错误：{error}</p>;

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

重点：

- `useEffect` 用于组件显示后请求数据；
- `response.ok` 用于判断 HTTP 状态是否成功；
- `try...catch...finally` 处理成功、失败和收尾；
- 空依赖数组 `[]` 表示组件首次显示后请求一次。

---

## 26.4 不要直接把 useEffect 回调写成 async

错误：

```jsx
useEffect(async () => {
  const response = await fetch('/api/users');
}, []);
```

不推荐这样写。

正确：

```jsx
useEffect(() => {
  async function loadData() {
    const response = await fetch('/api/users');
  }

  loadData();
}, []);
```

原因：`useEffect` 的回调应该返回清理函数或不返回内容，而 `async` 函数返回 Promise。

## 26.5 点击按钮再请求

不是所有请求都要页面一打开就发送。

```jsx
import { useState } from 'react';

export default function App() {
  const [joke, setJoke] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  async function loadJoke() {
    try {
      setLoading(true);
      setError(null);

      const response = await fetch('https://official-joke-api.appspot.com/random_joke');
      if (!response.ok) {
        throw new Error('请求笑话失败');
      }

      const data = await response.json();
      setJoke(`${data.setup} ${data.punchline}`);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }

  return (
    <div>
      <button onClick={loadJoke} disabled={loading}>
        {loading ? '加载中...' : '获取笑话'}
      </button>

      {error && <p style={{ color: 'red' }}>{error}</p>}
      {joke && <p>{joke}</p>}
    </div>
  );
}
```

## 26.6 POST 提交 JSON 数据

```jsx
async function createUser(user) {
  const response = await fetch('/api/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(user),
  });

  if (!response.ok) {
    throw new Error(`创建失败：${response.status}`);
  }

  return await response.json();
}
```

使用：

```jsx
async function handleSubmit(e) {
  e.preventDefault();

  try {
    const savedUser = await createUser({ name: '小明', age: 18 });
    console.log('保存成功：', savedUser);
  } catch (err) {
    alert(err.message);
  }
}
```

## 26.7 请求取消 AbortController

如果组件已经卸载，请求还没回来，就不应该继续更新这个组件的 state。

可以使用 `AbortController`。

```jsx
import { useEffect, useState } from 'react';

export default function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController();

    async function loadUsers() {
      try {
        setLoading(true);
        setError(null);

        const response = await fetch('/api/users', {
          signal: controller.signal,
        });

        if (!response.ok) {
          throw new Error('请求失败');
        }

        const data = await response.json();
        setUsers(data);
      } catch (err) {
        if (err.name === 'AbortError') {
          return;
        }
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }

    loadUsers();

    return () => {
      controller.abort();
    };
  }, []);

  if (loading) return <p>加载中...</p>;
  if (error) return <p>{error}</p>;

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

更严谨一点：请求被取消时，`finally` 里也可能执行。项目中可以结合 `ignore` 标记或判断 `controller.signal.aborted`，避免取消后设置 loading。

## 26.8 防止旧请求覆盖新请求

用户快速切换 id 时，可能出现问题：

```text
请求 A 先发出，比较慢
请求 B 后发出，比较快
B 先回来，页面显示 B
A 后回来，又把页面覆盖成 A
```

可以用 `ignore` 标记。

```jsx
import { useEffect, useState } from 'react';

function UserDetail({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    let ignore = false;

    async function loadUser() {
      setLoading(true);

      const response = await fetch(`/api/users/${userId}`);
      const data = await response.json();

      if (!ignore) {
        setUser(data);
        setLoading(false);
      }
    }

    loadUser();

    return () => {
      ignore = true;
    };
  }, [userId]);

  if (loading) return <p>加载中...</p>;
  if (!user) return <p>暂无用户</p>;

  return <p>{user.name}</p>;
}
```

这表示：如果这个 effect 已经过期，就不要再更新 state。

## 26.9 抽取请求函数

不要把所有请求细节都写在组件里。

推荐：

```text
src/
  api/
    userApi.js
```

userApi.js：

```jsx
const BASE_URL = '/api';

export async function getUsers() {
  const response = await fetch(`${BASE_URL}/users`);

  if (!response.ok) {
    throw new Error('获取用户列表失败');
  }

  return await response.json();
}

export async function createUser(user) {
  const response = await fetch(`${BASE_URL}/users`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(user),
  });

  if (!response.ok) {
    throw new Error('创建用户失败');
  }

  return await response.json();
}
```

组件中：

```jsx
import { useEffect, useState } from 'react';
import { getUsers } from './api/userApi.js';

export default function App() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    getUsers().then(setUsers).catch(console.error);
  }, []);

  return <div>{users.length}</div>;
}
```

这样组件更干净。

## 26.10 自定义 Hook 封装请求

简单封装：

```jsx
import { useEffect, useState } from 'react';

export function useUsers() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let ignore = false;

    async function loadUsers() {
      try {
        setLoading(true);
        setError(null);

        const response = await fetch('/api/users');
        if (!response.ok) throw new Error('获取用户失败');

        const data = await response.json();
        if (!ignore) setUsers(data);
      } catch (err) {
        if (!ignore) setError(err.message);
      } finally {
        if (!ignore) setLoading(false);
      }
    }

    loadUsers();

    return () => {
      ignore = true;
    };
  }, []);

  return { users, loading, error };
}
```

使用：

```jsx
function UserList() {
  const { users, loading, error } = useUsers();

  if (loading) return <p>加载中...</p>;
  if (error) return <p>{error}</p>;

  return users.map((user) => <p key={user.id}>{user.name}</p>);
}
```

## 26.11 axios 简单认识

除了浏览器自带的 `fetch`，项目中也常用 axios。

安装：

```bash
npm i axios
```

示例：

```jsx
import axios from 'axios';

export async function getUsers() {
  const response = await axios.get('/api/users');
  return response.data;
}
```

本教材主要用 `fetch`，因为它是浏览器内置 API，更适合打基础。

## 26.12 请求错误要给用户看懂

不要只写：

```jsx
console.error(error);
```

用户看不到控制台。

建议页面显示：

```jsx
{error && (
  <div className="error">
    <p>加载失败：{error}</p>
    <button onClick={reload}>重新加载</button>
  </div>
)}
```

错误处理至少包含：

- 开发者能看到详细错误；
- 用户能看到友好提示；
- 必要时可以重试。

---

## 26.13 常见错误

- 忘记 `await response.json()`；
- 以为 `fetch` 遇到 404 会自动进入 catch；
- 不判断 `response.ok`；
- `useEffect(async () => {})`；
- 请求失败不显示错误；
- loading 永远不改回 false；
- 组件卸载后仍更新 state；
- 搜索请求返回顺序错乱，旧结果覆盖新结果。

---

## 26.14 小结与练习

本章重点：

- 请求一般有 `data`、`loading`、`error` 三种状态；
- `fetch` 请求后要判断 `response.ok`；
- GET 用于读取，POST 常用于创建；
- 请求可以抽到 `api` 文件；
- 可以用 `AbortController` 或 `ignore` 避免过期更新；
- 用户需要看到友好的错误提示。

练习：

1. 请求一个用户列表，显示加载中、成功、失败三种界面。
2. 写一个按钮，点击后重新加载数据。
3. 写一个 POST 提交函数。
4. 用 `ignore` 处理快速切换用户 id 的旧请求覆盖问题。
5. 把请求函数从组件中抽到 `src/api/userApi.js`。
