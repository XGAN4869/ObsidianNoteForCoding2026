# 11 小型博客项目：需求与设计

这是后续两节的统一目标。先设计，再写代码。

## 功能范围（第一版）

- 用户注册、登录。
- 查看已发布文章列表（分页）。
- 查看文章详情。
- 登录用户创建文章。
- 作者编辑和删除自己的文章。
- 作者发布/取消发布。
- 健康检查。

不在第一版实现评论、图片上传、富文本、关注、全文搜索，避免一次学太多。

## API 清单

| 方法 | 路径 | 认证 | 说明 |
|---|---|---|---|
| GET | `/health` | 否 | 服务状态 |
| POST | `/api/auth/register` | 否 | 注册 |
| POST | `/api/auth/login` | 否 | 登录并返回 token |
| GET | `/api/posts` | 否 | 已发布列表 |
| GET | `/api/posts/:id` | 否 | 已发布详情；作者可看自己的草稿 |
| POST | `/api/posts` | 是 | 创建草稿 |
| PATCH | `/api/posts/:id` | 是 | 作者更新 |
| DELETE | `/api/posts/:id` | 是 | 作者删除 |
| POST | `/api/posts/:id/publish` | 是 | 作者发布 |

## 数据流

```text
请求 -> express.json -> requestLog -> auth(需要时) -> route
     -> controller -> service -> repository/SQLite
     -> 统一 JSON 响应
     -> errorHandler（任何异常）
```

## 验收标准

1. 空标题返回 400，不写入数据库。
2. 未登录创建文章返回 401。
3. 非作者修改文章返回 403。
4. 删除成功返回 204。
5. 数据库错误返回 500，但不泄露 SQL 和堆栈。
6. `npm test` 全部通过。
