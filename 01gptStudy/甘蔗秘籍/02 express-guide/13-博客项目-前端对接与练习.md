# 13 博客项目：前端对接与练习

## Vue/React 调用接口

```js
const response = await fetch('http://localhost:3000/api/posts?page=1');
const payload = await response.json();
if (!response.ok) throw new Error(payload.error?.message || '请求失败');
posts.value = payload.data; // React 中改为 setPosts(payload.data)
```

登录后保存 token 时，教学项目可暂存在内存或 `sessionStorage`。高安全要求场景优先考虑 httpOnly Cookie，并配套 CSRF 防护；不要把长期密钥放 localStorage。

## 跨域

如果前端是 `http://localhost:5173`，后端是 `http://localhost:3000`，开发时是跨源请求。安装并配置 `cors` 时只允许明确来源：

```js
const cors = require('cors');
app.use(cors({ origin: 'http://localhost:5173' }));
```

生产环境把来源放配置中；CORS 只影响浏览器，不是权限系统。

## 分阶段练习

2. 给文章增加 `tags` 字段，并校验数组长度。
3. 新增管理员角色，只允许管理员删除他人文章。
4. 把内存数组换成 SQLite，写 migration。
5. 为 401、403、404、400 各写一个测试。
6. 添加请求 ID 和耗时日志。
