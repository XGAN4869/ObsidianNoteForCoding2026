# 03 路由与中间件

## 路由

路由由 HTTP 方法、路径和处理函数组成：

```js
app.get('/users', (req, res) => res.json([]));
app.post('/users', (req, res) => res.status(201).json({ ok: true }));
app.patch('/users/:id', (req, res) => res.json({ id: req.params.id }));
app.delete('/users/:id', (req, res) => res.sendStatus(204));
```

常见 REST 约定：集合用复数名词，创建返回 201，删除成功常用 204，找不到资源返回 404。

## 路径参数、查询参数、请求体

```js
app.get('/posts/:id', (req, res) => {
  const id = req.params.id;       // /posts/42 -> '42'
  const page = req.query.page;    // /posts?page=2 -> '2'
  res.json({ id, page });
});
```

三者都来自用户输入，必须校验；不要直接相信类型和内容。

## 中间件是什么

中间件函数形状是 `(req, res, next)`。它可以修改请求、返回响应，或调用 `next()` 交给下一个函数。

```js
function requestLog(req, res, next) {
  console.log(req.method, req.originalUrl);
  next();
}
app.use(requestLog);
```

顺序很重要：先注册的先执行。忘记 `next()` 且不发送响应，请求会一直等待。

## 内置中间件

```js
app.use(express.json({ limit: '1mb' }));
app.use(express.urlencoded({ extended: true }));
app.use(express.static('public'));
```

只在需要时启用；上传文件要使用专门的 multipart 中间件并限制大小。

## Router 拆分

`routes/posts.js`：

```js
const router = require('express').Router();

router.get('/', (req, res) => res.json([]));
router.get('/:id', (req, res) => res.json({ id: req.params.id }));

module.exports = router;
```

主文件：

```js
const postsRouter = require('./routes/posts');
app.use('/api/posts', postsRouter);
```

最终路径是 `/api/posts` 和 `/api/posts/:id`。

## 条件中间件与权限

```js
function requireAdmin(req, res, next) {
  if (!req.user || req.user.role !== 'admin') {
    return res.status(403).json({ error: 'forbidden' });
  }
  next();
}
```

`return` 用来避免发送响应后继续执行。
