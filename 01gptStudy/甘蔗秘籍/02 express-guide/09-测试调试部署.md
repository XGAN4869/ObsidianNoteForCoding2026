# 09 测试、调试与部署

## API 测试

推荐 `node:test`（Node 内置）配合 `supertest`：

```bash
npm install --save-dev supertest
```

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const request = require('supertest');
const app = require('../src/app');

test('GET /health returns ok', async () => {
  const res = await request(app).get('/health');
  assert.equal(res.statusCode, 200);
  assert.deepEqual(res.body, { ok: true });
});
```

测试要覆盖成功、缺参数、未登录、无权限、资源不存在和数据库异常。

## 手工调试

可使用浏览器 DevTools、curl 或 Postman：

```bash
curl -i http://localhost:3000/health
curl -i -X POST http://localhost:3000/api/posts ^
  -H "Content-Type: application/json" ^
  -d "{\"title\":\"测试\",\"content\":\"正文\"}"
```

Windows PowerShell 中换行符和引号与 Bash 不同；出错时先写成一行命令。

## 部署前检查

- `NODE_ENV=production`。
- 只从 `process.env` 读取密钥和数据库地址。
- 健康检查端点 `/health`。
- 反向代理（如 Nginx）负责 HTTPS 和静态资源时，正确设置 `trust proxy`。
- 日志、备份、监控和回滚方案已准备。

## 排错顺序

1. 看客户端状态码和响应体。
2. 看服务端日志中的请求 ID。
3. 确认路由方法、路径和中间件顺序。
4. 单独测试数据库查询。
5. 用最小复现用例写成回归测试。
