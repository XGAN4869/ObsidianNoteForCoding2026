## 版本说明

本文以 **App Router**（`app/` 目录）为主，示例使用 TypeScript。Next.js 会持续更新，安装后请以项目中的 `package.json`、官方文档和命令输出为准。本文不依赖某个未来版本的特有 API；遇到版本差异，先查官方迁移说明。

## 你会掌握什么

- 用文件夹和文件设计页面、布局、加载态、错误态和接口。
- 判断代码应放在 Server Component 还是 Client Component。
- 使用服务端数据获取、缓存、重新验证、动态路由和静态生成。
- 处理表单提交、Server Actions、鉴权、环境变量和安全边界。
- 从零完成一个带文章列表、详情、Markdown、管理表单和部署方案的小博客。

## 学习约定

文档中的命令默认在项目根目录执行。看到“验证”章节时务必亲自运行；看到“为什么”时先用自己的话复述。出错时保留完整错误信息，不要只截最后一行。
