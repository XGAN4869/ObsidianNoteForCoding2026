# Node.js 核心知识（1–87）

## 基础篇（1–16）

### 1. 概述
Node.js 是浏览器外运行 JavaScript 的运行时，由 V8、libuv 与 Node API 组成；它不是语言也不是框架。

### 2. 安装 Node
安装官网 LTS，验证 `node -v`、`npm -v`。PATH 变更后重开终端。

### 3–8. npm、package.json、install、run、npx、发布与私服
`package.json` 描述脚本和依赖；`npm install` 解析依赖并写 lock，CI 用 `npm ci`；`npm run` 使用本地 `.bin`；npx 执行 CLI；发布需递增版本并排除密钥；私服通过 `.npmrc` 配置 registry。

### 9–16. 模块、全局、渲染、path、os、process、子进程、FFmpeg
CJS 用 require，ESM 用 import；避免污染 global；CSR 在浏览器渲染、SSR 在服务器生成 HTML；路径用 `path.join`；系统信息用 `os`；参数和环境变量从 `process` 读取；`spawn` 处理长命令、`fork` 支持 IPC；FFmpeg 通过参数数组调用并检查退出码。

## 工具与网络（17–32）

### 17–25. events、util、pngquant、fs、crypto、CLI、Markdown、zlib
EventEmitter 提供 on/once/emit/off；util 可 promisify；图片压缩用 pngquant 子进程；文件大数据用流和 pipeline；密码使用 scrypt/argon2，令牌用随机字节和 HMAC；CLI 解析 argv 并返回退出码；Markdown 使用成熟解析器并过滤 XSS；gzip 响应要设置 Content-Encoding 与 Vary。

### 26–32. http、代理、动静分离、邮件、Express、请求响应头
http 服务必须结束响应并限制请求体；反向代理设置 X-Forwarded-*、超时和重试；静态资源交给 CDN/Nginx；SMTP 使用 TLS 与环境变量；Express 错误处理中间件四参数；Referer 只能弱校验，下载仍需鉴权；响应设置 CSP、Cache-Control 等安全头。

## 数据库与 ORM（33–43）

MySQL 使用主键、外键、索引和 DECIMAL；查询用参数化 SQL，分页优先游标；JOIN 防止笛卡尔积；mysql2 用连接池和事务；Knex migration 可回滚；Prisma 用 schema 和 `migrate deploy`；MVC 分离 Controller/Service/Repository；JWT 固定算法并设置过期、issuer、audience，敏感信息不放 payload。

## Redis 与 Lua（44–52）

Redis 支持 string/hash/list/set/zset，key 必须有 TTL；Pub/Sub 不保证离线消息，可靠投递用 Streams/队列；MULTI/EXEC 与 WATCH 实现事务；RDB 是快照、AOF 是命令日志；副本有延迟，Sentinel 负责故障转移；ioredis 需重连上限；Lua 脚本原子执行，适合限流计数，脚本要短小。

## 进阶服务与实战（53–74）

定时任务需锁与幂等；Serverless 有冷启动和时长限制；TCP 是字节流，net 服务要定义消息边界；Socket.IO 校验身份并处理重连；爬虫遵守条款与速率；Node-API 编写原生扩展；上传用分片、校验和、隔离目录；下载支持 Range；缓存区分强缓存与协商缓存；HTTP/2 依赖 TLS 和代理兼容；短链接校验 URL scheme；串口处理拔线和校验；SSO 用 OAuth2/OIDC，单设备登录撤销旧会话，扫码码值短期且防重放；OpenAI 密钥只放服务端并设超时预算；远程桌面强认证和审计；杀毒先隔离再扫描；OSS 使用预签名 URL；libuv 线程池不适合无限 CPU 任务；Fastify schema 驱动，网关负责鉴权、限流、路由和超时。

## 微服务、消息队列与部署（75–87）

微服务按业务边界拆分并承担网络成本；RabbitMQ 通过 exchange/queue/binding 路由，消费者确认、幂等和死信；Kafka 以 topic/partition/offset 工作，分区有序，重复消费需幂等键；Nacos 提供注册与动态配置，变更可审计回滚；Elasticsearch 用 keyword 精确过滤、text 全文检索，深分页用 search_after；cluster 多进程不共享内存；PM2 管理进程、日志、实例和优雅退出，部署执行 `npm ci`、迁移、健康检查与回滚。

## 通用安全原则

所有输入校验类型、长度和权限；SQL 参数化；文件限制大小并防路径穿越；密钥用环境变量；记录 request id、耗时和错误；生产不暴露堆栈，不用 root 运行。
