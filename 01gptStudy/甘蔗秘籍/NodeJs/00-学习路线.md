# Node.js 学习路线（给初级前端的慢速版）

这套笔记的目标不是背很多名词，而是让你可以**看懂、运行、修改、排错**一个 Node.js 小服务。

## 使用方法

1. 一次只读一个小节，不要一天读完全部文件。
2. 看到代码就复制到自己的练习目录运行。
3. 先猜结果，再运行。结果不同也没关系，差异就是要学习的地方。
4. 每章末尾的检查清单全部能回答“是”，再进入下一章。
5. 任何密码、Token、真实用户数据都不要放进练习代码或截图。

## 版本说明

示例以 Node.js 20 或更高的 LTS（长期支持）版本为准。Node.js、npm、Express、MySQL、Redis 等软件都在持续更新；遇到版本差异时，先看错误信息，再查对应版本的官方文档。

## 学习节奏建议

- 第 1 周：01–06，每天只做 1～2 个小实验。
- 第 2 周：07、08、10，能用浏览器或请求工具访问自己的 API。
- 第 3 周：11–14，先使用本地服务，理解数据和安全边界。
- 第 4 周：15–19，练习可靠性、测试和部署思维。

不要追求一次写出“大项目”。能解释一行代码、能定位一个错误，就是进步。
