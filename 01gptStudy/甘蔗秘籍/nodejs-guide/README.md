## 版本说明

Node.js、npm、Express 和数据库驱动都会更新。本文只使用长期稳定的核心概念；安装时选择当前仍受支持的 Node.js LTS，并以项目 `package.json` 与所用库的官方文档为准。不要把示例中的版本号当作永远不变的事实。

## 完成后的能力

你应能独立创建 Node.js 项目，理解事件循环和异步错误，读写文件，设计 HTTP API，连接数据库，实现认证、测试和部署，并能解释每个决定的原因。
