# 11 博客项目：需求与初始化

## 1. MVP 功能

- 公开文章列表和详情：`GET /api/posts`、`GET /api/posts/:slug`。
- 登录后的文章管理：创建、编辑、删除、草稿/发布。
- 标签、分页、搜索、健康检查。
- 统一错误格式、输入校验、日志和测试。

暂不做评论、多人协作和文件上传，先完成可验证闭环。

## 2. 初始化

```bash
mkdir node-blog && cd node-blog
npm init -y
npm install express dotenv
npm install -D typescript tsx @types/node @types/express
```

推荐结构：

```text
src/
├─ server.ts
├─ app.ts
├─ routes/posts.ts
├─ controllers/posts.ts
├─ services/posts.ts
├─ repositories/posts.ts
├─ middleware/auth.ts
├─ middleware/error.ts
├─ lib/env.ts
└─ types/
tests/
```

## 3. 数据模型

`User(id, email, passwordHash, role)`；`Post(id, slug, title, excerpt, content, status, authorId, publishedAt, createdAt, updatedAt)`；`Tag` 与关联表。slug 唯一；草稿没有公开 `publishedAt`；时间统一 UTC。

## 4. 配置和健康检查

启动时校验 `PORT`、`DATABASE_URL`、`SESSION_SECRET`。`GET /health` 只返回服务状态；更深入的数据库探针可单独做 readiness 检查，避免把敏感信息暴露给公网。
