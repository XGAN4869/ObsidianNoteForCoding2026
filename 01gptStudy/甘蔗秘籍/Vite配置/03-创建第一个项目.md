# 第 03 课：创建第一个 Vite 项目

## 本课目标

用官方 `create-vite` 脚手架创建一个原生 JavaScript 项目，安装依赖，启动开发服务器，修改文字，并正确停止服务器。为降低认知负担，本课只使用 npm 和 `vanilla` 模板。

## 选择一个安全位置

先在文件资源管理器里创建一个专门放练习的目录，例如 `D:\frontend-study`。目录名尽量只用英文字母、数字和短横线，避免第一次练习就遇到特殊字符或同步盘权限问题。在资源管理器地址栏输入 `powershell` 并回车，可以在这个目录打开 PowerShell。执行下面的命令创建项目：

```powershell
npm create vite@latest my-vite-app -- --template vanilla
```

把命令拆开看：`npm create` 表示运行项目创建器；`vite@latest` 表示使用当前最新版 create-vite；`my-vite-app` 是新目录名；额外的 `--` 用来把后面的参数转交给创建器；`--template vanilla` 选择不带 Vue、React 的原生 JavaScript 模板。第一次运行可能询问是否安装创建器，确认包名来自 `create-vite` 后按提示继续。

## 进入目录并安装

创建成功后逐行执行：

```powershell
cd my-vite-app
npm install
npm run dev
```

`cd` 是进入项目目录。`npm install` 根据 `package.json` 和锁文件安装依赖。`npm run dev` 启动开发服务器。终端会显示 Local 地址，默认通常是 `http://localhost:5173/`。按住 Ctrl 再单击链接，或把完整地址复制进浏览器。端口被占用时，Vite 可能寻找下一个可用端口，因此以终端实际显示的地址为准。

## 做第一次修改

服务器运行时不要关闭这个终端。在编辑器中打开 `my-vite-app` 整个目录，而不是只打开某一个文件。找到 `src/main.js`，把页面中的某一段可见文字改成“我的第一个 Vite 页面”，保存文件。回到浏览器，通常会很快更新，这就是开发体验中的 HMR。若没有变化，先确认文件已经保存，再确认浏览器地址正是终端显示的地址。

## 正确停止和重新启动

回到正在运行服务的 PowerShell，按 `Ctrl + C`。如果终端询问是否终止，按提示确认。浏览器刷新后无法访问是正常的，因为本地服务器已经停止。以后重新开发时，不必重新创建项目，只需打开项目目录的终端，执行：

```powershell
npm run dev
```

通常也不需要每次都运行 `npm install`。只有第一次获取项目、依赖记录发生变化，或者 `node_modules` 不存在时才需要安装。

## 不要做的事

不要在服务器运行时反复执行 `npm run dev`，这会创建多个进程和多个端口。不要把 `localhost` 理解成公网地址。不要把脚手架选择成一个自己还没学过的复杂框架，然后同时排查 Vite 和框架语法。不要因为终端出现普通提示就立刻删除 `node_modules`；先看最后几行是否真正包含 `error`。

## 检查点

你需要亲手完成五件事：项目目录出现；`package.json` 存在；`npm install` 成功；浏览器能打开终端显示的地址；修改 `src/main.js` 并保存后页面更新。最后用 `Ctrl + C` 停止服务器，再独立启动一次。如果这六步都能完成，你已经掌握了 Vite 最重要的基本循环。
