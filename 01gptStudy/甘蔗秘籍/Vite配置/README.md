# Vite 从零开始：慢速、清楚、可重复的学习路线

这套文档写给第一次接触 Vite、容易被大量新名词弄乱、需要把步骤拆得很细的初级前端学习者。你不需要一次记住全部内容，也不需要因为操作慢而着急。每次只打开一篇文档，只完成一个小目标。看到“检查点”时先停下来，确认屏幕上的结果与文档相同，再继续下一步。如果结果不同，不要连续乱点，也不要一次修改很多文件；先抄下报错，再查看第 14 课。

## 学习时固定使用的方法

每一课都按同一个顺序学习：第一遍只读“本课目标”和“先记住一句话”；第二遍照着命令操作；第三遍独立重复；最后回答复习问题。命令需要在项目目录的终端里执行。代码需要写进指定文件，不能把 JavaScript 代码直接输入 PowerShell。命令前面出现的 `$` 只是一些文档用来表示终端提示符的符号，不要复制 `$` 本身。本套教程统一使用 npm，先不要同时学习 Yarn、pnpm 或 Bun，避免把命令混在一起。

## 版本说明与准确性边界

本文在 2026-09-09 依据 Vite 官方中文文档核对，官方页面当时显示 Vite 8.2.2。当前主线要求 Node.js 20.19 以上，或者 Node.js 22.12 以上；某些框架模板可能要求更高版本。Vite 会持续更新，因此“概念与检查方法”比死记版本号更重要。开始新项目之前，请再次查看官方“开始”页面。教程只讲稳定、常用、适合初学者的能力，不把实验性选项当作默认方案。
