# 09 小型博客项目：需求与初始化

本实战做一个个人博客 MVP，重点是理解 Next.js，不追求复杂后台。

## 1. 功能范围

- 首页：最新文章列表。
- 文章详情：`/posts/[slug]`，展示标题、作者、日期、封面和 Markdown 正文。
- 标签筛选：`/tags/[tag]`。
- 管理页：登录用户创建/编辑/删除自己的文章。
- 状态：草稿、已发布。
- 404、加载态、错误态、响应式布局和 SEO 元数据。

刻意不做：多人协作、评论审核、支付、复杂富文本编辑器。先完成闭环，再扩展。

## 2. 建议技术栈

- Next.js App Router + TypeScript。
- 数据库：任意支持服务端连接的关系型数据库；开发阶段可用 SQLite，生产按平台选择托管数据库。
- ORM：选择团队熟悉且有当前版本文档的方案。
- Markdown：使用经过维护的解析器，并对 HTML 输出做清洗。
- 认证：采用成熟库，不手写密码哈希和会话协议。

## 3. 初始化

```bash
npx create-next-app@latest my-blog
cd my-blog
npm run dev
```

## 4. 数据模型

```text
User: id, name, email, role, createdAt
Post: id, slug(unique), title, excerpt, content, coverUrl,
      status(draft|published), authorId, publishedAt, createdAt, updatedAt
Tag: id, name(unique)
PostTag: postId, tagId（联合唯一）
```

`slug` 用于公开 URL，创建后谨慎修改；修改时应设置旧地址重定向。`publishedAt` 为草稿时可为空。所有时间统一存 UTC，展示时再按用户时区格式化。
