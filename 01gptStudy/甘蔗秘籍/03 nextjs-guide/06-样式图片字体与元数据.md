# 06 样式、图片、字体与元数据

## 1. 样式选择

- CSS Modules：组件级作用域，适合清晰稳定的样式。
- 全局 CSS：重置、主题变量、全局排版。
- Tailwind：用工具类快速构建，需统一设计 token。
- CSS-in-JS：确认与 Server Component、构建工具的兼容性后再用。

不要在业务组件中混用多套体系而没有约定。颜色、间距、断点等重复值应集中为变量或设计 token。

## 2. next/image

```tsx
import Image from 'next/image'

<Image src="/cover.jpg" alt="文章封面" width={1200} height={630} priority />
```

提供有意义的 `alt`；首屏最大图片可考虑 `priority`（按当前版本 API）；远程图片要在 Next 配置中明确允许的域名/模式。不要为了“方便”关闭优化并加载任意远程地址。

## 3. 字体

使用 `next/font` 可在构建时处理字体，减少布局跳动。只加载实际需要的字重；中文字体体积很大，更应评估子集化和 CDN 策略。

## 4. Metadata

静态元数据：

```ts
import type { Metadata } from 'next'
export const metadata: Metadata = {
  title: '我的博客',
  description: '记录前端学习。',
}
```

动态详情页可使用 `generateMetadata`，根据文章标题生成 title、description、Open Graph 图片。用户可控文本要经过安全处理。

## 5. 响应式与可访问性

- 从小屏开始设计，使用 CSS 媒体查询。
- 交互元素使用原生 `button`、`a`，不要用 `div` 冒充。
- 键盘可操作，焦点样式清晰，颜色对比度足够。
- 表单关联 `label`，错误信息与字段建立可读关系。
- 图片、图标和动态内容都有适当文本替代。
