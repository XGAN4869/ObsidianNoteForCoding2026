# 10 小型博客项目：页面与数据

## 1. 根布局与首页

```tsx
// app/page.tsx
import Link from 'next/link'
import { listPublishedPosts } from '@/lib/posts'
import PostCard from '@/components/PostCard'

export default async function HomePage() {
  const posts = await listPublishedPosts()
  return <main>
    <h1>我的博客</h1>
    <p>记录学习、工作与生活。</p>
    <section aria-label="最新文章">
      {posts.length === 0 ? <p>暂时没有文章。</p> : posts.map(post =>
        <PostCard key={post.id} post={post} />)}
    </section>
    <Link href="/admin/posts/new">写文章</Link>
  </main>
}
```

首页是服务端组件：数据在服务器取，浏览器只收到所需 HTML/客户端代码。

## 2. 文章卡片

```tsx
import Link from 'next/link'
import Image from 'next/image'
import type { PostSummary } from '@/lib/posts'

export default function PostCard({ post }: { post: PostSummary }) {
  return <article>
    {post.coverUrl && <Image src={post.coverUrl} alt="" width={640} height={360} />}
    <h2><Link href={`/posts/${post.slug}`}>{post.title}</Link></h2>
    <p>{post.excerpt}</p>
  </article>
}
```

## 3. 详情页、404 与元数据

```tsx
// app/posts/[slug]/page.tsx
import { notFound } from 'next/navigation'
import { getPublishedPost } from '@/lib/posts'

export default async function PostPage({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params
  const post = await getPublishedPost(slug)
  if (!post) notFound()
  return <article><h1>{post.title}</h1><PostBody content={post.content} /></article>
}
```

Markdown 转 HTML 后必须清洗，再交给展示组件；不要直接把数据库字段插入 `dangerouslySetInnerHTML`。`generateMetadata` 读取同一篇文章的标题和摘要，生成搜索和分享信息；对不存在文章返回合理的 not-found 行为。

## 4. 标签页与查询参数

`/tags/[tag]` 的 `params` 是路径标签；分页、搜索和排序放在 `searchParams`。服务端解析后把页码限制在合理范围，查询结果使用数据库分页，不要把全部文章读入内存再切片。

## 5. 加载与错误体验

```tsx
// app/posts/loading.tsx
export default function Loading() { return <p aria-live="polite">文章加载中……</p> }
```

为列表、详情和管理页分别考虑骨架屏、空状态、网络失败、文章不存在和无权限。`error.tsx` 需要客户端组件来调用 `reset`。

## 6. 缓存策略示例

公开已发布文章可使用时间重新验证；创建/编辑/删除成功后重新验证首页、标签页和详情路径。草稿只对作者可见，读取时必须带作者条件并避免公共缓存。缓存策略应写在 `lib/posts.ts` 的函数旁边，便于审查。
