# 01 环境与学习方法

## 1. Node.js 是什么

Node.js 是让 JavaScript 在浏览器之外运行的运行时。它使用 V8 执行 JavaScript，并提供文件系统、网络、进程、加密等服务端 API。

浏览器 JavaScript 主要操作 DOM；Node.js 没有 DOM，却可以监听端口、读数据库、处理文件和运行命令。Node.js 不是一种新语言，语法仍是 JavaScript。

## 2. 安装与检查

安装当前受支持的 LTS 版本，然后运行：

```bash
node --version
npm --version
```

建议使用版本管理器（Windows 可选择 nvm-windows 等成熟方案），团队在项目中固定 Node 主版本。开发、CI 和生产环境尽量保持一致。

## 3. 第一个程序

```js
// hello.js
console.log('你好，Node.js')
console.log(process.version)
```

运行：`node hello.js`。命令行参数在 `process.argv`，当前工作目录在 `process.cwd()`。

## 4. 创建项目

```bash
mkdir node-blog
cd node-blog
npm init -y
git init
```

`package.json` 记录项目名称、脚本和依赖；`package-lock.json` 锁定精确依赖树，应提交到 Git。常用脚本：

```json
"scripts": {
  "dev": "node --watch src/server.js",
  "start": "node src/server.js",
  "test": "node --test"
}
```

Node 内置 `--watch`、`node:test` 等能力会随版本演进；若团队使用 tsx、Vitest 或 Jest，要把理由和版本写清楚。

## 5. 你必须建立的服务端思维

1. 请求不是可信输入，所有数据都要校验。
2. 一个进程会同时处理许多请求，不能用阻塞操作拖住事件循环。
3. 进程可能随时重启，本地内存和磁盘不是可靠的共享存储。
4. 失败是正常分支：网络、数据库、权限和超时都要处理。
5. 日志不能泄露密码、Token、Cookie 和个人敏感信息。

## 6. 推荐学习方式

每学一个 API 都完成“最小例子 → 故意制造错误 → 加测试 → 写一句自己的解释”。先掌握 Node 核心，再学习 Express、数据库和部署，不要把框架魔法误认为 Node 本身。
