# 16 实时通信、爬虫和子进程

## 1. WebSocket 与 Socket.IO

WebSocket 是客户端和服务器保持长连接、双向发送消息的协议。连接建立后仍要做身份验证、消息大小限制、权限判断和心跳/超时处理。Socket.IO 提供房间、重连等更高层能力，但重连后消息是否丢失仍要由业务决定。

## 2. TCP 与消息边界

TCP 是字节流，不自带“一个消息就是一次 read”的边界。协议必须自行定义长度前缀、换行符或固定长度。Node `net` 服务要处理半包、粘包、超时和断开；不能把一次 `data` 事件当成完整业务消息。

## 3. `spawn`、`fork` 与 `exec`

```js
import { spawn } from 'node:child_process'

const child = spawn('ffmpeg', ['-i', 'input.mp4', 'output.mp4'], {
  stdio: ['ignore', 'pipe', 'pipe']
})
child.stderr.on('data', chunk => console.error(chunk.toString()))
child.on('close', code => console.log('退出码：', code))
```

`spawn` 适合长时间进程和流式输出；`fork` 专门启动另一个 Node 模块并支持 IPC；`exec` 会通过 shell 执行字符串，除非充分固定命令，否则不要把用户输入传给它。所有子进程都要设超时、处理退出码并清理临时文件。

## 4. 爬虫和外部 API

遵守网站条款、robots 规则和速率限制；设置超时、最大响应大小、重试退避和 User-Agent。外部 API 不稳定时，记录状态码和 request id，不要无限重试造成雪崩。

## 5. 其他服务边界

串口服务要处理拔线、校验和与重连；远程桌面要强认证、最小权限和审计；SSO 优先使用 OAuth2/OIDC，扫码码值短期有效并防重放；调用 AI 服务时密钥只放服务端，并设置超时和预算。
