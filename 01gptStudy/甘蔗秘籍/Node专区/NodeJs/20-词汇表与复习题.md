# 20 词汇表与复习题

## 词汇表

| 词 | 简单解释 |
|---|---|
| runtime | 运行 JavaScript 的环境，Node.js 就是运行时 |
| event loop | 安排异步回调的循环机制 |
| Promise | 表示未来成功或失败的结果 |
| stream | 分段处理数据的接口，适合大文件 |
| backpressure | 下游处理慢时让上游放慢 |
| module | 可导入/导出的代码文件 |
| middleware | 请求经过的中间处理函数 |
| API | 程序之间约定的调用界面 |
| status code | HTTP 响应状态码 |
| connection pool | 可复用的数据库连接集合 |
| transaction | 一组要全部成功或全部回滚的操作 |
| cache | 临时保存，减少重复计算或查询 |
| TTL | 数据自动过期前的时间 |
| idempotency | 重复执行仍得到可接受的同一结果 |
| ack | 消费者确认消息已处理 |
| offset | Kafka 消费位置 |
| graceful shutdown | 关闭前停止新工作并清理资源 |
| liveness/readiness | 进程存活/是否准备接流量 |

## 小测验答案提示

- “运行时”不是语言；语言是 JavaScript。
- Promise 的错误必须被等待并捕获。
- lock 文件帮助团队得到一致依赖版本。
- 用户只能通过 ID 访问自己拥有的资源。
- 大文件和网络正文都应有大小限制。
- 重试会带来重复执行，所以要幂等键。
