```plainText

│  │   │  {                                          │    │  │
│  │   │    length: 5,                               │    │  │
│  │   │    // 这里只有一个指针，指向外部内存          │    │  │
│  │   │    // 真正的字节数据不在这里                  │    │  │
│  │   │  }                                          │    │  │
│  │   └──────────────────┬──────────────────────────┘    │  │
│  │                      │                                │  │
```

- Buffer 对象本身（JS 层）在 V8 堆里，但它只是一个“壳”
    
- 真正的字节数据在 V8 堆之外的 C++ 内存里
    
- JS 层通过一个**外部指针**访问那块内存

### WHY？
**Buffer 对象本身（那个壳）在 V8 堆里，但真正的字节数据在 Node.js C++ 层单独分配的内存中**
V8 堆默认大小是 1.5G~4G，垃圾回收回扫描堆里面的所有对象，文件太大耗性能、Node.js 底层是 C++（libuv、文件系统、网络），不需要额外从 C++ 内存拷贝到 V8
```js
// fs.readFile 内部：
// 1. C++ 分配一块内存
// 2. 读文件到这块内存
// 3. 创建一个 Buffer 对象，指向这块内存
// 4. 返回给 JS
// 全程只有一次分配，没有拷贝
```
