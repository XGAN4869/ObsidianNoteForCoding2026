# 模块关系写作规则

README 最后一个二级标题必须是：

```markdown
## 模块之间的关系
```

该节内只能使用两个三级标题：

## 调用关系

说明模块之间真实存在的数据流和调用顺序。可以使用短列表或 Mermaid 图，但节点必须来自用户提供的模块。

使用 Mermaid 时：

````markdown
```mermaid
flowchart LR
  A[UserForm] --> B[useInitForm]
  B --> C[request]
```
````

如果模块之间没有直接调用关系，必须明确写“这些模块可以独立使用，下面是推荐组合方式”，不要强行虚构依赖。

## 综合示例

给出一个完整、可直接复制的综合示例，至少串起：

- 一个 Vue 组件
- 一个组合式 Hook 或工具函数
- 数据请求
- 成功和失败分支

示例代码必须带注释，并明确 import 来源。不能使用省略号或未定义变量。

如果用户只提供了一个模块，也要写综合示例，展示它在真实页面中的完整接入方式，并说明当前没有其他模块与之组合。
