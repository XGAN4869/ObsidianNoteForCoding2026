## 输出重点

- 不要只写代码摘要，要写成可画图的节点和边。
- 组件层之外，继续追 `App/store/services/Storage/API`。
- 每条链路都尽量写成：
  - 状态被谁持有
  - 方法被谁触发
  - 数据传给谁
  - 改完怎么回流
- Storage 要单独成表，不要散落在正文里。
- 如果存在多层状态源，明确区分：
  - 业务状态
  - runtime 状态
  - 失败补偿状态
