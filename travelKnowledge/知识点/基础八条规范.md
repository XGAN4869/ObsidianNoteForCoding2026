### 3. 配置常量单独抽离
- 下拉框 / 单选框选项：比如奖惩表单的 options 的 v-for
- 业务枚举值/特殊标记值，用来判断逻辑的，比如 complaint 那边的权限字段，也就是一个不变的常量
	- 优点：这样以后如果后端把 `'奖励'` 改成 `'REWARD'`，你只改一个地方
	```js
	REWARD_TYPE === '奖励'
	
	formData.type === REWARD_TYPE
	const isRewardType = computed(() => formData.type === REWARD_TYPE)
	const isPunishType = computed(() => formData.type === PUNISH_TYPE)
	```
- 组件默认配置（类似下拉框
	```js
	<t-date-picker
	  :placeholder="defaultConfig.placeholder"
	  :valueType="defaultConfig.valueType"
	  :format="defaultConfig.format"
	/>
	const defaultConfig = {
	  placeholder: '请选择日期',
	  format: 'YYYY-MM-DD',
	  valueType: 'YYYY-MM-DD',
	}
	```
