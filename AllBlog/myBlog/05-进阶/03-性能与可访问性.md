# 03 · 性能与可访问性

> 让博客跑得快，让残障人士也能用。

---

## 一、性能基础

### 三个核心指标

**Google 定义的 Core Web Vitals**：

| 指标 | 全称 | 目标值 | 含义 |
| --- | --- | --- | --- |
| **LCP** | Largest Contentful Paint | < 2.5s | 最大内容画出来的时间 |
| **FID / INP** | First Input Delay | < 100ms | 用户第一次交互到响应 |
| **CLS** | Cumulative Layout Shift | < 0.1 | 页面元素乱跳的程度 |

> Next.js 默认 **SSG（静态生成）**，**LCP 几乎天然达标**。

## 三、图片优化

### 用 `next/image`

```tsx
import Image from 'next/image';

// ✅ 推荐
<Image src="/cover.png" alt="封面" width={800} height={300} />

// ❌ 不要
<img src="/cover.png" alt="封面" />
```

**优点**：
- 自动转 WebP/AVIF（**省 30-50% 体积**）
- 自动 srcset（不同屏幕加载不同大小）
- Lazy load（**图片不在视口里时不加载**）

### 像素图特殊处理

像素图**不能被压缩**，所以：

```tsx
<Image
  src="/sprites/cat.png"
  alt="猫"
  width={32}
  height={32}
  unoptimized  // ← 关键：跳过 Next.js 的优化
/>
```

## 四、字体优化

### 用 `next/font`

我们已经用了，**自动优化**：
- 自托管（不需要请求 Google）
- 自动子集化（只下载用到的字符）
- 预加载

```tsx
import { VT323 } from 'next/font/google';

const vt323 = VT323({
  weight: '400',
  subsets: ['latin'],
  display: 'swap',
});
```

### 国内访问 Google Fonts

**国内访问 Google Fonts 不稳定**。

解决：用 `display: 'swap'` + 本地字体备份。

```tsx
const vt323 = VT323({
  weight: '400',
  subsets: ['latin'],
  display: 'swap',  // ← 关键：字体未加载完时用系统字体
  fallback: ['monospace'],  // 备用字体
});
```

或者**完全本地化**：

```ts
// 把字体文件放到 public/fonts/
import localFont from 'next/font/local';

const vt323 = localFont({
  src: '../public/fonts/VT323-Regular.ttf',
  display: 'swap',
});
```

## 五、JavaScript 优化

### 减少 client component

```tsx
// ❌ 默认是 server component，但你加了 'use client' → 整个组件都打包到客户端
'use client';
export function MyComponent() { ... }

// ✅ 拆：交互的部分 client，纯展示的部分 server
// server:
export default async function Page() {
  const data = await getData();
  return (
    <div>
      <Header />          {/* server */}
      <InteractivePart data={data} />  {/* client */}
    </div>
  );
}

// client:
'use client';
export function InteractivePart({ data }) {
  const [state, setState] = useState();
  // ...
}
```

### 动态导入

```tsx
import dynamic from 'next/dynamic';

// 不在初始加载里
const HeavyComponent = dynamic(() => import('@/components/Heavy'), {
  ssr: false,
  loading: () => <PixelSpinner />,
});
```

## 六、CSS 优化

### Tailwind 自动 purge

Tailwind 默认 **purge 没用到的 class**：

```ts
content: ['./src/**/*.{ts,tsx,mdx}'],  // ← 扫描这些文件里的 class
```

我们的 `tailwind.config.ts` 已经配置了。

### 避免内联大 CSS

```tsx
// ❌ 不好
<div style={{ background: '...', padding: '...', margin: '...' }}>

// ✅ 好
<div className="bg-fg p-4 m-4">
```

## 七、可访问性（a11y）

> 让色弱 / 视障 / 用键盘 / 用读屏器的用户也能用。

### 1. 语义化 HTML

```tsx
// ❌ 用一堆 div
<div onClick={...}>点我</div>

// ✅ 用 button
<button onClick={...}>点我</button>
```

| ❌ 不用 | ✅ 用 |
| --- | --- |
| `<div onClick>` | `<button>` |
| `<a onClick>` | `<a href>` 或 `<button>` |
| `<span class="title">` | `<h1>` / `<h2>` |
| `<div class="list">` | `<ul>` / `<ol>` |

### 2. alt 文本

```tsx
// ✅ 信息图
<Image src="/chart.png" alt="2026 年访问量趋势" />

// ✅ 装饰图
<Image src="/decoration.png" alt="" />

// ❌ 忘写 alt
<Image src="/chart.png" />
```

### 3. 键盘导航

我们的组件**默认支持 Tab / Enter / Esc**。

**自检**：
- [ ] 能用 Tab 走到所有交互元素
- [ ] Enter / Space 能触发按钮
- [ ] Esc 能关闭模态框
- [ ] 焦点指示器可见

焦点指示器（在 `globals.css`）：

```css
:focus-visible {
  outline: 2px solid var(--fg);
  outline-offset: 2px;
}
```

### 4. 颜色对比度

> **黑白配色天然达标**：
> - 白底黑字：21:1（最高对比度）
> - 黑底白字：21:1
>
> 但**深灰文字**在白底上只有 4.5:1，**不够**。

**自检**：
- 所有文字用 `--fg` 或 `--bg`，**不要用中间灰**

### 5. ARIA 属性

```tsx
// 装饰图标
<PixelSpinner aria-hidden="true" />

// 屏幕阅读器才能看到的文字
<button aria-label="关闭">
  <XIcon aria-hidden="true" />
</button>

// 当前页
<Link href="/" aria-current="page">[首页]</Link>

// 模态框
<div role="dialog" aria-modal="true" aria-labelledby="modal-title">
  <h2 id="modal-title">标题</h2>
</div>
```

### 6. 跳过导航

加"跳到主内容"链接（在 `layout.tsx`）：

```tsx
<a
  href="#main"
  className="
    absolute left-0 top-0
    p-2 bg-fg text-bg
    -translate-y-full
    focus:translate-y-0
    transition-none
    z-50
  "
>
  跳到主内容
</a>

<main id="main">...</main>
```

## 十、常见性能问题

### 问题 1：图太大

**症状**：LCP > 4s。

**解决**：
- 用 `next/image`
- 像素图用 `unoptimized`
- 封面图压缩到 < 200 KB

### 问题 2：字体加载慢

**症状**：FOIT（Flash of Invisible Text）—— 文字先不显示，字体加载完才显示。

**解决**：
- `display: 'swap'`（字体未加载完先用系统字体）
- `preload: true`（关键字体预加载）

### 问题 3：组件太多 client

**症状**：bundle 太大。

**解决**：
- 把能 server 的放 server
- 用 `dynamic()` 拆
