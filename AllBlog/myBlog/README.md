# 个人博客搭建教程 · 总目录

> 师傅写给"智力障碍"初级前端的、一步一步看得懂的全套教程。
> 全程手把手，配图、命令、代码、解释一个不漏。

---

## 这是什么

这是一份**极简像素风个人博客**的全套搭建教程。最终效果类似 1-bit 黑白像素的电子相框：

- 黑底白像素 / 白底黑像素，**两种主题一键切换**
- 一个像素小人、一只像素猫、一盏像素吊灯、一本像素日记、一扇像素门
- 内容有：**随笔博客 / 时光胶囊 / 代办清单 / 关于我 / 留言板 / 友链 / 自定义模块**
- 部署上线后，全世界都能访问

视觉风格示意（参考图）：

| 深色模式 | 浅色模式 |
| --- | --- |
| 黑底白像素 | 白底黑像素 |
| 单色 1-bit | 单色 1-bit |

---

## 怎么用这份教程

按顺序读，**不要跳**。

1. **先看 `01-方案/`**：知道我们要做什么、用什么、为什么这么做。
2. **再走 `02-环境搭建/`**：把电脑装好，把项目跑起来。
3. **然后 `03-基础架构/`**：学会像素风的"积木块"，以后反复用。
4. **最后 `04-模块开发/`**：一个模块一个模块拼起来。
5. **进阶** `05-进阶/`：上线、SEO、性能调优。
6. **附录** `06-附录/`：找资源、查字体、排雷。

## 你需要准备什么

| 准备 | 说明 |
| --- | --- |
| 一台电脑 | Windows / macOS / Linux 都可以，**跟着教程一步一步来** |
| 至少 2 小时 | 第一天能跑起来"Hello"就行 |
| 一点点耐心 | **别跳步骤**，别赶进度 |
| 一个 GitHub 账号 | 用于部署、留言板、域名（可选） |

## 学习路径建议

| 你的情况 | 建议路径 |
| --- | --- |
| **完全没碰过前端** | 全程跟读，不要省略，先跑通再理解 |
| **写过 HTML/CSS** | 可以跳过 `02-环境搭建/` 里基础部分 |
| **写过 React** | 直接看 `03-基础架构/` 和 `04-模块开发/` |
| **只想看效果** | 把整份 `docs/` 喂给 AI，让它给你一气呵成（但你会学不到东西） |
