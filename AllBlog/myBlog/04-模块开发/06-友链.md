## 一、友链是什么

友链 = **一个页面，列出你认可的其他博客**。

```

│ [·] 阿文的博客                       │
│     https://awen.me                  │
│     一个写代码和音乐的博客            │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ [·] 小明的日记                       │
│     https://xiaoming.dev             │
│     像素艺术 + 独立游戏              │
└──────────────────────────────────────┘
```

**友链 = 互相认可**：你列我的，我列你的，大家流量共享。

## 三、读取数据

新建 `src/lib/friends.ts`：

```ts
import friendsData from '@/../data/friends.json';
import type { Friend } from '@/types/friend';

const friends = friendsData as Friend[];

export function getAllFriends(): Friend[] {
  return friends;
}

/**
 * 获取 favicon URL
 * 如果 friend 自带 avatar 就用 avatar，否则用 Google 的 favicon 服务
 */
export function getFaviconUrl(friend: Friend): string {
  if (friend.avatar) return friend.avatar;
  try {
    const domain = new URL(friend.url).hostname;
    return `https://www.google.com/s2/favicons?domain=${domain}&sz=64`;
  } catch {
    return '';
  }
}
```

> Google favicon 服务国内访问**不稳定**。如果失败，可以用 `https://api.faviconkit.com/{domain}/64`。

新建 `src/components/friend/FriendCard.tsx`：

```tsx
import { PixelCard } from '@/components/pixel';
import { getFaviconUrl } from '@/lib/friends';
import type { Friend } from '@/types/friend';
import Image from 'next/image';

export function FriendCard({ friend }: { friend: Friend }) {
  const favicon = getFaviconUrl(friend);

  return (
    <a
      href={friend.url}
      target="_blank"
      rel="noopener noreferrer"
      className="no-underline"
    >
      <PixelCard interactive>
        <div className="p-4 flex items-start gap-4">
          {/* 头像 / favicon */}
          <div className="w-16 h-16 border-2 border-fg shrink-0 bg-bg flex items-center justify-center overflow-hidden">
            {favicon ? (
              <Image
                src={favicon}
                alt={friend.name}
                width={64}
                height={64}
                className="object-contain w-full h-full"
                unoptimized
                onError={(e) => {
                  // 加载失败时显示默认图标
                  (e.currentTarget as HTMLImageElement).style.display = 'none';
                }}
              />
            ) : (
              <span className="text-2xl">·</span>
            )}
          </div>

          {/* 信息 */}
          <div className="flex-1 min-w-0">
            <h2 className="text-2xl font-bold">{friend.name}</h2>
            <p className="text-sm mt-1 break-all">{friend.url}</p>
            {friend.description && (
              <p className="mt-2">{friend.description}</p>
            )}
          </div>

          {/* 箭头 */}
          <span className="text-2xl shrink-0">↗</span>
        </div>
      </PixelCard>
    </a>
  );
}
```

## 六、自动从 URL 抓 favicon（高级）

如果 `data/friends.json` 里很多没填 `avatar`，可以写个脚本**批量抓**。

### `scripts/update-favicons.ts`

```ts
import fs from 'node:fs';
import path from 'node:path';
import https from 'node:https';

interface Friend {
  name: string;
  url: string;
  description: string;
  avatar?: string;
}

const friendsPath = path.join(__dirname, '../data/friends.json');
const friends: Friend[] = JSON.parse(fs.readFileSync(friendsPath, 'utf-8'));

async function getFavicon(domain: string): Promise<string> {
  // 试 /favicon.ico
  return new Promise((resolve) => {
    const url = `https://${domain}/favicon.ico`;
    https.get(url, (res) => {
      if (res.statusCode === 200) resolve(url);
      else resolve('');  // 失败
    }).on('error', () => resolve(''));
  });
}

(async () => {
  for (const friend of friends) {
    if (friend.avatar) continue;
    try {
      const domain = new URL(friend.url).hostname;
      const faviconUrl = await getFavicon(domain);
      if (faviconUrl) {
        friend.avatar = faviconUrl;
        console.log(`✓ ${friend.name}: ${faviconUrl}`);
      } else {
        console.log(`✗ ${friend.name}: 没找到`);
      }
    } catch (e) {
      console.error(`✗ ${friend.name}: ${e}`);
    }
  }

  fs.writeFileSync(friendsPath, JSON.stringify(friends, null, 2));
  console.log('完成');
})();
```

在 `package.json` 加：

```json
{
  "scripts": {
    "favicons": "tsx scripts/update-favicons.ts"
  }
}
```

跑：

```bash
pnpm add -D tsx
pnpm favicons
```

> ⚠️ **隐私问题**：抓 favicon 时，你的脚本会访问对方网站，**对方能看到你的 IP**。
> 介意的话用 Google favicon API：但国内访问不稳定。

## 九、找朋友的方法

> "我刚搭博客，谁跟我换友链？"

1. **加同类博客的 QQ / 微信群**：搜"博客交流"、"友链互换"
2. **在 R V 站（如 RST、NodeSeek）发帖**："建了个新博客，求互链"
3. **自己主动**：找喜欢的博客，**主动**给对方留言 / 邮件申请

**师傅的个人建议**：

> 友链的价值在"互访"，不在"挂链"。
> 真正读朋友的博客，**比挂 100 个死链有用**。
