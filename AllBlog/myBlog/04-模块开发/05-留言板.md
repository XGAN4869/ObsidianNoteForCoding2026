# 05 · 留言板

> 让访客在你的博客上留言。
> **用 Giscus**：免费、无广告、自动同步到 GitHub Discussions。

---

## 一、为什么用 Giscus

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| **Giscus**（推荐） | 免费、Markdown、支持表情、无广告 | 访客得有 GitHub 账号 |
| **Disqus** | 老牌、用户多 | **广告多、丑、加载慢** |
| **自建**（SQLite） | 完全可控 | 防垃圾留言烦 |
| **Valine** / **Waline** | 简单 | 还是要后端 |

**Giscus 最适合个人博客**——直接挂在 GitHub Discussions 上，**你的仓库你控制**。

---

## 二、Giscus 是什么

- 基于 **GitHub Discussions** 的评论系统
- 开源：<https://github.com/giscus/giscus>
- 访客用 GitHub 账号登录、留言
- 评论存到 **你的仓库的 Discussions**
- **你（仓库管理员）** 可以随时删评论、锁 Discussion

---

## 三、配置 Giscus（一步步来）

### 步骤 1：开 GitHub Discussions

1. 打开你的 GitHub 仓库页面（比如 `yourname/pixel-blog`）
2. 点 **Settings**（仓库的 Settings，不是账号的）
3. 滚到 **Features** 部分
5. 勾 **☑️ Discussions**
6. 点 **Set up discussions**
7. 进入 Discussions 页面，按提示创建第一个分类（比如 "General"）

### 步骤 2：装 Giscus App

1. 打开 <https://github.com/apps/giscus>
2. 点 **Install**
3. 选 **Only select repositories**
4. 选你的 `pixel-blog` 仓库
5. 确认安装

### 步骤 3：拿 Giscus 配置

1. 打开 <https://giscus.app/>
2. 填表：

| 字段 | 填什么 |
| --- | --- |
| **Repository** | 你的 `用户名/pixel-blog` |
| **Discussion category** | 刚才建的分类，比如 `Announcements` 或 `General` |
| **Mapping** | 选 `pathname`（推荐，URL 决定 discussion） |
| **Theme** | 选 `light` 或 `dark`（稍后我们做切换） |
| **Language** | `zh-CN` |

3. 滚到 **Enable giscus** 区域
4. 复制给你的 script 标签里的 **`data-repo`、`data-repo-id`、`data-category`、`data-category-id`**

### 步骤 4：装包

```bash
pnpm add @giscus/react
```

### 步骤 5：建组件

新建 `src/components/GiscusComments.tsx`：

```tsx
'use client';

import Giscus from '@giscus/react';
import { useTheme } from '@/hooks/useTheme';

export function GiscusComments() {
  const { theme, mounted } = useTheme();

  if (!mounted) {
    return <div className="border-2 border-fg p-8 text-center">评论区加载中...</div>;
  }

  return (
    <Giscus
      id="comments"
      repo="yourname/pixel-blog"           // ← 改成你的
      repoId="R_xxxxx"                    // ← 改成你的
      category="Announcements"            // ← 改成你的
      categoryId="DIC_xxxxx"              // ← 改成你的
      mapping="pathname"
      term="Welcome to PixelBlog!"
      strict="0"
      reactionsEnabled="1"
      emitMetadata="0"
      inputPosition="top"
      theme={theme === 'dark' ? 'dark' : 'light'}
      lang="zh-CN"
      loading="lazy"
    />
  );
}
```

> **主题方案**：Giscus 自带 `light`、`dark`、`preferred_dimmed` 等主题。
> 我们根据 useTheme 切换。

## 六、自定义 Giscus 主题（可选）

Giscus 默认主题跟我们的 1-bit 像素风**不完全一致**。

### 方案 A：用 Giscus 自带的"transparent_dark"

`theme="transparent_dark"` —— 透明背景，跟你的暗色主题融合。

### 方案 B：自定义主题

打开 <https://giscus.app/> → 选 **Custom** → 在 CSS 框里改样式：

```css
/* 你的浅色主题 */
:root {
  --color-primary: #000000;
  --color-background: #ffffff;
  --color-text: #000000;
  --color-border: #000000;
}

/* 你的暗色主题 */
:root[data-theme='dark'] {
  --color-primary: #ffffff;
  --color-background: #000000;
  --color-text: #ffffff;
  --color-border: #ffffff;
}
```

把这段 CSS 拷到 Giscus 的"Custom CSS"输入框里。

### 方案 C：完全用 iframe + 自己的样式

**不用 Giscus 库**，直接用 `<iframe>` 嵌入：

```tsx
export function GiscusIframe() {
  return (
    <iframe
      src="https://giscus.app/embed?repo=yourname/pixel-blog&..."
      style={{
        width: '100%',
        border: 'none',
        minHeight: '300px',
      }}
    />
  );
}
```

> 但这样**主题切换需要刷新 iframe**，体验差。

## 七、防止 spam

Giscus 内置 GitHub 登录门槛，**几乎没有 spam**。

如果真碰到 spam：
1. 进 GitHub 仓库 → Discussions
2. 找到 spam 评论
3. 删除（或锁定整个 Discussion）

## 九、备选方案：纯本地留言板

> 如果你不想让访客用 GitHub 登录，**可以**做本地版。

**缺点**：你自己要审核所有留言，**防 spam 烦**。

### 简单方案

API 路由 `src/app/api/messages/route.ts`：

```ts
import { NextResponse } from 'next/server';
import { Octokit } from '@octokit/rest';

const octokit = new Octokit({ auth: process.env.GITHUB_TOKEN });
const [owner, repo] = (process.env.GITHUB_REPO ?? '').split('/');
const FILE_PATH = 'data/messages.json';

// 留言需要审核，默认放在 messages-pending.json
// 你审核后移到 messages.json

export async function GET() {
  // 读 messages.json（已审核）
  try {
    const { data } = await octokit.repos.getContent({
      owner,
      repo,
      path: FILE_PATH,
    });
    if (Array.isArray(data)) return NextResponse.json([]);
    const content = Buffer.from(data.content, 'base64').toString('utf-8');
    return NextResponse.json(JSON.parse(content));
  } catch {
    return NextResponse.json([]);
  }
}

export async function POST(request: Request) {
  const body = await request.json();
  // 简单校验
  if (!body.author || !body.content) {
    return NextResponse.json({ error: 'invalid' }, { status: 400 });
  }
  // 加 rate limit（防止 spam）
  // （实际项目用 upstash/ratelimit）

  // 存到 pending
  // ... 类似 capsules 的逻辑
  return NextResponse.json({ success: true });
}
```

**做不做，看你**。**师傅推荐 Giscus**——简单、省事、不用防 spam。
