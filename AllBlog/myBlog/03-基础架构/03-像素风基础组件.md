## 二、组件设计原则

### 5 条铁律

1. **永远不传 Tailwind class 进来**（除了 `className`）
2. **永远用 CSS 变量**（颜色跟主题）
3. **永远有 `forwardRef`**（方便 ref 传递）
4. **永远有合理的 `displayName`**
5. **永远写 TypeScript 类型**，导出给外部用

## 四、PixelButton 按钮

### 设计规则

- 默认：`bg-bg text-fg border-2 border-fg`
- hover：`shadow-pixel-sm`，位置偏移 -1px（看起来"按下去了一点"）
- active：`shadow-none`，位置偏移 +2px（"按到底"）
- disabled：`opacity-50`，`cursor-not-allowed`
- 三种 variant：`default` / `primary` / `ghost`

### 代码

新建 `src/components/pixel/PixelButton.tsx`：

```tsx
import { ButtonHTMLAttributes, forwardRef } from 'react';

type Variant = 'default' | 'primary' | 'ghost';

type PixelButtonProps = ButtonHTMLAttributes<HTMLButtonElement> & {
  variant?: Variant;
};

const variantStyles: Record<Variant, string> = {
  default: 'bg-bg text-fg',
  primary: 'bg-fg text-bg',
  ghost: 'bg-transparent text-fg',
};

export const PixelButton = forwardRef<HTMLButtonElement, PixelButtonProps>(
  function PixelButton(
    { variant = 'default', className = '', disabled, children, ...rest },
    ref,
  ) {
    return (
      <button
        ref={ref}
        disabled={disabled}
        className={`
          inline-flex items-center justify-center
          px-4 py-2
          border-2 border-fg
          ${variantStyles[variant]}
          ${disabled ? 'opacity-50 cursor-not-allowed' : 'cursor-pointer shadow-pixel-sm hover:shadow-pixel-none hover:translate-x-px hover:translate-y-px active:translate-x-0.5 active:translate-y-0.5 active:shadow-none'}
          transition-none
          select-none
          ${className}
        `}
        {...rest}
      >
        {children}
      </button>
    );
  },
);
```

### 使用

```tsx
import { PixelButton } from '@/components/pixel';

<PixelButton onClick={handleClick}>点我</PixelButton>
<PixelButton variant="primary">主要操作</PixelButton>
<PixelButton variant="ghost">取消</PixelButton>
<PixelButton disabled>不可点</PixelButton>
```

## 六、PixelInput 输入框

### 代码

新建 `src/components/pixel/PixelInput.tsx`：

```tsx
import { InputHTMLAttributes, forwardRef } from 'react';

type PixelInputProps = InputHTMLAttributes<HTMLInputElement> & {
  label?: string;
  error?: string;
};

export const PixelInput = forwardRef<HTMLInputElement, PixelInputProps>(
  function PixelInput({ label, error, className = '', ...rest }, ref) {
    return (
      <div className="flex flex-col gap-1">
        {label && (
          <label className="text-sm font-bold">
            {label}
            {rest.required && <span className="ml-1">*</span>}
          </label>
        )}
        <input
          ref={ref}
          className={`
            bg-bg text-fg border-2 border-fg
            px-3 py-2
            outline-none
            focus:shadow-pixel-sm
            disabled:opacity-50 disabled:cursor-not-allowed
            ${error ? 'border-accent' : ''}
            ${className}
          `}
          {...rest}
        />
        {error && (
          <span className="text-sm text-accent">[!] {error}</span>
        )}
      </div>
    );
  },
);
```

## 十二、PixelModal 模态框

新建 `src/components/pixel/PixelModal.tsx`：

```tsx
'use client';

import { ReactNode, useEffect } from 'react';
import { createPortal } from 'react-dom';

type PixelModalProps = {
  open: boolean;
  onClose: () => void;
  title?: string;
  children: ReactNode;
};

export function PixelModal({ open, onClose, title, children }: PixelModalProps) {
  // ESC 关闭
  useEffect(() => {
    if (!open) return;
    const handler = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose();
    };
    document.addEventListener('keydown', handler);
    return () => document.removeEventListener('keydown', handler);
  }, [open, onClose]);

  // 锁定背景滚动
  useEffect(() => {
    if (!open) return;
    document.body.style.overflow = 'hidden';
    return () => {
      document.body.style.overflow = '';
    };
  }, [open]);

  if (!open) return null;

  return createPortal(
    <div
      className="fixed inset-0 z-50 flex items-center justify-center p-4"
      style={{ background: 'rgba(0,0,0,0.8)' }}
      onClick={onClose}
    >
      <div
        className="bg-bg text-fg border-2 border-fg shadow-pixel-lg max-w-md w-full"
        onClick={(e) => e.stopPropagation()}
      >
        {title && (
          <div className="flex items-center justify-between border-b-2 border-fg px-4 py-2">
            <h2 className="text-2xl font-bold">{title}</h2>
            <button
              onClick={onClose}
              className="border-2 border-fg px-2"
              aria-label="关闭"
            >
              [X]
            </button>
          </div>
        )}
        <div className="p-4">{children}</div>
      </div>
    </div>,
    document.body,
  );
}
```

> 用了 `createPortal` —— 把模态框渲染到 `<body>` 直接子子，**避免被父元素的 z-index / overflow 干扰**。

在 `globals.css` 里加动画：

```css
@keyframes pixel-spin {
  0%   { transform: rotate(0deg); }
  25%  { transform: rotate(90deg); }
  50%  { transform: rotate(180deg); }
  75%  { transform: rotate(270deg); }
  100% { transform: rotate(360deg); }

  animation: pixel-spin 0.8s steps(4) infinite;
```

## 十五、cn 工具函数（合并 className）

新建 `src/lib/cn.ts`：

```ts
/**
 * 合并 className，过滤 falsy 值
 * 用法：cn('base', isActive && 'active', className)
 */

type ClassValue =
  | string
  | number
  | null
  | undefined
  | false
  | ClassValue[]
  | { [key: string]: boolean | undefined };

export function cn(...inputs: ClassValue[]): string {
  const classes: string[] = [];

  for (const input of inputs) {
    if (!input) continue;
    if (typeof input === 'string' || typeof input === 'number') {
      classes.push(String(input));
    } else if (Array.isArray(input)) {
      const nested = cn(...input);
      if (nested) classes.push(nested);
    } else if (typeof input === 'object') {
      for (const key in input) {
        if (input[key]) classes.push(key);
      }
    }
  }

  return classes.join(' ');
}
```

## 十六、所有组件的可访问性

### 必备属性

| 元素 | 属性 |
| --- | --- |
| `<button>` | 始终有可见文字，或 `aria-label` |
| `<input>` | 始终有 `<label>` 或 `aria-label` |
| `<a>` | 始终有可见文字，或 `aria-label` |
| `<img>` | 始终有 `alt` |
| 装饰图标 | `aria-hidden="true"` |

### 键盘导航

- `Tab` - 下一个元素
- `Shift + Tab` - 上一个
- `Enter / Space` - 激活按钮
- `Esc` - 关闭弹窗

> 我们的组件**默认支持以上**，不需要额外代码。

### 焦点指示器

```css
/* globals.css */
:focus-visible {
  outline: 2px solid var(--fg);
  outline-offset: 2px;
}
```

## 十九、常见问题

### Q1：组件怎么改样式？

**A**：直接改组件源代码。**不要**在外面传 className 覆盖。

### Q2：组件能不能继承其他组件库？

**A**：能，但要小心。lucide-react 的图标跟像素风不搭，**别用它做交互组件**。

### Q3：要不要封装 `forwardRef`？

**A**：要。我们的组件都封装了，**方便 ref**。

### Q4：要不要用 `class-variance-authority` (cva)？

**A**：cva 适合**变体很多**的组件（比如 Button）。我们的组件变体少，**用 if-else 就够**。
