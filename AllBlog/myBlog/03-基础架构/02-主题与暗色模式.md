# 02 · 主题与暗色模式

> 怎么实现"点一下切换黑白"，**防止页面闪屏**，跟随系统偏好。

---

## 一、原理

### 三种实现方式

| 方案 | 实现 | 难度 | 推荐 |
| --- | --- | --- | --- |
| **A. CSS 变量 + data 属性** | 手写 | ★ | ✅ 我们用这个 |
| **B. next-themes 库** | 装包 | ★ | 🟡 也行 |
| **C. Tailwind dark: 类** | 系统自动 | ★★ | ❌ 不能手切 |

我们用 **A 方案**，原因是：

1. **0 依赖**，不引入 `next-themes`（虽然它也好用）
2. **完全可控**，想怎么改怎么改
3. **符合 1-bit 极简美学**（黑白二选一，不需要"灰度中间态"）

### 怎么工作

```html
<!-- 亮色 -->
<html data-theme="light">
  <body style="background: var(--bg); color: var(--fg);">
    黑字白底
  </body>
</html>

<!-- 暗色 -->
<html data-theme="dark">
  <body style="background: var(--bg); color: var(--fg);">
    白字黑底
  </body>
</html>
```

**核心思路**：
- CSS 变量 `--bg` 和 `--fg` 在 `:root` 上定义
- 通过 `data-theme` 属性切换两套变量值
- Tailwind 用了 `bg: var(--bg)`，所以**改一个变量，全站跟着变**

## 二、完整实现

### 步骤 1：定义 CSS 变量

打开 `src/app/globals.css`：

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

/* ==================== 主题变量 ==================== */

/* 默认（亮色） */
:root {
  --bg: #ffffff;
  --fg: #000000;
  --accent: #ff0000;
}

/* 用户手动切到暗色（覆盖系统） */
:root[data-theme='dark'] {
  --bg: #000000;
  --fg: #ffffff;
  --accent: #ff5555;
}

/* 用户手动切到亮色（覆盖系统） */
:root[data-theme='light'] {
  --bg: #ffffff;
  --fg: #000000;
  --accent: #ff0000;
}

/* 系统是暗色，用户没手动选过 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) {
    --bg: #000000;
    --fg: #ffffff;
    --accent: #ff5555;
  }
}

/* ==================== 全局样式 ==================== */

html,
body {
  background: var(--bg);
  color: var(--fg);
}

/* 强制所有元素硬边 */
* {
  border-radius: 0 !important;
}

/* 链接 */
a {
  color: var(--fg);
  text-decoration: underline;
  text-underline-offset: 2px;
}

/* 图片不模糊 */
img {
  image-rendering: pixelated;
}

/* 选中文本 */
::selection {
  background: var(--fg);
  color: var(--bg);
}

/* 滚动条 */
::-webkit-scrollbar {
  width: 12px;
  height: 12px;
}
::-webkit-scrollbar-track {
  background: var(--bg);
}
::-webkit-scrollbar-thumb {
  background: var(--fg);
  border: 2px solid var(--bg);
}
```

### 步骤 2：配 Tailwind

打开 `tailwind.config.ts`：

```ts
import type { Config } from 'tailwindcss';

const config: Config = {
  content: ['./src/**/*.{ts,tsx,mdx}'],

  // 关键：dark 模式触发条件
  darkMode: ['selector', '[data-theme="dark"]'],

  theme: {
    extend: {
      colors: {
        bg: 'var(--bg)',
        fg: 'var(--fg)',
        accent: 'var(--accent)',
      },
      boxShadow: {
        pixel: '4px 4px 0 0 var(--fg)',
        'pixel-sm': '2px 2px 0 0 var(--fg)',
        'pixel-lg': '8px 8px 0 0 var(--fg)',
      },
      borderRadius: {
        none: '0',
      },
    },
  },
  plugins: [],
};

export default config;
```

`darkMode: ['selector', '[data-theme="dark"]']` 的意思是：
> 当 `<html>` 有 `data-theme="dark"` 属性时，Tailwind 的 `dark:` 前缀生效。

这样你可以写：

```tsx
<div className="bg-bg text-fg dark:bg-fg dark:text-bg">
  黑白互换
</div>
```

### 步骤 3：创建主题工具

新建 `src/lib/theme.ts`：

```ts
/**
 * 主题工具函数
 * 主题存储在 localStorage 的 'theme' 键
 */

export type Theme = 'light' | 'dark';

const STORAGE_KEY = 'theme';

/**
 * 获取当前主题（优先用 localStorage，否则跟系统）
 */
export function getStoredTheme(): Theme | null {
  if (typeof window === 'undefined') return null;
  return localStorage.getItem(STORAGE_KEY) as Theme | null;
}

/**
 * 获取系统主题
 */
export function getSystemTheme(): Theme {
  if (typeof window === 'undefined') return 'light';
  return window.matchMedia('(prefers-color-scheme: dark)').matches
    ? 'dark'
    : 'light';
}

/**
 * 应用主题到 <html> 元素
 */
export function applyTheme(theme: Theme): void {
  if (typeof document === 'undefined') return;
  document.documentElement.setAttribute('data-theme', theme);
}

/**
 * 保存主题到 localStorage 并应用
 */
export function setTheme(theme: Theme): void {
  applyTheme(theme);
  if (typeof window !== 'undefined') {
    localStorage.setItem(STORAGE_KEY, theme);
  }
}

/**
 * 切换主题（light ↔ dark）
 */
export function toggleTheme(): Theme {
  const current = getStoredTheme() ?? getSystemTheme();
  const next: Theme = current === 'light' ? 'dark' : 'light';
  setTheme(next);
  return next;
}

/**
 * 在页面加载前同步执行的主题脚本
 * 放在 <head> 里，避免"先亮再暗"的闪屏
 */
export const themeInitScript = `
(function() {
  try {
    var stored = localStorage.getItem('theme');
    if (stored === 'light' || stored === 'dark') {
      document.documentElement.setAttribute('data-theme', stored);
    }
  } catch (e) {}
})();
`;
```

        {/* 在 CSS 加载前同步设置主题，防止闪屏 */}
        <script dangerouslySetInnerHTML={{ __html: themeInitScript }} />

> `dangerouslySetInnerHTML` 听起来吓人，但**只是 React 允许你插入一段 HTML/字符串的方式**。
> 这里插入的是**我们自己写的、安全的 JS**，不会执行任何外部代码。

### 步骤 5：创建 useTheme Hook

新建 `src/hooks/useTheme.ts`：

```ts
'use client';

import { useEffect, useState, useCallback } from 'react';
import {
  type Theme,
  getStoredTheme,
  getSystemTheme,
  setTheme as setStoredTheme,
} from '@/lib/theme';

/**
 * 主题切换 hook
 *
 * 用法：
 *   const { theme, toggle, setTheme, mounted } = useTheme();
 *
 *   if (!mounted) return null;  // 防止 hydration mismatch
 */
export function useTheme() {
  const [theme, setThemeState] = useState<Theme>('light');
  const [mounted, setMounted] = useState(false);

  // 组件挂载时读取
  useEffect(() => {
    const stored = getStoredTheme();
    const current = stored ?? getSystemTheme();
    setThemeState(current);
    setMounted(true);
  }, []);

  // 切换
  const toggle = useCallback(() => {
    setThemeState((prev) => {
      const next: Theme = prev === 'light' ? 'dark' : 'light';
      setStoredTheme(next);
      return next;
    });
  }, []);

  // 直接设置
  const setTheme = useCallback((next: Theme) => {
    setStoredTheme(next);
    setThemeState(next);
  }, []);

  return { theme, toggle, setTheme, mounted };
}
```

### 步骤 6：升级主题切换按钮

新建 `src/components/layout/ThemeToggle.tsx`：

```tsx
'use client';

import { useTheme } from '@/hooks/useTheme';

export function ThemeToggle() {
  const { theme, toggle, mounted } = useTheme();

  // 防止 hydration 报错（服务端不知道用户的主题）
  if (!mounted) {
    return (
      <button
        className="border-2 border-fg px-4 py-2"
        aria-label="切换主题"
        disabled
      >
        [·]
      </button>
    );
  }

  return (
    <button
      onClick={toggle}
      className="border-2 border-fg px-4 py-2 shadow-pixel-sm hover:shadow-pixel-none hover:translate-x-px hover:translate-y-px active:translate-x-0.5 active:translate-y-0.5"
      aria-label={`切换到${theme === 'light' ? '暗色' : '亮色'}模式`}
      title={`当前：${theme === 'light' ? '亮色' : '暗色'}模式`}
    >
      [{theme === 'light' ? '☼' : '☾'}]
    </button>
  );
}
```

## 三、什么是"hydration mismatch"

### 问题

Next.js 默认做**服务端渲染（SSR）**，意思是：

```
浏览器请求 → 服务器生成 HTML → 浏览器显示
```

但 `useTheme` 这种 hook **只在浏览器跑**（因为依赖 `localStorage`）。

**矛盾点**：
- **服务器**渲染按钮时，不知道用户的主题，所以渲染 `[·]`（占位）
- **浏览器**接过去后，又渲染 `[☼]`（真实主题）
- React 比对："咦？不一样？" → **报错**

### 解决：`mounted` 状态

```tsx
// 服务端：mounted = false → 显示占位
// 客户端首次：mounted = false → 显示占位
// 客户端 useEffect 后：mounted = true → 显示真实
```

**两次渲染都一样**，React 不报错。

## 四、什么时候用什么 class

### 三种"主题切换 class"

```tsx
// 1. 用 CSS 变量（推荐，亮暗自动跟随）
<div className="bg-bg text-fg">

// 2. 用 dark: 前缀（手动控制）
<div className="bg-white dark:bg-black">

// 3. 混用（变量 + dark:）
<div className="bg-bg dark:bg-fg">
```

**建议**：
- 90% 用 `bg-bg text-fg border-fg`（变量，**主题切换自动生效**）
- 极少数情况用 `dark:` 前缀（比如想**只在暗色下**才显示某元素）

## 五、防止主题相关的 bug

### Bug 1：刷新页面时"闪一下"

**原因**：服务器渲染了亮色，浏览器加载完 JS 后又切到暗色。

**解决**：用 `themeInitScript`，**在 CSS 加载前**就把 `data-theme` 写到 `<html>` 上。

### Bug 2：用户禁用 localStorage

**原因**：隐私模式 / 浏览器设置可能禁用 localStorage。

**解决**：

```ts
try {
  localStorage.setItem('theme', theme);
} catch (e) {
  // localStorage 不可用，就只切内存
  // 下次刷新会回到系统默认，但当前会话能切换
}
```

### Bug 3：用户开了"减少动态效果"

**原因**：系统设置"prefers-reduced-motion"。

**解决**：在 `globals.css` 里：

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 八、进阶（可选）

### 加更多主题（比如"反转"主题）

如果你想加第三种主题（比如"复古绿屏"）：

```ts
type Theme = 'light' | 'dark' | 'green';
```

```css
:root[data-theme='green'] {
  --bg: #000000;
  --fg: #33ff33;  /* 经典绿屏 */
  --accent: #ffff00;
}
```

但**像素风的灵魂是 1-bit 二元美学**，**别加太多颜色**。

### 加"自动跟随时间"

```ts
// 早上 6-18 点亮色，18-6 点暗色
const hour = new Date().getHours();
const autoTheme = hour >= 6 && hour < 18 ? 'light' : 'dark';
```
