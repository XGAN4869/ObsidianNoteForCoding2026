# 02 · 功能规划与最小可用版本（MVP）

> 我们要建什么、为什么是这些、**先做什么后做什么**。

## 一、功能总览

你给的四个需求 + 师傅补充的四个，凑成 **8 个模块**。

```
┌──────────────────────────────────────────┐
│             🏠 首页（入口）                │
│  Logo + 自我介绍 + 最新随笔 + 待办概览     │
└──────────────────────────────────────────┘
       ↓            ↓            ↓
  ┌────────┐  ┌──────────┐  ┌──────────┐
  │ 随笔 📝 │  │ 时光胶囊 💌│  │ 代办清单 ✅│
  └────────┘  └──────────┘  └──────────┘
       ↓            ↓            ↓
  ┌────────┐  ┌──────────┐  ┌──────────┐
  │ 关于我 👤│  │ 留言板 💬 │  │ 友链 🔗  │

                ┌──────────────┐
                │ 自定义模块 🧩│
```

## 二、你提的 4 个功能（核心）

### 1. 记录随笔 ✍️

> "像 Word 一样写文章"

- **技术**：MDX（Markdown + JSX 混合）
- **存哪**：`content/posts/*.mdx` 文件夹里，**跟着代码一起 commit 到 Git**
- **支持**：标题、日期、标签、封面图、代码高亮、表情、嵌入组件
- **不依赖数据库**：纯文件，**永远不丢**

**用户场景**：
- 打开博客 → 点"随笔" → 看到文章列表
- 点一篇文章 → 看正文
- 点左上角"切换主题" → 黑白互换

### 2. 时光胶囊 💌

> "给未来的自己写信"

- **技术**：本地 JSON 或 SQLite，**前端写入 + 时间判断**
- **存哪**：`data/capsules.json`（一个文件一目了然）
- **机制**：每条胶囊有 `unlockAt`（解锁日期）
  - `unlockAt > 现在`：显示"🔒 这封信还没到时间，解锁于 2027-01-01"
  - `unlockAt <= 现在`：显示完整内容
- **新增胶囊**：网页表单，填"寄给未来几月几日 + 内容"
- **保护机制**：即使前端被破解看源代码，**JS 时间是浏览器本地时间**，用户改了能看到 —— 这是个**纯前端娱乐项目**，不是银行密码箱

**用户场景**：
- 今天写"2027 年 1 月 1 日才解锁的信"
- 写完按"加密保存"
- 页面显示 🔒 锁住的信封 + 倒计时
- 时间到了自动显示内容

### 3. 代办清单 ✅

> "我今天要做的事"

- **技术**：本地 JSON / SQLite
- **功能**：
  - 新增任务（标题、可选截止日期）
  - 勾选完成（划掉）
  - 删除任务
  - 拖拽排序（可选，**后期**）
  - 按"全部 / 今天 / 已完成"过滤
- **存哪**：`data/todos.json` 或 `data/todos.db`

**用户场景**：
- 早上打开博客 → 看"今天要做 3 件事"
- 做完一件 → 勾掉
- 全做完 → 显示一个像素笑脸

### 4. 自定义模块 🧩

> "博客还能加点啥？"

教程里给出 **5 个可选模块**，**挑喜欢的做**，都是像素风：

| 模块           | 难度  | 干啥                   |
| ------------ | --- | -------------------- |
| **🎵 像素音乐盒** | ★★  | 放几首你喜欢的歌，像素播放按钮      |
| **📚 读书清单**  | ★   | 你读过 / 在读 / 想读的书，像素书架 |
| **🎬 看片清单**  | ★   | 你看过 / 在看 / 想看的电影     |
| **📷 像素相册**  | ★★★ | 上传图片，自动转像素风（用算法）     |
| **🌧 心情日历**  | ★★  | 每天选一个像素表情，年底能看一整年的心情 |

每个模块都是**独立的页面 + 数据文件**，**互不依赖**。挑一个做完即可，**不必全做**。

## 三、师傅补充的 4 个功能（让逻辑闭环）

### 5. 关于我 👤

> "博客不自我介绍，像进了一个房间没人说话"

- 一个页面
- 内容：
  - 像素头像（可手绘或上传）
  - 一段自我介绍（Markdown）
  - 联系入口（邮箱 / GitHub / 微博 / 推特）
  - 一张小地图（"我在这儿"，可选）

**不做不行的理由**：博客 = 个人，没有"关于我"= **没头没尾**。

### 6. 留言板 💬

> "博客是单向的还是双向的？"

两种实现方案：

| 方案 | 难度 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. Giscus**（推荐） | ★★ | 基于 GitHub Discussions，免费，无广告 | 访客得有 GitHub 账号 |
| **B. 本地 SQLite + 审核** | ★★★ | 无需登录 | 你得自己审核防垃圾留言 |

**推荐方案 A**：GitHub Discussions 做后端，前端嵌入 `<iframe>` 或 `@giscus/react`。
**审核权归你**——访客留言会进你的 GitHub 仓库的 Discussions，你可以一键删。

### 7. 友链 🔗

> "互联网精神：互通有无"

- 一个页面
- 一个 `data/friends.json`，每条包含：名字、URL、描述、头像 URL
- 自动获取对方 favicon（用 `https://www.google.com/s2/favicons?domain=xxx.com`）
- 像素风卡片排列

**逻辑闭环**：你的"访客"通过留言板认识你，通过友链认识你的朋友。

### 8. 首页 🏠

> "博客的门脸"

聚合一切：

```
┌────────────────────────────────────┐
│  Logo (像素风) + 站名              │
├────────────────────────────────────┤
│  👤 一句话介绍 + 最近在干嘛         │
├────────────────────────────────────┤
│  📝 最新 3 篇随笔                   │
│  💌 时光胶囊里快解锁的 1 个         │
│  ✅ 还有 X 件事没做完               │
├────────────────────────────────────┤
│  [主题切换按钮] [RSS 链接] [GitHub] │
└────────────────────────────────────┘
```

**逻辑闭环**：用户从首页能跳到任何模块，**不需要先懂你的菜单**。

## 五、模块依赖关系

```
首页 ─── 依赖 ─→ 所有模块的"最新 N 条"接口
导航 ─── 依赖 ─→ 所有模块的存在
主题切换 ── 依赖 ─→ Tailwind dark mode

随笔 ─┐
时光胶囊 ─┼─ 都是独立的页面，可以并行做
代办 ─┤
关于我 ─┤
留言板 ─┤
友链 ─┘
```

**好消息**：除了"首页"和"导航"是聚合入口，其他模块**互不依赖**。
你可以**先做喜欢的模块**，最后补首页。

## 六、每个模块的"完成定义"

> 怎么算"这个模块做好了"？

### 随笔博客 ✅ 完成标准

- [ ] 能新增一篇 `.mdx` 文件，刷新页面就能看到
- [ ] 文章页有标题、日期、标签
- [ ] 代码块有高亮
- [ ] 图片能正常显示
- [ ] 暗色 / 亮色下都好看
- [ ] 有"上一篇 / 下一篇"导航

### 时光胶囊 ✅ 完成标准

- [ ] 能新增胶囊（表单 + 时间）
- [ ] 没到时间的显示锁 🔒
- [ ] 到时间的显示内容
- [ ] 列表页能看到所有胶囊（不管锁没锁）
- [ ] 数据存到本地文件，重启不丢

### 代办清单 ✅ 完成标准

- [ ] 新增 / 完成 / 删除 / 清除已完成
- [ ] 切换"全部 / 未完成 / 已完成"过滤
- [ ] 数据持久化
- [ ] 暗色 / 亮色下都好看

### 关于我 ✅ 完成标准

- [ ] 头像显示
- [ ] 自我介绍排版美观
- [ ] 联系方式可点击（邮箱 / GitHub）

### 留言板 ✅ 完成标准

- [ ] Giscus 评论区加载成功
- [ ] 能登录 GitHub 留言
- [ ] 你能在 Discussions 后台审核

### 友链 ✅ 完成标准

- [ ] 至少 3 条友链
- [ ] 自动获取 favicon
- [ ] 点击新窗口跳转

## 七、师傅的"反例"——别做的东西

> "智力障碍"初级前端最容易做的事 —— **做多**。

### 别做

| 别做 | 原因 |
| --- | --- |
| ~~一上来就接数据库~~ | 本地 JSON 就够，你又不上亿条数据 |
| ~~一上来就搞"用户系统"~~ | 个人博客只有你一个作者 |
| ~~一上来就加评论~~ | 留言板有了就够了 |
| ~~一上来就搞 SEO 大全~~ | 部署的时候顺手做 |
| ~~一上来就搞 PWA~~ | V3.0 再说 |
| ~~一上来就搞"主题色自定义"~~ | 黑白两套够了，加颜色反而破坏像素感 |
| ~~一上来就搞"国际化多语言"~~ | 你又不会写英文博客 |
| ~~一上来就接 AI~~ | AI 写博客是另一个话题 |
| ~~一上来就搞"付费内容"~~ | 你的博客不是公众号 |
| ~~一上来就搞"会员系统"~~ | 同上 |

**原则**：**MVP 跑通 > V2.0 全做完 > V1.0 多功能**。

先把"能用的极简版本"跑出来，**再考虑加东西**。
