# 01 · 开发环境准备

> 把电脑装好，三个工具：Node.js、pnpm、VSCode、Git。
> **三个工具，每个都讲三遍**：安装、验证、常见错误。

## 二、Node.js 安装（Windows）

### 步骤 1：打开官网

浏览器访问：<https://nodejs.org/>

你会看到两个大大的绿色按钮：
- 左：**LTS**（推荐新手）→ 点这个
- 右：**Current**（最新版，可能不稳定）→ 别点

> LTS = Long Term Support = 长期支持版 = 稳定。
> 师傅推荐你**永远用 LTS**。

### 步骤 2：下载安装包

下载 `.msi` 文件（大约 30 MB）。

### 步骤 3：双击安装包

一路 **"Next"**（下一步）。

**关键步骤**：
- 有一步问你 "Tools for Native Modules" → **勾选**
- 有一步问"Add to PATH" → **必须勾选**（默认勾了）
- 安装路径 → 默认 `C:\Program Files\nodejs\` 就好

### 步骤 4：验证安装

按 `Win + R`，输入 `cmd`，回车，打开命令提示符。

输入：

```bash
node -v
```

你应该看到：

```
v20.x.x   （或更高，比如 v22.x.x）
```

输入：

```bash
npm -v
```

你应该看到：

```
10.x.x   （或更高）
```

> ✅ 如果两个都显示了版本号，**Node.js 安装成功**。

## 三、Node.js 安装（macOS）

### 步骤 1：用 Homebrew（推荐）

如果你**已经装了 Homebrew**：

```bash
brew install node@20
```

如果**没装 Homebrew**，先去 <https://brew.sh/> 复制安装命令。

### 步骤 2：或者用官方安装包

去 <https://nodejs.org/> 下载 `.pkg` 双击安装。

### 步骤 3：验证

打开"终端"（Terminal.app），输入：

```bash
node -v
```

看到 `v20.x.x` 或更高即可。

## 五、pnpm 安装

> **pnpm 是什么**：装"包"的工具。
> 你可以理解成 npm 的"更快、更省"版本。
> **不用也行**，用 npm 也可以——但 pnpm 真的快很多。

### 一行命令安装

打开命令行（Windows 是 cmd / PowerShell / Git Bash；macOS / Linux 是 Terminal），输入：

```bash
npm install -g pnpm
```

> `-g` = 全局安装 = 装到电脑里、以后所有项目都能用。

### 验证

```bash
pnpm -v
```

看到 `9.x.x` 或更高即可。

### 如果报错

**Windows 报错 `EPERM: operation not permitted`**：

用管理员身份打开命令行（右键 → "以管理员身份运行"），重新执行命令。

**macOS / Linux 报错 `EACCES`**：

```bash
sudo npm install -g pnpm
```

## 六、Git 安装

### Windows

去 <https://git-scm.com/download/win> 下载安装包。

**一路 Next**，**关键步骤**：
- "Default editor" → 选 **VS Code**（如果你已经装了）
- "Adjusting your PATH environment" → 选 **"Git from the command line and also from 3rd-party software"**（默认）

### macOS

```bash
brew install git
```

或者装 Xcode Command Line Tools（自带 Git）：

```bash
xcode-select --install
```

### Linux

```bash
sudo apt install git   # Ubuntu/Debian
sudo yum install git   # CentOS/Fedora
```

### 验证

```bash
git --version
```

看到 `git version 2.x.x` 即可。

### 配置 Git（每次新电脑都要做）

```bash
git config --global user.name "你的名字"
git config --global user.email "your-email@example.com"
```

> 这里的"你的名字"和邮箱**不一定**得是真名，会出现在你每次提交的记录里。
> 邮箱**推荐**用 GitHub 注册邮箱。

**验证配置**：

```bash
git config --global --list
```

你应该看到你刚设置的 name 和 email。

## 七、VSCode 安装

### 步骤 1：下载

去 <https://code.visualstudio.com/> 下载。

### 步骤 2：安装

双击安装包（Windows）/ 把 .app 拖到 Applications（macOS）。

Windows 安装时**勾选**：
- ✅ "Add to PATH"
- ✅ "Add 'Open with Code' action to Windows Explorer"
- ✅ "Register Code as an editor for supported file types"

### 步骤 3：装中文界面（如果你想）

1. 打开 VSCode
2. 按 `Ctrl + Shift + P`（macOS 是 `Cmd + Shift + P`）
3. 输入 `Configure Display Language`
4. 选 `zh-cn`
5. 重启 VSCode

### 步骤 4：装必备插件

打开 VSCode，左边栏点"扩展"图标（长得像 4 个方块），搜索并安装：

| 插件 | 干嘛的 |
| --- | --- |
| **ESLint** | 找代码错误 |
| **Prettier** | 格式化代码 |
| **Tailwind CSS IntelliSense** | Tailwind class 自动补全 |
| **Auto Rename Tag** | 改 HTML 标签时自动改配对 |
| **Path Intellisense** | 文件路径自动补全 |
| **Chinese (Simplified) Language Pack** | 中文界面 |
| **MDX** | MDX 文件语法高亮 |
| **Error Lens** | 错误高亮显示 |

> 我们在 `01-方案/04-项目目录结构.md` 里建了 `.vscode/extensions.json`。
> **当你打开项目文件夹时，VSCode 会自动提示"推荐安装这些插件"**，一键全装。

## 八、装完了吗？自检清单

node -v       # 应该显示 v20+ 或 v22+

## 九、创建项目文件夹

挑一个你喜欢的位置建项目文件夹。

比如 Windows：

```
C:\Users\你的用户名\Documents\pixel-blog\
```

或者 macOS / Linux：

```
~/Documents/pixel-blog/
```

### 用命令行创建

```bash
# Windows (PowerShell)
mkdir C:\Users\你的用户名\Documents\pixel-blog
cd C:\Users\你的用户名\Documents\pixel-blog

# macOS / Linux
mkdir -p ~/Documents/pixel-blog
cd ~/Documents/pixel-blog
```

### 用 VSCode 打开

**方法 1**：命令行打开

```bash
code .
```

**方法 2**：VSCode 里手动开

`File` → `Open Folder` → 选 `pixel-blog` 文件夹。

## 十、常见问题

### Q1：Node.js 安装后 `node -v` 还是没反应？

**A**：命令行**没刷新**。关掉重开一个命令行窗口。

或者你的 PATH 没设好：

**Windows**：
1. Win + R → 输入 `sysdm.cpl` → "高级"选项卡 → "环境变量"
2. 找到 `Path` → 编辑 → 看有没有 `C:\Program Files\nodejs\`
3. 没有就新建，加上去

**macOS / Linux**：
重开 Terminal。

### Q2：pnpm 装不上？

**A**：

```bash
# 用 npm 装（最稳）
npm install -g pnpm

# 或者用官方脚本
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

### Q3：Git 报错 `fatal: not a git repository`？

**A**：你在文件夹里没初始化 Git。先进项目文件夹：

```bash
cd pixel-blog
git init
```

### Q4：VSCode 打开命令行？

**A**：

- `Ctrl + ` ` （macOS 是 `Cmd + ` ` `）—— 打开 VSCode 内置终端
- 或者菜单 `Terminal` → `New Terminal`

### Q5：可以用别的编辑器吗？

**A**：可以，但**VSCode 是 Next.js 的"官方推荐"**，出问题好查。

| 编辑器 | 支持度 |
| --- | --- |
| **VSCode** | ★★★★★ 推荐 |
| WebStorm | ★★★★ 重量级，收费，慢 |
| Sublime Text | ★★★ 能用，但 TS 支持弱 |
| Atom | ★★ 已停更 |
| 记事本 / vim | ★ 不推荐 |

### Q6：可以用 yarn 或 npm 代替 pnpm 吗？

**A**：

| 包管理器 | 教程里用的命令 | 你的命令 |
| --- | --- | --- |
| **pnpm**（推荐） | `pnpm install` | - |
| **npm**（最普及） | `pnpm install` 改成 | `npm install` |
| **yarn** | `pnpm install` 改成 | `yarn install` |
| **bun**（最快） | `pnpm install` 改成 | `bun install` |

**教程统一用 pnpm**，但你换成 npm 也行，**所有命令一一对应**。
