## 二、VSCode 配置

按 `Ctrl + Shift + P` → 输入 `Open User Settings (JSON)` → 回车。

把整份配置**覆盖**进去：

```json
{
  // 编辑器基础
  "editor.fontSize": 14,
  "editor.fontFamily": "'JetBrains Mono', 'Cascadia Code', Consolas, monospace",
  "editor.fontLigatures": true,
  "editor.tabSize": 2,
  "editor.insertSpaces": true,
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.minimap.enabled": false,
  "editor.wordWrap": "on",
  "editor.lineHeight": 1.6,
  "editor.renderWhitespace": "boundary",
  "editor.bracketPairColorization.enabled": true,

  // 文件
  "files.eol": "\n",
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,
  "files.exclude": {
    "**/.next": true,
    "**/.git": true,
    "**/node_modules": true
  },

  // 搜索
  "search.exclude": {
    "**/node_modules": true,
    "**/.next": true,
    "**/dist": true,
    "**/.git": true
  },

  // TypeScript
  "typescript.tsdk": "node_modules/typescript/lib",
  "typescript.enablePromptUseWorkspaceTsdk": true,
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[javascript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[json]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[jsonc]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[css]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },

  // ESLint
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "typescript",
    "typescriptreact"
  ],
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit",
    "source.organizeImports": "explicit"
  },

  // Tailwind
  "tailwindCSS.experimental.classRegex": [
    ["cva\\(([^)]*)\\)", "[\"'`]([^\"'`]*).*?[\"'`]"],
    ["cx\\(([^)]*)\\)", "(?:'(?:'|'|[^'])*')|(?:\"(?:\"|\"|[^\"])*\")|((?:\\w+/)*\\w+)"]
  ],

  // 终端
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.fontFamily": "'JetBrains Mono', 'Cascadia Code', monospace",

  // 其他
  "window.titleBarStyle": "native",
  "workbench.colorTheme": "Default Light+",
  "workbench.iconTheme": "vscode-icons"
}
```

> 配置项含义：
> - `formatOnSave: true` 每次保存文件自动格式化
> - `tabSize: 2` 按 Tab 缩进 2 空格
> - `files.insertFinalNewline: true` 文件最后留一个空行
> - `tailwindCSS.experimental.classRegex` 让 Tailwind 插件识别 `className={cn(...)}` 里的 class

## 三、推荐字体

### 代码字体（等宽）

VSCode 默认的 `Cascadia Code` 已经很好，但**更推荐**：

| 字体                 | 特点              | 下载                                   |
| ------------------ | --------------- | ------------------------------------ |
| **JetBrains Mono** | 师傅最推荐，斜杠 0 区分   | <https://www.jetbrains.com/lp/mono/> |
| **Fira Code**      | 带连字 (`=>` 变成箭头) | <https://github.com/tonsky/FiraCode> |
| **Cascadia Code**  | 微软出品，默认有        | 自带                                   |

### 安装步骤

1. 下载字体 zip
2. 解压
3. 全选 `.ttf` 文件
4. 右键 → "安装"（Windows）/ 双击 → "Install Font"（macOS）
5. 重启 VSCode

### 在 VSCode 设置里指定字体

```json
"editor.fontFamily": "'JetBrains Mono', 'Cascadia Code', Consolas, monospace"
```

## 五、VSCode 内置终端的妙用

### 多终端

终端右上角 **`+`** → 开多个终端，**常用配置**：

- **1**: 默认（root 项目目录）
- **2**: `cd src && pnpm tsc --watch`（TypeScript 实时检查）
- **3**: 跑 `pnpm dev` 的另一个端口

### 在终端里用 Git

```bash
# 状态
git status

# 看修改了啥
git diff

# 提交
git add .
git commit -m "feat: 新功能"

# 看提交历史
git log --oneline
```

> VSCode 也有 Git 图形界面（左边的"源代码管理"图标），但**初学者用命令行更清楚发生了什么**。

### 在终端里调试

```bash
# 看 Next.js 编译报错
pnpm dev

# 单独跑 TypeScript 类型检查
pnpm tsc --noEmit

# 跑 ESLint
pnpm lint

# 自动修复 lint 错误
pnpm lint --fix
```

## 六、调试技巧

### 1. 用 `console.log`

```tsx
export default function Home() {
  console.log('页面渲染了', new Date());
  return <div>...</div>;
}
```

打开浏览器 → F12 → Console 标签 → 看输出。

### 2. 用 React DevTools

装浏览器插件：**React Developer Tools**。

能看到 React 组件的 props / state / 组件树。

### 3. 用 `debugger` 关键字

```tsx
function handleClick() {
  debugger;  // ← 在这里停一下
  // ...
}
```

浏览器会**自动停在 `debugger` 那一行**，可以一步步走。

### 4. 看网络请求

F12 → Network 标签 → 刷新页面 → 看每个请求的状态码 / 大小 / 时间。

### 5. 移动端调试

F12 → 点左上角的"切换设备"图标 → 选 iPhone / iPad → 看手机上的样子。

## 七、排错技巧

### 报错信息看不懂？

复制报错信息，**丢给 AI**（比如我），或者：

1. 看**报错第一行**（一般最重要）
2. 看**报错文件名** + **行号**
3. Google 报错信息的关键字

### 终端日志怎么看？

Next.js 的日志格式：

```
✓ Compiled in 2.3s         ← 编译成功
GET / 200 in 50ms          ← 路由 / 状态码 / 耗时
Error: Cannot find module   ← 错误堆栈
```

> **绿色对勾** = 成功
> **红色叉号** = 报错（看后面）

### 项目跑不起来？

按顺序检查：

1. `pnpm install` 是否成功（依赖装全了？）
2. `pnpm dev` 有没有报错（看完整日志）
3. 浏览器 Console 报错信息（按 F12 看）
4. 端口被占用？换端口 `pnpm dev -- -p 3001`

## 八、装一些提高效率的小工具

### Snippets（代码片段）

VSCode 自带了一些，新手**先用默认的**。

要加自定义 snippet：

`Ctrl + Shift + P` → `Snippets: Configure User Snippets` → 选 `typescriptreact.json`：

```json
{
  "React Function Component": {
    "prefix": "rfc",
    "body": [
      "export function ${1:ComponentName}() {",
      "  return (",
      "    <div>",
      "      $0",
      "    </div>",
      "  );",
      "}"
    ],
    "description": "Create a React function component"
  },
  "useState Hook": {
    "prefix": "us",
    "body": [
      "const [${1:state}, set${1/(.*)/${1:/capitalize}/}] = useState<${2:type}>(${3:initialValue});"
    ],
    "description": "React useState hook"
  },
  "useEffect Hook": {
    "prefix": "ue",
    "body": [
      "useEffect(() => {",
      "  $0",
      "}, [${1:dependencies}]);"
    ],
    "description": "React useEffect hook"
  }
}
```

存盘后，输入 `rfc` 按 Tab，**自动展开**为：

```tsx
export function ComponentName() {
  return (
    <div>
      
    </div>
  );
}
```

### 主题（颜色）
