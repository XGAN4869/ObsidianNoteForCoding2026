## 二、Piskel 教程（5 分钟入门）

> 推荐新手从 Piskel 开始，**免安装**。

### 步骤 1：打开 Piskel

<https://www.piskelapp.com/>

点 **Create New**

### 步骤 2：选画布大小

推荐 **32x32** 或 **64x64**，**小一点更容易控制**。

### 步骤 3：选工具

左边工具栏：

| 工具 | 快捷键 | 干啥 |
| --- | --- | --- |
| **Pencil** | `B` | 画单个像素（默认） |
| **Eraser** | `E` | 擦掉像素 |
| **Bucket** | `G` | 填色 |
| **Picker** | `I` | 取色 |
| **Line** | `L` | 画线 |
| **Rect** | `U` | 矩形 |
| **Circle** | `C` | 圆形 |
| **Move** | `M` | 移动整个画布 |

### 步骤 4：关闭"抗锯齿"

右边工具栏，**取消**勾选 "Pixel perfect mode" 旁边的 "Smoothing"。

### 步骤 5：导出

右边 → **Export** → **PNG** → 下载。

放你的项目 `public/sprites/` 下。

## 三、用 AI 生成像素图

### 提示词模板

> 适用 Midjourney、DALL-E、Stable Diffusion、Adobe Firefly 等。

#### 角色

```
pixel art character, 1-bit style, only black and white,
64x64 pixels, no anti-aliasing, retro game character,
[描述角色: "young programmer with glasses"],
transparent background, --ar 1:1
```

#### 物品

```
pixel art icon, 1-bit, black and white only,
16x16 pixels, [物品: "coffee cup"],
centered, transparent background
```

#### 场景

```
pixel art scene, 1-bit, black and white,
800x300 pixels, [场景: "程序员在电脑前工作"],
no anti-aliasing, --ar 8:3
```

### AI 生成的坑

1. **通常会带颜色** → 用 ImageMagick 或 PS 转成黑白
2. **可能会有抗锯齿** → 缩小到目标尺寸，再放大
3. **细节可能不对** → 像素图要的是"简洁"，复杂生成往往失败

**AI 生成后，建议手工修一下**。

## 四、像素图后处理

### 用 ImageMagick 转黑白

```bash
# 安装 ImageMagick
# macOS: brew install imagemagick
# Ubuntu: sudo apt install imagemagick
# Windows: https://imagemagick.org/script/download.php

# 把图片缩到 64x64，再转 1-bit
magick input.png -resize 64x64! -colorspace Gray -threshold 50% output.png
```

参数：
- `64x64!`：强制缩到 64x64（`!` 表示不等比）
- `-colorspace Gray`：转灰度
- `-threshold 50%`：50% 以下变黑，以上变白

### 用 GIMP 转

1. `Image` → `Scale Image` → 选目标大小
2. `Image` → `Mode` → `Grayscale`
3. `Colors` → `Threshold` → 拖动滑块

### 用 Photopea（在线 PS）

<https://www.photopea.com/>

同上，免费，跟 PS 一样的操作。

      <path d={pathData} />
    </svg>
  );
}

## 六、动画 / Sprite Sheet

### 什么是 Sprite Sheet

> 一张图里**有多个动作帧**，浏览器按帧切换。

```
┌────────────────────────────┐
│ [猫走路] [猫跑] [猫跳]    │  ← 一张图
└────────────────────────────┘
       ↑     ↑     ↑
     帧1   帧2   帧3
```

### 怎么用 CSS 显示动画

```css
.pixel-cat {
  width: 32px;
  height: 32px;
  background: url('/sprites/cat-sheet.png') 0 0;
  background-size: 160px 32px;  /* 5 帧 × 32px */
  animation: cat-walk 0.8s steps(5) infinite;
}

@keyframes cat-walk {
  to { background-position: -160px 0; }
}
```

> `steps(5)` = 5 帧跳变，**不平滑**。

### Piskel 做 sprite sheet

1. Piskel → New
2. 画第一帧
4. 右键 → "Duplicate frame"
5. 改第二帧
6. 重复
7. Export → Sprite Sheet

### 哪些能直接用

| 类型 | 版权 |
| --- | --- |
| **自己画的** | ✅ 你的 |
| **CC0 / Public Domain** | ✅ 随便用 |
| **CC BY 4.0** | ✅ 用，但要署名 |
| **CC BY-SA** | ✅ 用，要署名 + 同样协议 |

### 哪些不能直接用

| 类型 | 版权 |
| --- | --- |
| **游戏截图** | ❌ 大部分游戏公司都有版权 |
| **某宝买的"素材包"** | ⚠️ 看授权，一般**不能商用** |
| **AI 生成的** | ⚠️ **法律上不确定**，不同国家不同 |
| **别人的像素图** | ❌ 默认有版权 |

> **原则**：用之前**确认版权**，**注明来源**。
>
> 个人博客**基本上没人来查版权**，但**商用或者公开博客**要小心。

## 十、像素图调试技巧

### 图片看起来糊？

检查：

1. **CSS 加了 `image-rendering: pixelated`**？
2. **图片被等比放大到非整数倍**？（比如 32x32 → 100x100）
3. **导出的格式对吗**？（PNG，**不要 JPEG**）

### 图片颜色不对？

1. **导出模式 = Indexed color**（256 色以内）
2. **禁用抗锯齿**
3. **不要 JPEG**，**永远 PNG**

### 像素画错位？

1. 检查 grid（栅格）是否开了
2. 检查坐标（**整数**坐标）
3. **Piskel 的 "Pixel perfect" 模式**开了吗？
