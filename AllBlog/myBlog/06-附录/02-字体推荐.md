# 02 · 字体推荐

> 像素风的灵魂 = **像素字体**。
> 选错字体，**一切白搭**。

---

## 一、字体选择原则

### 5 条标准

| 标准 | 原因 |
| --- | --- |
| **等宽** | 像素风要求每个字符宽度一致 |
| **点阵化** | 字符由"点"组成，不是矢量 |
| **整数倍缩放** | 在常用大小（16、24、32、48）下不模糊 |
| **免费可商用** | 不要被字体公司发律师函 |
| **支持中文**（或配中文） | 博客主要语言 |

### 师傅的取舍

> **英文**：用 Google Fonts 的 VT323（等宽、点阵、免费）。
> **中文**：用 Google Fonts 的 ZCOOL KuaiLe（圆润、像素感、免费）。
> **标题**：用 Press Start 2P（粗壮、复古）。
> **代码**：用 JetBrains Mono（不是像素字体，但等宽）。

## 二、英文像素字体

### VT323（主推）

- **来源**：Google Fonts
- **风格**：终端风、等宽、复古
- **大小**：1 个 weight（400）
- **下载**：<https://fonts.google.com/specimen/VT323>

```tsx
import { VT323 } from 'next/font/google';

const vt323 = VT323({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-vt323',
  display: 'swap',
});
```

**适用**：正文、副标题、按钮文字。

### Press Start 2P

- **来源**：Google Fonts
- **风格**：8-bit 街机风、**粗壮**
- **大小**：1 个 weight（400）
- **下载**：<https://fonts.google.com/specimen/Press+Start+2P>

```tsx
import { Press_Start_2P } from 'next/font/google';

const pressStart = Press_Start_2P({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-press-start',
  display: 'swap',
});
```

**适用**：大标题、Logo、强调。
> **缺点**：字距大，**段落正文用太丑**。

### Silkscreen

- **来源**：Google Fonts
- **风格**：简洁像素、扁平
- **大小**：2 个 weight（400 / 700）

**适用**：跟 VT323 类似，**适合不喜欢 VT323 字形的人**。

### Major Mono Display

- **来源**：Google Fonts
- **风格**：极简、几何
- **大小**：1 个 weight

**适用**：Logo。

### DotGothic16

- **来源**：Google Fonts
- **风格**：日式 + 像素
- **大小**：1 个 weight
- **支持**：日文 + 英文

**适用**：日文博客或日式风格。

### 其他推荐

| 字体 | 来源 | 风格 |
| --- | --- | --- |
| **Departure Mono** | dafont.com | 终端风 |
| **Perfect DOS** | dafont.com | DOS 时代 |
| **Pixel Operator** | dafont.com | 8-bit |
| **04b03** | 04b03-font | 极小像素 |

## 三、中文字体

### ZCOOL KuaiLe（主推）

- **来源**：Google Fonts
- **风格**：圆润、像素感、不完全点阵但**有像素的味道**
- **大小**：1 个 weight
- **支持**：**中文（简体）** + 英文
- **下载**：<https://fonts.google.com/specimen/ZCOOL+KuaiLe>

```tsx
import { ZCOOL_KuaiLe } from 'next/font/google';

const zcool = ZCOOL_KuaiLe({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-zcool',
  display: 'swap',
});
```

**适用**：**所有中文正文**。

### ZCOOL XiaoWei

- **风格**：细、像素感弱一些
- **适用**：副标题

### 霞鹜文楷 (LXGW WenKai)

- **风格**：开源楷体
- **适用**：想用楷体而不是像素感的

### 其他中文字体

| 字体 | 风格 |
| --- | --- |
| **思源宋体** (Source Han Serif) | 宋体，**不是像素**，但免费可商用 |
| **思源黑体** (Source Han Sans) | 黑体，同上 |
| **站酷高端黑** | 站酷出品，标题用 |
| **阿里巴巴普惠体** | 阿里巴巴出品 |

> **中文像素字体很难找**（中文 7000+ 字，每个字都点阵化要人命）。
> 大部分"中文像素字体"都是**部分**做了像素处理。
> 实际项目里，**ZCOOL KuaiLe + VT323** 搭配基本够用。

## 四、代码字体

> 代码**不用像素字体**（等宽就行，因为代码里有 a、l、I 容易混淆）。

### JetBrains Mono（主推）

- **来源**：JetBrains 官网
- **下载**：<https://www.jetbrains.com/lp/mono/>
- **特点**：等宽、带连字、可区分 0/o/I/l

```tsx
import { JetBrains_Mono } from 'next/font/google';

const jetbrainsMono = JetBrains_Mono({
  subsets: ['latin'],
  variable: '--font-jetbrains',
  display: 'swap',
});
```

### Fira Code

- 带连字（`=>` 变箭头）
- 等下

### Cascadia Code

- 微软出品
- 等下

### 师傅的选择

> **代码**：JetBrains Mono
> **英文博客正文**：VT323
> **英文标题**：Press Start 2P
> **中文正文**：ZCOOL KuaiLe
> **中文标题**：ZCOOL KuaiLe + 加粗

## 五、字体配置（完整版）

打开 `src/app/layout.tsx`：

```tsx
import { VT323, Press_Start_2P, ZCOOL_KuaiLe, JetBrains_Mono } from 'next/font/google';

const vt323 = VT323({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-vt323',
  display: 'swap',
});

const pressStart = Press_Start_2P({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-press-start',
  display: 'swap',
});

const zcool = ZCOOL_KuaiLe({
  weight: '400',
  subsets: ['latin'],
  variable: '--font-zcool',
  display: 'swap',
});

const jetbrainsMono = JetBrains_Mono({
  subsets: ['latin'],
  variable: '--font-jetbrains',
  display: 'swap',
});

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN">
      <body
        className={`
          ${vt323.variable}
          ${pressStart.variable}
          ${zcool.variable}
          ${jetbrainsMono.variable}
          font-pixel text-base
        `}
      >
        {children}
      </body>
    </html>
  );
}
```

`tailwind.config.ts`：

```ts
fontFamily: {
  pixel: ['var(--font-vt323)', 'monospace'],
  'pixel-title': ['var(--font-press-start)', 'monospace'],
  'pixel-cn': ['var(--font-zcool)', 'sans-serif'],
  mono: ['var(--font-jetbrains)', 'monospace'],
},
```

## 六、本地字体（推荐国内部署）

> Google Fonts 国内访问慢，**部署到国内时建议本地化**。

### 步骤 1：下载字体

去 Google Fonts 下载字体 zip，解压出 `.ttf` 或 `.woff2` 文件。

### 步骤 2：放到 `public/fonts/`

```
public/fonts/
├── VT323-Regular.ttf
├── PressStart2P-Regular.ttf
├── ZCOOLKuaiLe-Regular.ttf
└── JetBrainsMono-Regular.ttf
```

### 步骤 3：用 `next/font/local`

```tsx
import localFont from 'next/font/local';

const vt323 = localFont({
  src: '../public/fonts/VT323-Regular.ttf',
  display: 'swap',
  variable: '--font-vt323',
});
```

### 步骤 4：备选方案

把字体放到 CDN（自己的 OSS / 七牛 / Cloudflare R2），用 `@font-face`：

```css
/* globals.css */
@font-face {
  font-family: 'VT323';
  src: url('https://cdn.yoursite.com/fonts/VT323-Regular.woff2') format('woff2');
  font-display: swap;
}

@font-face {
  font-family: 'ZCOOL KuaiLe';
  src: url('https://cdn.yoursite.com/fonts/ZCOOLKuaiLe.woff2') format('woff2');
  font-display: swap;
}
```

## 七、字体的最佳实践

### 1. 只加载用到的字符（子集化）

Google Fonts 自动做了，但你本地字体要手动：

```bash
# 用 fonttools
pip install fonttools brotli

pyftsubset VT323-Regular.ttf \
  --output-file=VT323-Regular-subset.woff2 \
  --flavor=woff2 \
  --layout-features='kern' \
  --unicodes=U+0020-007E,U+4E00-9FFF
```

### 2. 用 woff2 格式

```bash
# 转换
fonttools tt2woff2 VT323-Regular.ttf -o VT323-Regular.woff2
```

> **woff2 体积比 ttf 小 60-80%**。

### 3. preload 关键字体

```tsx
// layout.tsx 的 <head>
<link rel="preload" href="/fonts/VT323-Regular.woff2" as="font" type="font/woff2" crossOrigin="anonymous" />
```

### 4. font-display: swap

```css
@font-face {
  font-display: swap;
}
```

**避免 FOIT**（字体未加载完文字不可见）。

## 八、中文像素风的"折中方案"

> 因为**中文像素字体难找**，推荐"英文字体像素化 + 中文字体圆润化"：

- **英文**：VT323（像素风）
- **中文**：ZCOOL KuaiLe（圆润，不完全像素）

视觉上**不完全一致**，但**比纯英文像素字体好看**。

### 方案 B：CSS 让中文也像素化

```css
.cn {
  font-family: 'VT323', 'ZCOOL KuaiLe', monospace;
  /* 让浏览器尝试"伪像素"渲染 */
  font-smooth: never;
  -webkit-font-smoothing: none;
}
```

效果**有限**，但有点用。

### 方案 C：等真正的好中文像素字体出现

> 现实是**目前没有**完美的中文字体。
> 这是"等开源社区进步"的问题，**不是你能解决的**。

## 九、字体调试

### 字体没生效？

1. 浏览器 F12 → Elements → 看 `<body>` 的 `className` 是否有 `font-pixel`
2. Computed 标签 → 看 `font-family` 计算值
3. 字体加载了？看 Network 标签 → Fonts

### 中文字体慢？

- Google Fonts 国内慢 → 本地化
- 字符太多 → 用 `font-display: swap`
- 体积大 → 用 woff2 + 子集化

### 字距不对？

```css
.pixel-title {
  letter-spacing: 0.1em;  /* 加宽字距 */
}
```

### 字体在某些大小下糊？

| 大小 | 字号 |
| --- | --- |
| **完美清晰** | 16px / 24px / 32px / 48px（4 的倍数） |
| **次清晰** | 12px / 20px / 28px |
| **会糊** | 13px / 17px / 19px / 23px（避免） |
