# 04 · 环境搭建与项目初始化

> 从这一步开始，我们要真正动手了。目标：**让一个空白的 Next.js 项目在你电脑上跑起来**。
> 师傅假设你是 Windows 电脑（从你前面的截图文件名看是 Windows 环境），命令都用 Windows 适用的写法。

---

## 一、你需要装什么（清单）

| 工具           | 作用    | 怎么检查是否已装        |     |
| ------------ | ----- | --------------- | --- |
| Node.js ≥ 20 | 运行 JS | 命令行输 `node -v`  |     |
| npm（随 Node）  | 装包    | `npm -v`        |     |
| 一个代码编辑器      | 写代码   | 推荐 VS Code      |     |
| Git（可选但建议）   | 版本管理  | `git --version` |     |
|              |       |                 |     |

### 检查方法

打开**终端**（Windows 按 `Win + R`，输入 `cmd` 或 `powershell` 回车；或用 VS Code 里的终端），依次输入：

```bash
node -v     # 期望看到 v20.x 或更高
npm -v      # 期望看到 10.x 或更高
git --version
```

- 如果 `node -v` 报"不是内部或外部命令"，说明没装 Node。去 [nodejs.org](https://nodejs.org) 下载 **LTS 版本**，一路下一步安装，装完**重开终端**再试。

---

## 二、创建 Next.js 项目

在你想放项目的目录下，打开终端，运行：

```bash
npx create-next-app@latest my-omori-blog
```

它会问几个问题，**照着下面选**（↑↓ 选，回车确认）：

| 问题                | 选择                 |
| ----------------- | ------------------ |
| TypeScript?       | **Yes**            |
| ESLint?           | **Yes**            |
| Tailwind CSS?     | **Yes**            |
| `src/` directory? | **No**（用 app 目录即可） |
| App Router?       | **Yes**            |
| Turbopack?        | **Yes**（默认）        |
| import alias?     | 回车用默认 `@/*`        |

> 如果它问你 "Would you like to use Turbopack for next dev?"，选 Yes，更快。

装完后：

```bash
cd my-omori-blog
npm run dev
```

浏览器打开 `http://localhost:3000`，看到 Next.js 的欢迎页，就**成功了**。

> 这一步最重要，先确保"能跑起来"。看到页面就说明环境没问题，后面所有报错都不怕。

---

## 三、初始化 shadcn/ui

shadcn 是一套高质量组件，我们用 CLI 把它"复制"进项目，再改造成手绘风。

```bash
npx shadcn@latest init
```

问题选项（推荐）：

| 问题              | 选择          |
| --------------- | ----------- |
| Which color?    | 随便选（我们后面会改） |
| CSS variables?  | **Yes**     |
| React 19 / RSC? | 按提示选 Yes    |

初始化完成后，项目里会多出 `components/ui/` 目录和 `lib/utils.ts`。

### 先装几个马上要用的组件

```bash
npx shadcn@latest add button card input textarea dialog dropdown-menu calendar popover toast
```

> 这些组件后面都会用到，现在先装上，不急着改。

## 四、安装项目依赖

```bash
# 状态管理
npm install zustand

# 表单 + 校验
npm install react-hook-form zod @hookform/resolvers

# 动画
npm install motion

# 数据库 ORM
npm install @prisma/client
npm install -D prisma

# 密码哈希 + JWT
npm install bcryptjs jose
npm install -D @types/bcryptjs

# Markdown 渲染（随笔正文）
npm install react-markdown remark-gfm

# 日期处理
npm install date-fns
```

> 先全部装上，具体哪个包在哪一章用，到那一章会再解释。**别纠结"现在用不上"**，一次装齐省心。

---

## 五、初始化 Prisma（数据库）

```bash
npx prisma init --datasource-provider sqlite
```

这会生成：
- `prisma/schema.prisma` —— 数据库模型文件
- `.env` —— 环境变量文件

打开 `.env`，把 `DATABASE_URL` 改成：

```env
DATABASE_URL="file:./dev.db"
```

> 意思是"数据库文件放在 prisma 目录下的 dev.db"。

## 六、项目现在的状态（检查点）

做完以上，你的项目应该是这样：

```
my-omori-blog/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── components/ui/          ← shadcn 组件
├── lib/utils.ts            ← shadcn 的 cn()
├── prisma/schema.prisma    ← 数据库模型
├── .env                    ← 环境变量
├── package.json
└── ...（一堆配置文件）
```

**验证一下**：`npm run dev` 还能正常打开 `localhost:3000`，就继续下一章。

---

## 七、师傅的三个新手提醒

1. **`.env` 不要提交到 Git**（如果你用 Git）。里面以后会放密码，泄漏就完了。检查 `.gitignore` 里有没有 `.env`。
2. **改完依赖后如果报奇怪的错**，先 `Ctrl+C` 停掉 `npm run dev`，重跑一次。
3. **VS Code 装这两个插件**（搜索安装）：
   - `ESLint`
   - `Tailwind CSS IntelliSense`（写类名会提示，效率翻倍）
   - `Prisma`（数据库 schema 高亮和校验）
