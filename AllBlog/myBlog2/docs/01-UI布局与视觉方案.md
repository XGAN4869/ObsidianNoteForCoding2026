# 01 · UI 布局与视觉方案（OMORI 风格）

> 这一篇不讲代码，只讲"长什么样"。我们把整套视觉语言定下来，后面所有代码都照着它写。

---

## 一、OMORI 风格的本质（先理解，再动手）

OMORI 不是"可爱手绘"这么简单，它的视觉是**矛盾对撞**：

- **白与黑**：大片刺眼的纯白（White Space）vs 突兀的纯黑线条
- **暖与冷**：梦境是奶油、粉紫、淡蓝；现实是灰、暗红、深褐
- **童稚与压抑**：涂鸦般的线条、蜡笔色块，却承载着沉重情绪
- **留白即语言**：越重要的东西，周围留白越多

**翻译成设计语言，我们的博客要做到：**

| 游戏元素 | 博客对应 | 落地方式 |
|---------|---------|---------|
| White Space（白空间） | 首页留白、卡片间隙 | 大 margin、低信息密度 |
| 手绘描边 | 卡片/按钮的边框 | 不规则圆角 + 抖动描边 |
| 蜡笔色块 | 主题色、情绪色 | 低饱和、带颗粒质感的色块 |
| 手写体标题 | 标题、情绪词 | 手写风格字体 |
| 漂浮方块/门/楼梯 | 装饰元素、导航 | SVG 小插画、hover 动效 |
| 情绪表情（红手/白花等） | 心情标记 | 每个心情配一个手绘 emoji/图形 |

## 二、配色系统（CSS 变量）

### 主题基色（一套"浅色" + 一套"深色"）

OMORI 有鲜明的浅色（梦境）与深色（现实/阴暗）两种氛围，我们做成可切换的主题。

#### 浅色主题（默认，对应"白空间 / 梦境"）

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#FAFAF7`（暖白） | 页面底色 |
| `--bg-card` | `#FFFFFF` | 卡片底 |
| `--bg-muted` | `#F0EEE8` | 次级底色、hover |
| `--ink` | `#1A1A1A`（近黑） | 主文字、描边 |
| `--ink-soft` | `#6B6B6B` | 次要文字 |
| `--paper` | `#FFFDF6`（纸色） | 随笔纸张底色 |
| `--accent` | `#E8A0BF`（粉） | 主强调色 |

### 情绪色（心情标记专用）

OMORI 的情绪是有图形的，我们为每个心情配颜色 + 手绘图标：

| 心情 | 英文 | 颜色 | 手绘图形 | 使用场景 |
|------|------|------|---------|---------|
| 平静 | Calm | `#A7C7E7` | 白色水母 | 默认 |
| 开心 | Happy | `#F5C6D0` | 粉花 | 随笔/胶囊 |
| 难过 | Sad | `#7A8BA8` | 雨滴 | 随笔/胶囊 |
| 愤怒 | Angry | `#D9534F` | 红手 | 随笔/胶囊 |
| 害怕 | Afraid | `#8B72A8` | 蜘蛛 | 胶囊/回忆 |
| 疲惫 | Tired | `#B8B0A0` | 睡云 | 随笔 |
| 孤独 | Lonely | `#6E8FA8` | 单只眼 | 随笔 |

> 这些图标后面会用内联 SVG 手绘实现，不依赖图片素材，保证可维护、可换色。

## 三、字体

| 用途 | 字体 | 备选 |
|------|------|------|
| 中文正文 | 系统默认（思源黑体 / 苹方 / 微软雅黑） | 不额外加载中文字体，避免体积爆炸 |
| 中文标题（手写感） | 手写风格：`Ma Shan Zheng`（马善政楷体） | 用 next/font 的 Google Fonts |
| 英文标题/点缀 | `Caveat` 或 `Shantell Sans`（手写） | 同上 |
| 等宽/代码 | `JetBrains Mono` | 时间戳、标签用 |

> 说明：中文字体文件很大，**标题用手写体、正文用系统字体**是最佳平衡。手写体通过 `next/font/google` 加载，会自动做字体子集优化（只加载用到的字）。

## 四、核心视觉元素（CSS 手绘技法）

这一节是"皮"的关键，我们用纯 CSS 复刻手绘感。

### 1. 手绘描边卡片

```css
/* 概念代码，后面 05 章落地 */
.hand-drawn-card {
  background: var(--bg-card);
  border: 2px solid var(--ink);
  border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px;
  /* ↑ 不规则圆角：让每个角都不一样，模拟手绘 */
  box-shadow: 4px 4px 0 var(--ink); /* 硬投影，像贴纸 */
}
```

要点：
- **不规则圆角**（`border-radius` 用 8 个值）是手绘感的核心，比普通圆角高级得多。
- **硬投影**（无模糊、偏移的纯色阴影）制造"贴纸/剪纸"质感。

### 2. 纸张纹理背景

```css
body {
  background-image: repeating-linear-gradient(
    0deg,
    transparent,
    transparent 2px,
    rgba(0,0,0,0.015) 2px,
    rgba(0,0,0,0.015) 4px
  );
  /* 极淡的横向细纹，模拟纸的纤维 */
}
```

### 3. 抖动/歪斜（可选点缀）

用 CSS `transform: rotate(-1deg)` 给个别元素加轻微倾斜，打破呆板。

### 4. 手绘 SVG 装饰

- **漂浮方块**：几个带描边的小方框，`animation` 上下浮动。
- **门**：首页一个可 hover 的"门"SVG，通往时光胶囊。
- **楼梯**：装饰性阶梯线。
- 全部用内联 SVG + 少量 CSS，不引第三方图标库。

## 五、页面布局（线框图）

### 1. 全局结构（桌面端）

```
┌─────────────────────────────────────────────┐
│  顶部导航（手绘描边横条）                      │
│  [ 头像/名字 ]  随笔  胶囊  待办  布置  ...   │
├─────────────────────────────────────────────┤
│                                             │
│              主内容区（留白充足）              │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│  底部（版权 + 心情小语）                       │
└─────────────────────────────────────────────┘
```

- 导航用**顶栏**（不是侧栏），因为博客内容简单，顶栏更直接。
- 顶栏左边是站点名 + 一个手绘头像，右边是导航项 + 主题切换按钮。

### 2. 首页（白空间 Home）

这是整个博客的"灵魂页面"，对应 OMORI 的 White Space：

│                                             │
│   ┌───────┐  ┌───────┐  ┌───────┐          │
│   │ 随笔   │  │ 待办   │  │ 胶囊   │  ← 3个门  │
│   │ 入口   │  │ 入口   │  │ 入口   │          │
│   └───────┘  └───────┘  └───────┘          │
│                                             │
│   ┌─────────────────────────────┐           │

**首页四要素**：
1. 当天心情（可点开改）

### 8. 移动端适配

- 顶栏收起为汉堡菜单。
- 首页三个"门"纵向堆叠。
- 卡片间距缩小但仍保留留白。
- 断点：`< 640px`（手机）、`640–1024px`（平板）、`> 1024px`（桌面）。

## 六、动效规范

OMORI 的动效是"缓慢、呼吸感、梦境感"，不是炫技：

| 动效 | 实现 | 节奏 |
|------|------|------|
| 卡片 hover | 轻微上浮 + 阴影加深 | 0.2s ease-out |
| 漂浮方块 | `translateY` 往返 | 3~6s infinite ease-in-out |
| 开门（首页入口） | 卡片 hover 时微旋转 | 0.3s |
| 心情切换 | 图标淡入缩放 | 0.25s |
| 待办勾选 | 勾线 stroke 动画 + 文字划线 | 0.3s |
| 拆胶囊 | 封口展开 | 0.6s |

**统一原则：慢、柔、少。** 每个动画都要有"呼吸感"，避免高频闪烁。

---

## 七、无障碍与可读性（师傅的坚持）

- 正文字号 ≥ 16px，行高 1.7。
- 文字与背景对比度符合 WCAG AA（浅色主题 `--ink` 对 `--bg` 对比度已达标）。
- 手写体只用于标题，正文永远用系统字体保证可读。
- 所有按钮有 `:focus-visible` 焦点样式。
- 尊重 `prefers-reduced-motion`，用户系统开启"减少动效"时关闭漂浮动画。
