## 一、配置 Tailwind 主题（globals.css）

打开 `app/globals.css`，**清空重写**为下面内容：

```css
/* app/globals.css */
@import "tailwindcss";

/* ===== 浅色主题（白空间/梦境）===== */
:root {
  --bg: #FAFAF7;
  --bg-card: #FFFFFF;
  --bg-muted: #F0EEE8;
  --ink: #1A1A1A;
  --ink-soft: #6B6B6B;
  --paper: #FFFDF6;
  --accent: #E8A0BF;
  --accent-2: #A7C7E7;
  --accent-3: #C9B1E0;
  --danger: #D9534F;
  --shadow: #00000014;
}

/* ===== 深色主题（现实/阴暗）===== */
.dark {
  --bg: #17151A;
  --bg-card: #201D24;
  --bg-muted: #2A2630;
  --ink: #EDE8F0;
  --ink-soft: #9B95A3;
  --paper: #26222C;
  --accent: #C77B9A;
  --accent-2: #6E8FA8;
  --accent-3: #8B72A8;
  --danger: #E06C69;
}

/* ===== 全局基础 ===== */
body {
  background-color: var(--bg);
  color: var(--ink);
  font-family: var(--font-sans); /* 系统字体，见下 */
  /* 纸张纹理：极淡的横向细纹 */
  background-image: repeating-linear-gradient(
    0deg,
    transparent,
    transparent 2px,
    rgba(0,0,0,0.015) 2px,
    rgba(0,0,0,0.015) 4px
  );
}

/* 尊重系统"减少动效"设置 */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

> Tailwind v4 用 `@import "tailwindcss"` 而不是旧的 `@tailwind base` 三行，注意别写错。

## 二、手绘描边卡片（核心工具类）

在 `globals.css` 里追加：

```css
/* 手绘卡片：不规则圆角 + 硬投影 */
.hand-drawn {
  background: var(--bg-card);
  border: 2px solid var(--ink);
  border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px;
  box-shadow: 4px 4px 0 var(--ink);
}

/* hover 时轻微上浮（贴纸感） */
.hand-drawn-hover {
  transition: transform 0.2s ease-out, box-shadow 0.2s ease-out;
}
.hand-drawn-hover:hover {
  transform: translate(-2px, -2px);
  box-shadow: 6px 6px 0 var(--ink);
}

/* 纸张质感（随笔正文用） */
.paper {
  background: var(--paper);
  border: 2px solid var(--ink);
  border-radius: 12px 4px 14px 6px / 6px 14px 4px 12px;
  box-shadow: 3px 3px 0 var(--shadow);
}

/* 轻微歪斜（点缀用） */
.tilt-l { transform: rotate(-1deg); }
.tilt-r { transform: rotate(1deg); }
```

> 这里用了 8 值 `border-radius`（`斜杠` 前后各 4 个），让四个角各不相同，是手绘感的精髓。

## 三、手写字体（next/font）

打开 `app/layout.tsx`，改造成这样（手写体标题 + 系统字体正文）：

```tsx
// app/layout.tsx
import type { Metadata } from "next";
import { Caveat, Shantell_Sans } from "next/font/google";
import "./globals.css";

// 手写体（英文标题/点缀）
const hand = Shantell_Sans({ subsets: ["latin"], variable: "--font-hand" });
const caveat = Caveat({ subsets: ["latin"], variable: "--font-caveat" });

export const metadata: Metadata = {
  title: "我的 OMORI 博客",
  description: "一个属于我的数字心灵空间",
};

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="zh-CN">
      <body className={`${hand.variable} ${caveat.variable} antialiased`}>
        {children}
      </body>
    </html>
  );
}
```

> `next/font/google` 会在构建时自动下载并子集化字体，不额外发请求，性能好。
> 中文字体文件太大，所以中文标题我们**用 CSS 手写体兜底**（见下），英文标题用 `Caveat`。

再在 `globals.css` 里定义标题类：

```css
.font-hand {
  font-family: var(--font-hand), "Ma Shan Zheng", "KaiTi", cursive;
}
.font-caveat {
  font-family: var(--font-caveat), cursive;
}
```

## 四、心情图标组件（MoodIcon）

这是全站的"情绪脸"。先建一个心情元数据文件：

```ts
// lib/moods.ts
export const MOODS = {
  CALM:    { label: "平静", color: "#A7C7E7" },
  HAPPY:   { label: "开心", color: "#F5C6D0" },
  SAD:     { label: "难过", color: "#7A8BA8" },
  ANGRY:   { label: "愤怒", color: "#D9534F" },
  AFRAID:  { label: "害怕", color: "#8B72A8" },
  TIRED:   { label: "疲惫", color: "#B8B0A0" },
  LONELY:  { label: "孤独", color: "#6E8FA8" },
} as const;

export type Mood = keyof typeof MOODS;

export const MOOD_LIST = Object.entries(MOODS).map(([key, val]) => ({
  key: key as Mood,
  ...val,
}));
```

然后写图标组件（手绘 SVG，用简单的几何图形表达每种心情）：

```tsx
// components/mood/MoodIcon.tsx
import { MOODS, type Mood } from "@/lib/moods";

// 每个心情一个简单手绘 SVG 图形
function Icon({ mood, size }: { mood: Mood; size: number }) {
  const c = MOODS[mood].color;
  switch (mood) {
    case "HAPPY":
      // 一朵小花
      return (
        <g>
          <circle cx="12" cy="16" r="3" fill={c} />
          <circle cx="12" cy="8" r="2.5" fill={c} />
          <circle cx="7" cy="10" r="2.5" fill={c} />
          <circle cx="17" cy="10" r="2.5" fill={c} />
          <circle cx="9" cy="14" r="2.5" fill={c} />
          <circle cx="15" cy="14" r="2.5" fill={c} />
        </g>
      );
    case "SAD":
      // 一滴雨
      return (
        <g>
          <path d="M12 5 C12 5 8 12 8 15 A4 4 0 0 0 16 15 C16 12 12 5 12 5 Z" fill={c} />
        </g>
      );
    case "ANGRY":
      // 红色手（简化为手掌）
      return (
        <g>
          <rect x="7" y="8" width="10" height="10" rx="3" fill={c} />
          <rect x="10" y="13" width="4" height="4" rx="1.5" fill={c} />
        </g>
      );
    case "AFRAID":
      // 蜘蛛（圆形 + 腿）
      return (
        <g>
          <circle cx="12" cy="12" r="4" fill={c} />
          {[0, 45, 90, 135, 180, 225, 270, 315].map((a) => (
            <line
              key={a}
              x1="12" y1="12"
              x2={12 + 7 * Math.cos((a * Math.PI) / 180)}
              y2={12 + 7 * Math.sin((a * Math.PI) / 180)}
              stroke={c} strokeWidth="1.5"
            />
          ))}
        </g>
      );
    case "TIRED":
      // 一朵打盹的云
      return (
        <g>
          <ellipse cx="12" cy="14" rx="7" ry="4.5" fill={c} />
          <circle cx="9" cy="12" r="3" fill={c} />
          <circle cx="15" cy="12" r="3" fill={c} />
        </g>
      );
    case "LONELY":
      // 单只眼睛
      return (
        <g>
          <path d="M4 12 Q12 5 20 12 Q12 19 4 12 Z" fill="none" stroke={c} strokeWidth="2" />
          <circle cx="12" cy="12" r="3" fill={c} />
        </g>
      );
    case "CALM":
    default:
      // 水母（半圆 + 触须）
      return (
        <g>
          <path d="M6 12 A6 6 0 0 1 18 12 Z" fill={c} />
          <path d="M8 12 Q8 16 7 17" stroke={c} strokeWidth="1.5" fill="none" />
          <path d="M12 12 Q12 16 11 17" stroke={c} strokeWidth="1.5" fill="none" />
          <path d="M16 12 Q16 16 15 17" stroke={c} strokeWidth="1.5" fill="none" />
        </g>
      );
  }
}

export default function MoodIcon({
  mood,
  size = 24,
  className,
}: {
  mood: Mood;
  size?: number;
  className?: string;
}) {
  return (
    <svg
      width={size}
      height={size}
      viewBox="0 0 24 24"
      className={className}
      style={{ color: MOODS[mood].color }}
      aria-label={MOODS[mood].label}
      role="img"
    >
      <Icon mood={mood} size={size} />
    </svg>
  );
}
```

> 这里的 SVG 是"示意版"，你可以在理解结构后自行发挥，把图形画得更像 OMORI。核心是：**一个 `mood` 参数 → 一个图形 + 一个颜色**。

## 五、手绘按钮 / 卡片组件（改造 shadcn）

shadcn 的 Button 默认是圆角、扁平，我们改成手绘风。打开 `components/ui/button.tsx`，找到 `buttonVariants`，把 `default` 变体改成：

```tsx
default:
  "bg-[var(--ink)] text-[var(--bg)] border-2 border-[var(--ink)] \
   rounded-[12px_4px_14px_6px/6px_14px_4px_12px] \
   shadow-[3px_3px_0_var(--ink)] hover:translate-x-[1px] hover:translate-y-[1px] \
   hover:shadow-[1px_1px_0_var(--ink)] transition-all"
```

> 手绘按钮 = 硬边框 + 硬投影 + 不规则圆角 + 按下时"陷下去"。

## 六、一个漂浮装饰组件（OMORI 的漂浮方块）

```tsx
// components/layout/FloatingSquares.tsx
export default function FloatingSquares() {
  const squares = [
    { top: "10%", left: "8%", size: 20, delay: 0, color: "var(--accent)" },
    { top: "30%", right: "10%", size: 14, delay: 1.2, color: "var(--accent-2)" },
    { bottom: "20%", left: "15%", size: 16, delay: 2.1, color: "var(--accent-3)" },
    { top: "15%", right: "20%", size: 12, delay: 0.6, color: "var(--accent-2)" },
  ];

  return (
    <div className="pointer-events-none fixed inset-0 overflow-hidden" aria-hidden>
      {squares.map((s, i) => (
        <div
          key={i}
          className="absolute border-2"
          style={{
            top: s.top,
            left: s.left,
            right: s.right,
            bottom: s.bottom,
            width: s.size,
            height: s.size,
            borderColor: s.color,
            background: "transparent",
            animation: `float ${4 + (i % 3)}s ease-in-out ${s.delay}s infinite`,
          }}
        />
      ))}
      <style jsx>{`
        @keyframes float {
          0%, 100% { transform: translateY(0) rotate(0deg); }
          50% { transform: translateY(-12px) rotate(8deg); }
        }
      `}</style>
    </div>
  );
}
```
