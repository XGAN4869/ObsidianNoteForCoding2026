## 前端工程的一个完整请求需要包含什么？
项目有没有统一 HTTP 请求封装 + 页面四态（Loading, Success, Empty, Error），这套机制，有的话告诉我具体的代码位置，然后 请求缓存、自动重试、请求去重、AbortController、幂等性和乐观更新
1. AbortController（真正的取消异步任务）
2. disposed（哨兵标记，软拦截）不能主动打断 / 终止底层异步任务

## 如何辅助ai读代码
先告诉我你上面完成的这个模块的业务目标、数据流、状态变化和关键不变量。
然后指出最值得看的 3 个文件和函数。
每个函数只解释输入、输出、为什么这样做，以及一个反例。
