## 要求
- 注释内容要精简
- 页面中带 ! 和 todo 的注释请保留
- 注释要有主谓宾语，并补充场景说明

## 失败注释案例
- /** 只保留屏幕坐标，避免手势计算依赖具体组件的事件对象。 */
  - 1. 缺少主语，谁的屏幕坐标，主语不要是被解释对象的函数名
  - 2. 避免手势依赖什么组件的什么对象,产生了什么样的影响？

## 函数
```ts
  /**
   * @param items 
   * @param gap 每张卡片间隔
   */

   /**
   * @param 
   * @return
   */
```
