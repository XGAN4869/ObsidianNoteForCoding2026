## 瀑布流排版算法采纳
- 用增量追加，而不是一左一右，不然有的列图片会过长，有的过短，这个是看卡片的宽度和高度的
    初始：只有 A、B
    - A：列 0（列 0 总高 = 10）
    - B：列 1（列 1 总高 = 12） 列状态：`col0:[A(10)], col1:[B(12)]`
    触底，拿到新一批：`[C,D]` 只遍历 C、D，旧 A、B 不动
    - C：找最短列 → 列 0（10）塞进去，col0=10+9=19
    - D：现在最短是列 1（12），塞进去，col1=12+10=22 最终布局： col0: [A,C] 总高 19 col1: [B,D] 总高 22
    ✅ 旧卡片 A、B 还在原来的列，位置不变，用户不会看到内容跳来跳去
- 其次判断高度有失真问题，不能只计算图片比例要计算整张卡片的比例

测量 API 的选择、隐藏渲染成本和长列表性能，见 [卡片测量与 ResizeObserver](./卡片测量与ResizeObserver.md)。
