# 组件销毁时机

## 速查表

| 场景 | 卸载？ | 触发 |
| --- | --- | --- |
| 路由离开（无 keep-alive） | ✅ | `onUnmounted` / `onScopeDispose` |
| `v-if="false"` | ✅ | 同上 |
| `v-show="false"` | ❌ 仅 `display:none`，DOM 还在 | — |
| keep-alive 路由切走 | ❌ | 仅 `onDeactivated` |
| H5 切后台（tab 切走、最小化） | ❌ | 仅 `visibilitychange` |
| uni-app 页面 `onHide` | ❌ 组件驻留内存 | — |
| uni-app 页面 `onUnload` | ✅ | 页面根组件 + 所有子组件 |
| 组件 `:key` 变更 | ✅ 旧实例销毁、新建 | `onScopeDispose` |

## 1. Vue3 + Vue Router

- 路由离开 = 组件卸载（前提：路由组件**没有**被 `keep-alive` 包裹）
- 卸载时 DOM 移除、响应式作用域销毁
- `keep-alive` 包裹时：路由切走只跑 `onDeactivated`，不跑 `onUnmounted / onScopeDispose`；缓存淘汰或强制销毁才真正卸载

## 2. H5 浏览器切后台

- `visibilitychange` → `document.hidden`，**组件完全不卸载**
- 实例仍在内存，`onUnmounted` 不触发
- 👉 视频场景要单独维护「页面可见性标记」，不能靠卸载标记

## 3. uni-app

> App / 小程序切后台走页面 `onHide`；H5 切后台不触发页面生命周期，只有 `visibilitychange`。

### 页面生命周期

- `onLoad`：首次创建，仅 1 次
- `onShow`：页面可见（打开、后台切回、返回栈回来）
- `onHide`：页面隐藏（跳转新页面、切 App 后台、原生弹窗盖住）→ 不卸载，`disposed` 不变
- `onUnload`：页面真正销毁，`navigateBack` / `redirectTo` / `reLaunch` 触发 → 页面根组件 + 内部所有子组件一起卸载，`disposed=true`

**页面栈**：A→B，A 只 `onHide`、驻留内存；B 返回 A 走 `onShow`，不走 `onLoad`。

### 页面内自定义组件（如 HomeDiscoverFeed）

- `v-if="false"` → 销毁 ✅
- `v-show="false"` → 仅隐藏，DOM 保留
- 父页面 `onHide` → 子组件存活
- 父页面 `onUnload` → 所有子组件跟着卸载 ✅
- 组件 `:key` 值变更 → Vue 不复用，销毁旧实例、新建实例 ✅

## 4. key 在 diff 中的作用

```html
<组件 :key="'xyz-' + variableKey" />
```

key 变化时 Vue 判定为不同节点，不复用：销毁旧实例（`onScopeDispose` 执行）、创建新实例。常用于强制重建组件、重置内部状态。
