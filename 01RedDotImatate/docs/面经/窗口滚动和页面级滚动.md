# webview 两层结构

- 小程序 webview 分两个隔离线程：**视图层（渲染）、逻辑层（JS）**，只能通过 JSBridge 发消息通信，通信有开销。

1. **页面原生滚动本身：在视图层（webview 内核）独立跑**
滑动、惯性、回弹全部由浏览器内核处理，**默认不向 JS 发消息**，不打扰逻辑层。
2. **一旦你开启 `onPageScroll` 监听 即为窗口滚动**
每一次滚动位置变化，视图层就会通过 JSBridge，把 `scrollTop` 发给逻辑层 JS；
滚动越快，消息发得越频繁，产生通信开销；**不写 onPageScroll，就没有这笔开销**。
