# 屿社区业务模块目录与功能说明

本文档记录项目中已实现的业务模块、模块入口、主要功能以及对应的代码位置。

## 一、业务页面目录

```text
src/pages/
├─ index/                         # 首页：发现流、关注流、瀑布流卡片、刷新与分页加载
│  ├─ index.vue                   # 首页入口，切换「发现 / 关注」并维护两个内容流的滚动位置
│  ├─ common/
│  │  └─ HomeFeedPlaceholder.vue  # 首页共享占位，供关注提示和错误视图使用
│  ├─ feed/
│  │  ├─ HomeDiscoverFeed.vue      # 发现流入口
│  │  ├─ HomeFollowingFeed.vue     # 关注流入口、登录提示和推荐关注
│  │  ├─ HomeFeedError.vue         # 首屏请求失败反馈与重试
│  │  ├─ components/
│  │  │  ├─ HomeFeedView.vue       # 两条流共用的列表、卡片测量和可见区域渲染
│  │  │  └─ HomeNoteCard.vue       # 列表和测量区共用的笔记卡片
│  │  └─ composables/
│  │     ├─ useHomeFeed.ts         # 缓存、分页、实测分列与缓存恢复时的估算布局
│  │     ├─ useCursorFeed.ts       # 游标分页状态
│  │     └─ useWaterfall.ts        # 瀑布流列高与追加布局
│  ├─ pager/HomeFeedPager.vue      # 发现与关注的横向滑动切换
│  └─ docs/内容流与切页.md           # 缓存、布局、分页及滑动约束
│
├─ note/                          # 笔记详情：图文、视频、作者信息与互动数据展示
│  ├─ index.vue                   # 详情请求、正文、异常状态和返回处理
│  ├─ NoteNavbar.vue              # 作者区与操作菜单
│  ├─ note-failure.ts             # 详情错误分类

│

│  ├─ compose.vue                 # 图文/视频编辑器，编辑标题、正文、媒体、地点并发布或保存草稿

│     ├─ DraftNav.vue             # 草稿箱顶部导航、草稿数量和管理入口
```

## 二、业务接口模块

```text
src/api/modules/
├─ auth.ts                        # 验证码、手机号登录、注册、微信登录、微信绑定和退出登录
├─ feed.ts                        # 发现流和关注流的分页获取、数据标准化和游标处理
├─ note.ts                        # 笔记详情、发布笔记、草稿同步、草稿查询和草稿删除
├─ node.ts                        # 媒体上传、视频抽帧、视频封面确认及笔记/草稿底层请求
├─ media.ts                       # 图片/视频上传和视频帧获取的统一入口
├─ profile.ts                     # 当前用户或公开用户资料、用户笔记列表和喜欢列表
├─ follow.ts                      # 关注、取消关注、粉丝列表和关注列表
├─ message.ts                     # 通知列表、会话列表、会话详情、发送消息和未读数
├─ block.ts                       # 拉黑、解除拉黑和黑名单列表
├─ location.ts                    # 当前定位、逆地理编码、附近地点和关键词地点搜索
├─ settings.ts                    # 用户设置、偏好保存、夜间免打扰和应用版本检查
└─ mock.ts                        # 本地联调数据和发现流模拟分页场景
```


## 五、模块之间的主要关系

```text
登录 / 注册 / 微信绑定
          │
          ▼
      user store ───────────────► 我的 / 设置 / 发布 / 消息
          │
          ├─────────────────────► 首页关注流
          └─────────────────────► 他人主页 / 社交关系

首页 ──点击笔记──► 笔记详情 ──点击作者──► 他人主页
  │                  │                    │
  │                  ├─关注               ├─关注 / 私信
  │                  ├─点赞               └─拉黑
  │                  └─分享                         │
  │                                                 ▼
  └────────────────────────────────────────────── 黑名单

发布入口 ──► 编辑器 ──发布成功──► 笔记详情 / 我的主页刷新
    │          │
    │          └─存草稿──► 草稿箱 ──继续编辑 / 重试发布 / 删除
    └────────────────────► 地点搜索、媒体上传、视频封面
```

## 六、入口配置

页面注册和底部 Tab 配置统一位于：

```text
src/pages.json
```

底部 Tab 包含：首页、发布、消息、我；登录、注册、详情、社交、黑名单等页面通过页面跳转进入。
