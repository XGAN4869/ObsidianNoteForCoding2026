# 首页内容流与切页

`index.vue` 负责导航、页面生命周期、下拉刷新、触底加载和滚动位置恢复。`common` 放首页复用的占位视图，`feed` 放发现流、关注流和它们的列表组件与状态逻辑，`pager` 放横向切页组件。分页请求和响应类型位于 `src/types/feed.ts`，由 API 和分页逻辑共同使用。

`useCursorFeed.ts` 当前导出的函数名是 `usePagination`，用于管理发现流、关注流或其他需要游标分页的列表。

它只管理前端状态：列表、游标、加载状态、去重、刷新和重试。具体请求必须由 `src/api/modules/*` 提供，页面不直接调用 `uni.request`。

## 1. 分页数据契约

API 模块把后端响应转换成下面的前端格式：

```ts
export interface CursorPage<T> {
  list: T[]
  nextCursor: string | null
  hasMore: boolean
}
```

| 字段         | 含义                                        |
| ------------ | ------------------------------------------- |
| `list`       | 当前批次的数据                              |
| `nextCursor` | 下一次请求使用的游标；没有下一页时为 `null` |
| `hasMore`    | 服务端是否还有下一页                        |

游标是服务端生成的不透明值，前端不解析、不拼接、不自行生成，只在下一次请求中原样传回。

## 2. 创建一个分页实例

每一条信息流都创建独立实例，发现流和关注流不能共用游标或列表状态。

```ts
import { usePagination } from '@/pages/index/feed/composables/useCursorFeed'

interface FeedNote {
  id: string
  title: string
}

const discoverPagination = usePagination<FeedNote>({
  pageSize: 20,
  getKey: note => note.id,
  load: ({ cursor, pageSize }) => feedApi.getDiscover({ cursor, pageSize })
})
```

`load` 接收：

```ts
interface PaginationRequest {
  cursor: string | null
  pageSize: number
}
```

如果后端字段不同，只在 API 模块中转换：

```ts
export async function getDiscover(params: PaginationRequest): Promise<CursorPage<FeedNote>> {
  const response = await request<BackendResponse>({
    url: '/feed/discover',
    method: 'GET',
    data: params
  })

  return {
    list: response.records,
    nextCursor: response.cursor,
    hasMore: response.hasNext
  }
}
```

`BackendResponse` 和字段名只是 API 模块示例，实际名称以接口契约为准；页面和 composable 不需要跟着后端字段名变化。

## 3. 页面中的基本用法

```ts
void discoverPagination.loadInitial()
```

```ts
async function onReachBottom(): Promise<void> {
  await discoverPagination.loadMore()
}

async function onPullDownRefresh(): Promise<void> {
  await discoverPagination.refresh()
  uni.stopPullDownRefresh()
}
```

失败时调用：

```ts
await discoverPagination.retry()
```

模板示例：

```vue
<view v-if="discoverPagination.isInitialLoading">正在加载</view>
<view v-else-if="discoverPagination.isEmpty">暂无内容</view>
<view v-else>
  <HomeNoteCard
    v-for="note in discoverPagination.items"
    :key="note.id"
    :note="note"
  />

  <view v-if="discoverPagination.isLoadingMore">正在加载更多</view>
  <view v-else-if="!discoverPagination.hasMore">没有更多了</view>
  <button v-else-if="discoverPagination.error" @click="discoverPagination.retry">
    重新加载
  </button>
</view>
```

## 5. 当前实现的行为

- 默认每页 20 条，可通过 `pageSize` 修改。
- `getKey` 用于去重；首页传笔记的 `id`。
- 首屏成功后，`loadMore` 使用上一次确认的 `nextCursor`。
- 下一页失败时，旧列表和旧游标都会保留，可以直接重试。
- 刷新成功后替换首屏，刷新失败时旧列表继续保留。
- 同一条流同一时间只允许一个请求，连续触底不会重复发送请求。
- `hasMore` 为 `false` 后不会继续请求。
- `hasMore` 为 `true` 但游标没有推进时，会进入错误状态，避免无限请求。

## 6. 发现流和关注流

```ts
const discoverPagination = usePagination({
  getKey: note => note.id,
  load: loadDiscover
})

const followingPagination = usePagination({
  getKey: note => note.id,
  load: loadFollowing
})
```

两条流必须使用不同的实例。切换 Tab 时只切换当前展示的实例，不能把发现流的 `items`、`nextCursor` 或错误状态复用给关注流。

## 7. 双列增量布局

首页使用 useWaterfall 保存两列的累计高度。每条新卡片放入累计高度较小的列；追加不改变旧卡片的位置，刷新和快照版本变化时重建两列。

封面统一为 3:4。方图、横图和缺失尺寸的图片均使用同一占位，等比裁切。首页卡片只展示标题，详情正文 `content` 不进入首页 Feed 卡片模型。作者行、内边距和间距沿用现有样式令牌。

`HomeFeedView` 在隐藏区用同一个 `HomeNoteCard` 渲染当前批次，等节点挂载后在组件内一次读取卡片尺寸和间距。发现流和关注流通过 `measure` 把结果交给 `useHomeFeed`。测量结果按输入顺序与笔记对应，缺少节点或尺寸无效时进入本次请求的错误处理。渲染时根据页面滚动位置扣除导航区域，再加上下缓冲筛选卡片，外层保持完整列高。

列高相等时优先放在左侧。追加时先复制列状态，逐张更新累计高度，整批完成后替换浅引用。首屏、刷新和快照切换从空列重新布局。

## 首页两条流的组合

`useHomeFeed.ts` 组合分页与双列布局，并维护卡片测量结果的类型。发现和关注分别创建实例，按账号与流类型隔离首屏缓存。有效缓存先用于展示，然后后台刷新。缓存批次测量失败时，由该文件按样式令牌估算卡片高度。发现流快照变动时通过 `refresh` 整体替换。

`ensureLoaded()` 只表示当前流实例是否已经启动过首屏流程。第一次调用会立即设置 `initialized`，重复的挂载、Tab 激活和滑动预览调用会直接结束。有效缓存会先恢复并展示，再后台刷新；没有缓存时请求首屏。下拉刷新和错误重试使用独立流程，不受 `initialized` 影响。

账号切换会改变两条流的组件 `key`，使它们重新创建。旧实例卸载后忽略晚到的请求结果。切回同一账号的已加载分段时，沿用组件实例和已记录的滚动位置。

## 首页横滑交互

首页使用 HomeFeedPager.vue 承载相邻两页，保持页面级纵向滚动。拖动时直接更新轨道位移；松手后按距离和速度决定切页或返回，并使用统一动效令牌完成缓动吸附。页面边界有阻尼，不循环；先锁定为纵向的手势保持滚动，多指和系统取消均复位。拖动产生的点击会被抑制，顶部 Tab 与当前页同步。

首页和详情图集共享 `src/composables/useSwipePager.ts` 及其纯手势计算 `src/utils/swipe-pager.ts`。每次手势都由调用方提供当前容器宽度，拖动期间沿用起始页和该宽度。多指、系统取消和新手势会清理旧速度，停住后松手按当前位移判定。首页首次露出相邻页时可以提前加载，已加载列表继续复用。

首页卡片打开事件沿 `HomeNoteCard → HomeFeedView → 当前流组件 → index.vue.openFeedNote` 向上转发。首页通过导航事件通道接收详情页确认的更新，按笔记 ID 同步已加载卡片和首屏缓存。首页只接收标题、封面和互动状态等卡片字段，详情正文 `content` 不进入首页列表。
