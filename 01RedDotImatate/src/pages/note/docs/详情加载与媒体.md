# 笔记详情加载与媒体

`index.vue` 当前是静态详情页，首页卡片通过 `open` 事件进入，页面负责正文、底部互动栏和“谁可以看”弹层，不调用接口。`NoteNavbar.vue` 负责作者区与菜单。详情 API 保留为后续接入入口，错误由统一请求层返回 `ApiError`。

## 加载与失效

- 当前页面没有加载、刷新、失败或重试状态，页面数据全部来自本地静态对象。
- 后续接入详情接口时，再按后端真实返回的 `code`、`message` 和 `data` 补充状态处理。
- 返回操作由 `goBack()` 处理，菜单和“谁可以看”弹层可以先在页面内关闭。

## 图片布局

`media/NoteImageGallery.vue` 管理渲染和触摸事件绑定。`media/composables/useNoteImageGallery.ts` 管理图片原始尺寸、布局和测量。`media/image-gesture.ts` 计算等比适配、捏合锚点和拖动边界。

- 页内媒体盒高度以第一张图片为基准，上限是窗口高度的三分之二。其他图片按各自比例在盒内居中。这样切图不会推动正文。
- 页内测量保存滚动前的坐标，使用时扣除当前滚动量。全屏测量使用可视区坐标，进入时冻结页内位置，退出前重新测量当前图片的回落位置。
- 每张图片的元信息按 URL 缓存，图片列表变动或组件销毁后丢弃旧回调。读取失败时由图片组件显示占位和重试。

## 全屏与手势

`media/composables/useNoteImageGestures.ts` 在点按、横向翻页、双指捏合与全屏拖动之间交接。翻页本身由首页与详情共享的 `src/composables/useSwipePager.ts` 处理。

- 适配倍率下单指横滑翻页，放大后单指拖动图片。捏合以初始指距和中点为基准，双指变单指时从当前变换接续拖动。松手后校正图片边界。
- 活动图片沿用同一个渲染节点，捏合进入全屏时无需重新加载。退出动画结束后释放底页滚动限制，原生 WebView 丢失过渡事件时由定时器收尾。
- 页面失活、容器尺寸变化和组件销毁会清理手势状态。尺寸变化后重新测量页内位置和全屏区域。

## 视频

视频播放器暂不接入。详情页仅保留图片相册，视频实现按后续需求单独补充。
