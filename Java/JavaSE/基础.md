## 自动类型转换
- 小范围变量 **可以直接赋值** 给大范围的变量，会补码：如 byte -> int，8位补成32位前面填0
	byte --> short --> int --> long --> float --> double
	        char↗
- 在表达式中，最终结果由最高类型决定，但是 byte short char 是直接转化成 int类型计算的
	byte、short、char--> int --> long --> float --> double
## 强制类型转换
- 大范围类型变量 **赋值给** 小范围类型变量
- 32位强制变成8位，如果转不过来会精度丢失

## 基本类型和包装类型
为什么Java需要包装类型？因为包装类型附带了一些方法
- 堆：new 出来的实例对象，Class对象中的 static 静态变量
- 虚拟机栈：局部变量（method里）
- Metaspace 元空间：**类元结构，这个类造出来的一个 `java.lang.Class` 类型的对象是在堆中不是在元空间中**
- 静态常量池：.class 文件，【磁盘上】，未进 JVM
- 运行时常量池：👆 **进jvm后，基于静态常量池的结构，在本地内存中生成运行时常量池**
```java
public class Test {
    // 成员变量，存放在堆中
    int a = 10;
    // 静态字段的存储属于 JVM 实现细节；在 JDK 8 及之后的 HotSpot 中位于 Java 堆。
    // 变量属于类，不属于对象。
    static int b = 20;

    public void method() {
        // 局部变量，存放在栈中
        int c = 30;
        static int d = 40; // 编译错误，不能在方法中使用 static 修饰局部变量
    }
}
```
- 重点：**所有整型包装类对象之间值的比较，全部使用 equals 方法比较**。

## 自动拆箱 / 装箱
1. 基本类型赋值给包装类型变量 → 装箱
	Integer a = 100; // 装箱
2. 包装类型赋值给基本类型变量 → 拆箱
	int b = a; // 拆箱
3. 泛型集合（List / Map）只能存对象，**必须装箱**

## 成员变量与局部变量
- 成员变量属于类or实例【成员变量 + 成员方法】
	被 `public`,`private` 【属于实例：实例对象.方法/变量】  `static`【属于类：直接类名.方法/变量】 修饰的
- static 类有共享性，不同实例都能访问到：static 变量逻辑上属于类，而不是某个实例。HotSpot JDK 8+ 中其存储与堆上的 Class 镜像对象相关联。

## 字符型常量和字符串常量的区别
char 基本数据类型, jvm 层不需要提前加载类库
String: 对象的内存占用👇
```
JVM 职责	String 在这里发生了什么
1. 类加载	加载 java.lang.String 类
2. 内存管理	在堆中创建 String 对象，管理对象引用
3. 执行字节码	执行 String.length() 等方法
4. 垃圾回收	判断 String 对象是否还被引用，决定是否回收
5. 线程与同步	String 对象也可以参与线程间共享，但 String 本身不等于锁机制
```
其实都需要 jvm 管理

## 重载和重写
重载：静态绑定、同一类可访问的方法集合中（包括继承的方法）、方法名通，参数不同
```java
class Parent {
    public void show(int a) {
        System.out.println("父类 int");
    }
}

class Child extends Parent {
    public void show(String a) {
        System.out.println("子类 String");
    }
}

Child child = new Child();

child.show(100);
child.show("Zora");
```
重写：动态绑定、父子类（继承关系）、方法名、参数列表**必须完全相同**。
	**方法的重写要遵循“两同两小一大”**【大：权限，小：返回值类型比父小，异常类应比父类方法声明抛出的异常类更小或相等；】
	并且，返回值是 基本数据类型 or void 必须类型和父类一致
	返回值是引用类型时：可以是父类的子类
