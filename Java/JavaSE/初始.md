# JDK
## JDK -- Java开发工具包 👇总和
![[Pasted image 20261104163621.png|672]]
.java --javac 编译 --> class 文件【java 运行时环境】--java启动器-->  jvm【执行字节码的虚拟机】 --> 核心类库
- JVM：【你以后学习 Java 并发、线程池、JVM 内存模型、GC、性能调优，实际上都是在逐渐理解 JVM 如何管理一个正在运行的 Java 程序】，类似 go routine
	1. 类加载：把 class 加载进来
	2. 内存管理（决定数据存放的是 stack heap metaspace...
	3. 执行字节码
	4. 垃圾回收
	5. JVM 会提供对象监视器、锁机制等运行时支持（线程、同步）
	补充：`native` 方法叫做本地方法（Native Method）。它是 Java 中一种特殊的方法：方法在 Java 中声明，**但是具体实现不使用 Java 代码，而是交给 JVM 或底层本地代码实现，因为有系统级的操作。**
- JDK 组成（从外到里）
	
	| 名称         | 含义              | 例子        |
	| ---------- | --------------- | --------- |
	| JDK        | 开发工具包           | JDK 21    |
	| 模块（Module） | 组织 Java API 的模块 | java.base |
	| 包（Package） | 组织类的命名空间        | java.lang |
	| 类（Class）   | 具体的类型定义         | String    |
	| 方法（Method） | 类提供的行为          | length()  |
