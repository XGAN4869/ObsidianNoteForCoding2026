# 学习路线：每周计划

**开始：2026-10-28；目标完成：2027-02-20；缓冲：2027-02-22 至 2027-02-27。**

- 每周按约 **30–34 小时有效学习**估算，只确定方向，不固定每天学什么。
- 周一至周六灵活推进，**周日补牙、休息，不安排学习或补进度**。下表日期区间中的周日均留空。
- Java 先补必需基础和开发配置，再结合 AI 做项目；看不懂的知识回头补，不要求看完整套课程。
- 本轮目标：一个完整的 Java + React 核心业务项目，配套测试、部署、监控与性能优化；黑马点评做缓存和秒杀专项，黑马头条做微服务入门。

## 穿插推进的内容

- **算法：11-04 起贯穿项目阶段。** 先按代码随想录理解常见专题，再穿插 Hot 100，后期复习薄弱题。本轮以约 60–80 道去重题目为参考，不要求刷完全部题单或多轮。
- **知识复习：01-04 起逐步穿插，02 月集中查漏。** JavaGuide、二哥用于整理 Java 知识，小林用于补 MySQL、Redis、操作系统和网络；面试后继续更新复盘笔记。
- **AI 辅助：以一个小模块为单位。** 先弄清需求与调用链，再实现、测试，最后自己解释和修改；配置、关键业务和错误处理需要实际验证。

## 进度调整

- 每周末只检查本周目标与卡点，允许在同一周内自由调配看课、写代码、排错和复习的时间。
- 已掌握的基础用小功能验证后跳过，把时间留给 Java 和项目实践。
- 工作变忙或休假时先保住当前主线。连续两周明显低于学习预算，就缩减范围或重排节点，不挤占周日。
- 缺口优先放进缓冲周；仍不够时，先减少选做进阶和黑马头条的深度，再减少算法题量与非核心页面，保留一个能测试、部署和演示的完整项目。
