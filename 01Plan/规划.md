## 2. Java 后端学习路线（按图片归纳）

项目主线：**Java SE → JavaWeb → 苍穹外卖 → 黑马点评 → 黑马头条**。

Java SE 学完即可进入 JavaWeb 和项目阶段；MySQL、Redis、JVM、JUC 等结合项目逐步补充，算法同步练习，面试复习放在求职前。

- [ ] Java SE：语法、面向对象、异常、集合、泛型、Lambda、Stream、IO —— 搜索：`黑马程序员 Java SE 基础 入门 集合 泛型 IO`
- [ ] MySQL：SQL、表设计、索引、事务 —— 搜索：`黑马程序员 MySQL 数据库 入门 索引 事务`
- [ ] Redis：基础使用与缓存设计，结合黑马点评学习 —— 搜索：`黑马点评 Redis 缓存穿透 缓存击穿 缓存雪崩 缓存一致性`
