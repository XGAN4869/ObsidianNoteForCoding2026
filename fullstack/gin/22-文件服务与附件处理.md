## 22.1 文件下载

```go
// 直接下载
r.GET("/download/:filename", func(c *gin.Context) {
	filename := c.Param("filename")
	filepath := "./uploads/" + filename

	// 检查文件是否存在
	if _, err := os.Stat(filepath); os.IsNotExist(err) {
		c.JSON(404, gin.H{"error": "文件不存在"})
		return
	}

	// 方式一：自动识别 Content-Type
	c.File(filepath)

	// 方式二：指定下载文件名
	// c.FileAttachment(filepath, filename)
})
```

## 22.2 区分预览和下载

```go
r.GET("/file/:filename", func(c *gin.Context) {
	filename := c.Param("filename")
	action := c.DefaultQuery("action", "inline")  // inline=预览, download=下载

	if action == "download" {
		c.Header("Content-Disposition", "attachment; filename="+filename)
	} else {
		c.Header("Content-Disposition", "inline")
	}
	c.File("./uploads/" + filename)
})
```

## 22.5 文件服务最佳实践

| 场景 | 方案 |
|------|------|
| 小文件（<10MB） | 本地磁盘 + Gin 静态服务 |
| 中等文件（<100MB） | 对象存储（OSS/S3）+ 签名 URL |
| 大文件（>100MB） | 对象存储 + 分片上传 |
| 视频/音频 | CDN + 流媒体服务器 |

## 本章小结

- `c.File()` 文件下载/预览
- `Content-Disposition: attachment` 强制下载
- 断点续传需要解析 `Range` 请求头
- 大文件用分片上传 + 合并策略
- 生产环境文件推荐存对象存储（OSS/S3）
