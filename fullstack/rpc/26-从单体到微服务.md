## 26.2 技术栈串联

| 层 | 技术 | 作用 |
|----|------|------|
| 接入层 | **Gin** + **gRPC Gateway** | REST API 入口 |
| 服务间通信 | **gRPC** | 高性能微服务通信 |
| 缓存层 | **Redis** | 热数据缓存、分布式锁、排行榜 |
| 数据访问 | **GORM** | ORM 简化数据库操作 |
| 数据库 | **MySQL** | 数据持久化 |

---

## 26.3 一个请求的完整旅程

```
1. 浏览器发 REST 请求 → Gin/Gateway
2. Gateway 验证 JWT → 提取 user_id
3. Gateway 调用 gRPC → Auth Service 验证权限
4. gRPC 调用 gRPC → Order Service 创建订单
5. Order Service → Redis 检查库存缓存
6. Order Service → GORM → MySQL 写订单
7. Order Service → Redis 更新缓存
8. 响应逐层返回 → 浏览器收到 JSON
```

---

## 26.4 后端工程师成长路线

```
Level 1：会用框架写 CRUD
  └→ Gin + GORM + MySQL

Level 2：理解高性能
  └→ Redis 缓存、连接池、SQL 优化

Level 3：理解分布式
  └→ gRPC 微服务、服务发现、负载均衡

Level 4：理解架构
  └→ 微服务拆分、DDD、CQRS、事件驱动

Level 5：全栈贯通
  └→ 从数据库到前端，从单体到微服务
```
