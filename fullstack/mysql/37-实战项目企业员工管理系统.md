# 第37章 实战项目：企业员工管理系统

## 本章目标

1. 完整设计企业员工管理系统的数据库架构
2. 掌握自引用外键（层级部门）、时间维度数据（考勤、薪资历史）的设计模式
3. 练习编写 30+ 个覆盖多种业务场景的 SQL 查询
4. 掌握存储过程的设计和事务应用
5. 掌握触发器的创建和使用场景
6. 综合运用窗口函数、CTE、子查询等高级 SQL 技巧

## 前置知识

- 熟练掌握 CREATE TABLE、INSERT、SELECT、UPDATE、DELETE
- 掌握 JOIN、子查询、聚合函数、窗口函数
- 了解存储过程、触发器的基本语法
- 理解事务 ACID 和隔离级别

## 37.1 业务需求分析

### 37.1.1 功能模块

```
1. 组织架构管理
   - 层级部门（总部 → 分公司 → 部门 → 小组）
   - 部门编制和预算管理

2. 员工管理
   - 员工基本信息（个人资料、联系方式、紧急联系人）
   - 职位体系（P1-P8 级别，薪资范围）
   - 入离职管理

3. 岗位变动管理
   - 晋升、调岗、降级记录
   - 岗位历史轨迹

4. 薪资管理
   - 薪资历史记录（支持补发、调薪）
   - 不允许同一时间段的重叠薪资记录

5. 考勤管理
   - 每日打卡记录
   - 迟到、早退、请假统计
```

### 37.1.2 ER 图（文字描述）

```
departments ──1:N──> departments (self-ref: parent_dept_id)
departments ──1:N──> employees
positions ──1:N──> employees
employees ──1:N──> salaries
employees ──1:N──> job_history
employees ──1:N──> attendance
```

## 37.2 完整表结构设计

### 37.2.1 部门表 (departments)

```sql
CREATE TABLE departments (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '部门ID',
  name VARCHAR(100) NOT NULL COMMENT '部门名称',
  parent_dept_id INT UNSIGNED DEFAULT NULL COMMENT '上级部门ID（NULL=顶级部门）',
  manager_id INT UNSIGNED DEFAULT NULL COMMENT '部门负责人ID',
  budget DECIMAL(14,2) NOT NULL DEFAULT 0.00 COMMENT '年度预算',
  sort_order INT NOT NULL DEFAULT 0 COMMENT '排序',
  status TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '1=正常 0=撤销',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_name (name),
  KEY idx_parent (parent_dept_id),
  CONSTRAINT fk_dept_parent FOREIGN KEY (parent_dept_id)
    REFERENCES departments(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='部门表';
```

### 37.2.2 职位表 (positions)

```sql
CREATE TABLE positions (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '职位ID',
  title VARCHAR(100) NOT NULL COMMENT '职位名称',
  level TINYINT UNSIGNED NOT NULL COMMENT '职级（1-8）',
  base_salary_min DECIMAL(10,2) NOT NULL COMMENT '薪资下限',
  base_salary_max DECIMAL(10,2) NOT NULL COMMENT '薪资上限',
  description VARCHAR(500) DEFAULT '' COMMENT '职位描述',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_title (title)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='职位表';
```

### 37.2.3 员工表 (employees)

```sql
CREATE TABLE employees (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '员工ID',
  emp_no VARCHAR(20) NOT NULL COMMENT '工号（唯一）',
  name VARCHAR(50) NOT NULL COMMENT '姓名',
  gender ENUM('M','F') NOT NULL COMMENT '性别',
  birth_date DATE NOT NULL COMMENT '出生日期',
  hire_date DATE NOT NULL COMMENT '入职日期',
  dept_id INT UNSIGNED NOT NULL COMMENT '所属部门ID',
  position_id INT UNSIGNED NOT NULL COMMENT '职位ID',
  phone VARCHAR(20) NOT NULL DEFAULT '' COMMENT '手机号',
  email VARCHAR(254) NOT NULL COMMENT '邮箱',
  address TEXT COMMENT '住址',
  emergency_contact VARCHAR(50) DEFAULT '' COMMENT '紧急联系人',
  emergency_phone VARCHAR(20) DEFAULT '' COMMENT '紧急联系人电话',
  status TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '1=在职 2=离职 3=停职',
  leave_date DATE DEFAULT NULL COMMENT '离职日期',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_emp_no (emp_no),
  UNIQUE KEY uk_email (email),
  KEY idx_dept_id (dept_id),
  KEY idx_position_id (position_id),
  KEY idx_name (name),
  KEY idx_hire_date (hire_date),
  CONSTRAINT fk_emp_dept FOREIGN KEY (dept_id) REFERENCES departments(id),
  CONSTRAINT fk_emp_position FOREIGN KEY (position_id) REFERENCES positions(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='员工表';
```

### 37.2.4 薪资表 (salaries)

```sql
CREATE TABLE salaries (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '薪资记录ID',
  emp_id INT UNSIGNED NOT NULL COMMENT '员工ID',
  amount DECIMAL(10,2) NOT NULL COMMENT '薪资金额',
  effective_from DATE NOT NULL COMMENT '生效日期',
  effective_to DATE DEFAULT NULL COMMENT '失效日期（NULL=当前生效中）',
  reason VARCHAR(200) DEFAULT '' COMMENT '调薪原因',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_emp_effective (emp_id, effective_from),
  KEY idx_emp_id (emp_id),
  CONSTRAINT fk_salary_emp FOREIGN KEY (emp_id) REFERENCES employees(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='薪资表';

-- 添加约束：同一员工的薪资时间段不能重叠
-- 注意：MySQL 不支持 CHECK 约束中的子查询，需要在应用层或触发器实现
-- 这里是示例性的注释，实际项目在应用层保证
```

### 37.2.5 岗位变动记录表 (job_history)

```sql
CREATE TABLE job_history (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '变动记录ID',
  emp_id INT UNSIGNED NOT NULL COMMENT '员工ID',
  old_dept_id INT UNSIGNED DEFAULT NULL COMMENT '原部门ID',
  new_dept_id INT UNSIGNED DEFAULT NULL COMMENT '新部门ID',
  old_position_id INT UNSIGNED DEFAULT NULL COMMENT '原职位ID',
  new_position_id INT UNSIGNED DEFAULT NULL COMMENT '新职位ID',
  change_type ENUM('promotion','transfer','demotion','probation_pass','resign') NOT NULL COMMENT '变动类型',
  change_date DATE NOT NULL COMMENT '变动日期',
  remark TEXT COMMENT '备注',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_emp_date (emp_id, change_date),
  CONSTRAINT fk_job_emp FOREIGN KEY (emp_id) REFERENCES employees(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='岗位变动记录表';
```

### 37.2.6 考勤表 (attendance)

```sql
CREATE TABLE attendance (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '考勤记录ID',
  emp_id INT UNSIGNED NOT NULL COMMENT '员工ID',
  att_date DATE NOT NULL COMMENT '考勤日期',
  clock_in DATETIME DEFAULT NULL COMMENT '上班打卡时间',
  clock_out DATETIME DEFAULT NULL COMMENT '下班打卡时间',
  status ENUM('normal','late','early','absent','leave') NOT NULL DEFAULT 'normal' COMMENT '考勤状态',
  leave_type ENUM('annual','sick','personal','marriage','bereavement','other') DEFAULT NULL COMMENT '请假类型',
  leave_hours DECIMAL(4,1) DEFAULT 0.0 COMMENT '请假时数',
  remark VARCHAR(200) DEFAULT '' COMMENT '备注',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_emp_date (emp_id, att_date),
  KEY idx_emp_date (emp_id, att_date),
  KEY idx_att_date (att_date),
  CONSTRAINT fk_att_emp FOREIGN KEY (emp_id) REFERENCES employees(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='考勤表';
```

## 37.4 业务 SQL 查询（30+ 示例）

### 37.4.1 基础查询

```sql
-- 查询 1：所有在职员工基本信息（含部门和职位名）
SELECT e.emp_no, e.name, e.gender, e.hire_date,
       d.name AS dept_name, p.title AS position_title
FROM employees e
JOIN departments d ON e.dept_id = d.id
JOIN positions p ON e.position_id = p.id
WHERE e.status = 1
ORDER BY e.hire_date;

-- 查询 2：部门平均薪资排名
SELECT d.name AS dept_name,
       ROUND(AVG(s.amount), 2) AS avg_salary,
       COUNT(DISTINCT e.id) AS headcount
FROM employees e
JOIN departments d ON e.dept_id = d.id
JOIN salaries s ON e.id = s.emp_id AND s.effective_to IS NULL
WHERE e.status = 1
GROUP BY d.id, d.name
ORDER BY avg_salary DESC;

-- 查询 3：部门薪资高于部门平均的员工
WITH dept_avg AS (
  SELECT dept_id, AVG(s2.amount) AS avg_sal
  FROM employees e2
  JOIN salaries s2 ON e2.id = s2.emp_id AND s2.effective_to IS NULL
  WHERE e2.status = 1
  GROUP BY dept_id
)
SELECT e.name, p.title, s.amount, d.name AS dept_name,
       ROUND(da.avg_sal, 2) AS dept_avg_salary
FROM employees e
JOIN salaries s ON e.id = s.emp_id AND s.effective_to IS NULL
JOIN departments d ON e.dept_id = d.id
JOIN positions p ON e.position_id = p.id
JOIN dept_avg da ON e.dept_id = da.dept_id
WHERE s.amount > da.avg_sal AND e.status = 1
ORDER BY s.amount - da.avg_sal DESC;

-- 查询 4：Top 5 最高薪资员工
SELECT e.name, d.name AS dept_name, p.title, s.amount
FROM employees e
JOIN salaries s ON e.id = s.emp_id AND s.effective_to IS NULL
JOIN departments d ON e.dept_id = d.id
JOIN positions p ON e.position_id = p.id
WHERE e.status = 1
ORDER BY s.amount DESC
LIMIT 5;

-- 查询 5：员工入职年限（到今日）
SELECT e.emp_no, e.name, e.hire_date,
       TIMESTAMPDIFF(YEAR, e.hire_date, CURDATE()) AS years_of_service,
       TIMESTAMPDIFF(MONTH, e.hire_date, CURDATE()) % 12 AS extra_months
FROM employees e
WHERE e.status = 1
ORDER BY years_of_service DESC;
```

### 37.4.2 统计与聚合

```sql
-- 查询 6：各部门人数统计
SELECT d.name AS dept_name,
       COUNT(*) AS headcount,
       SUM(CASE WHEN e.gender = 'M' THEN 1 ELSE 0 END) AS male_count,
       SUM(CASE WHEN e.gender = 'F' THEN 1 ELSE 0 END) AS female_count
FROM departments d
LEFT JOIN employees e ON d.id = e.dept_id AND e.status = 1
GROUP BY d.id, d.name
ORDER BY headcount DESC;

-- 查询 7：每个员工的最新薪资
SELECT e.name, s.amount, s.effective_from
FROM employees e
JOIN salaries s ON e.id = s.emp_id
WHERE s.effective_to IS NULL
ORDER BY s.amount DESC;

-- 查询 8：员工薪资增长幅度（入职薪资 vs 当前薪资）
SELECT e.name,
       first_sal.amount AS first_salary,
       curr_sal.amount AS current_salary,
       curr_sal.amount - first_sal.amount AS increase,
       ROUND((curr_sal.amount - first_sal.amount) / first_sal.amount * 100, 2) AS increase_pct
FROM employees e
JOIN salaries first_sal ON e.id = first_sal.emp_id
JOIN salaries curr_sal ON e.id = curr_sal.emp_id AND curr_sal.effective_to IS NULL
WHERE first_sal.effective_from = (
  SELECT MIN(effective_from) FROM salaries WHERE emp_id = e.id
) AND e.status = 1
ORDER BY increase_pct DESC;

-- 查询 9：部门预算利用率
SELECT d.name AS dept_name,
       d.budget AS annual_budget,
       COALESCE(SUM(s.amount) * 12, 0) AS annual_salary_cost,
       ROUND(COALESCE(SUM(s.amount) * 12, 0) / d.budget * 100, 2) AS budget_utilization_pct
FROM departments d
LEFT JOIN employees e ON d.id = e.dept_id AND e.status = 1
LEFT JOIN salaries s ON e.id = s.emp_id AND s.effective_to IS NULL
GROUP BY d.id, d.name, d.budget
ORDER BY budget_utilization_pct DESC;
```

```sql
WITH RECURSIVE dept_tree AS (
  -- 锚点：顶级部门
  SELECT id, name, parent_dept_id, 0 AS depth, CAST(name AS CHAR(500)) AS path
  FROM departments
  WHERE parent_dept_id IS NULL

  UNION ALL

  -- 递归：下级部门
  SELECT d.id, d.name, d.parent_dept_id,
         dt.depth + 1,
         CONCAT(dt.path, ' > ', d.name)
  FROM departments d
  JOIN dept_tree dt ON d.parent_dept_id = dt.id
)

       CONCAT(REPEAT('  ', depth), name) AS dept_name_indented,
       depth,
       path
```

## 37.5 存储过程

### 37.5.1 员工调岗

```sql
DELIMITER //

CREATE PROCEDURE sp_employee_transfer(
  IN p_emp_id INT UNSIGNED,
  IN p_new_dept_id INT UNSIGNED,
  IN p_new_position_id INT UNSIGNED,
  IN p_change_date DATE,
  IN p_remark VARCHAR(500)
)
BEGIN
  DECLARE v_old_dept_id INT UNSIGNED;
  DECLARE v_old_position_id INT UNSIGNED;
  DECLARE v_change_type ENUM('promotion','transfer','demotion','probation_pass','resign');
  DECLARE v_old_level TINYINT;
  DECLARE v_new_level TINYINT;

  -- 错误处理
  DECLARE EXIT HANDLER FOR SQLEXCEPTION
  BEGIN
    ROLLBACK;
    SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '转岗失败，事务已回滚';
  END;

  START TRANSACTION;

  -- 获取当前部门和职位
  SELECT dept_id, position_id INTO v_old_dept_id, v_old_position_id
  FROM employees WHERE id = p_emp_id FOR UPDATE;

  -- 获取职级
  SELECT level INTO v_old_level FROM positions WHERE id = v_old_position_id;
  SELECT level INTO v_new_level FROM positions WHERE id = p_new_position_id;

  -- 判断变动类型
  IF v_old_position_id != p_new_position_id THEN
    IF v_new_level > v_old_level THEN
      SET v_change_type = 'promotion';
    ELSEIF v_new_level < v_old_level THEN
      SET v_change_type = 'demotion';
    ELSE
      SET v_change_type = 'transfer';
    END IF;
  ELSE
    SET v_change_type = 'transfer';
  END IF;

  -- 更新员工信息
  UPDATE employees
  SET dept_id = p_new_dept_id,
      position_id = p_new_position_id
  WHERE id = p_emp_id;

  -- 记录变动
  INSERT INTO job_history (emp_id, old_dept_id, new_dept_id,
                           old_position_id, new_position_id,
                           change_type, change_date, remark)
  VALUES (p_emp_id, v_old_dept_id, p_new_dept_id,
          v_old_position_id, p_new_position_id,
          v_change_type, p_change_date, p_remark);

  COMMIT;
  SELECT CONCAT('员工 ', p_emp_id, ' 转岗成功 (', v_change_type, ')') AS result;
END //

DELIMITER ;
```

```sql
DELIMITER //

CREATE PROCEDURE sp_department_budget_report(
  IN p_dept_id INT UNSIGNED,
  IN p_year INT
)
BEGIN
  DECLARE v_budget DECIMAL(14,2);
  DECLARE v_salary_total DECIMAL(14,2);

  -- 获取预算
  SELECT budget INTO v_budget FROM departments WHERE id = p_dept_id;

  -- 计算全年薪资支出（简化计算：按月统计实际发放）
  SELECT COALESCE(SUM(monthly_salary), 0) INTO v_salary_total
  FROM (
    SELECT e.id,
           s.amount * (
             -- 该薪资记录在 p_year 中的有效月数
             LEAST(
               IFNULL(s.effective_to, CONCAT(p_year, '-12-31')),
               CONCAT(p_year, '-12-31')
             ) - GREATEST(s.effective_from, CONCAT(p_year, '-01-01'))
           ) / 30 AS monthly_salary  -- 简化：天数/30
    FROM employees e
    JOIN salaries s ON e.id = s.emp_id
    JOIN departments d ON e.dept_id = d.id
    WHERE d.id = p_dept_id
      AND s.effective_from <= CONCAT(p_year, '-12-31')
      AND (s.effective_to IS NULL OR s.effective_to >= CONCAT(p_year, '-01-01'))
  ) AS t;

  -- 输出报告
  SELECT
    d.name AS dept_name,
    v_budget AS annual_budget,
    v_salary_total AS salary_expenditure,
    v_budget - v_salary_total AS remaining,
    ROUND(v_salary_total / v_budget * 100, 2) AS utilization_pct
  FROM departments d
  WHERE d.id = p_dept_id;
END //

DELIMITER ;
```

```sql
CREATE PROCEDURE sp_attendance_summary(

  IN p_year INT,
  IN p_month INT

  DECLARE v_end_date DATE;

      SUM(CASE WHEN a.status NOT IN ('absent', 'leave') THEN 1 ELSE 0 END)
      / COUNT(*) * 100, 1
    ) AS attendance_rate
  FROM employees e
  JOIN attendance a ON e.id = a.emp_id
```

## 常见错误

### 错误 1：薪资记录时间段重叠

```
问题：同一员工的 salary 记录 overlapping，导致查询当前薪资时返回多条。

预防：
  - 应用层：插入新薪资前，先关闭已有记录的 effective_to
  - 数据库层：通过触发器检查或使用 CHECK 约束的代理方案
```

### 错误 2：考勤唯一约束未生效

```
问题：attendance 表 uk_emp_date (emp_id, att_date) 确保每人每天一条记录，
     但应用层使用 INSERT 而不是 INSERT ... ON DUPLICATE KEY UPDATE，
     导致重复打卡时直接报错。

解决：使用 INSERT ... ON DUPLICATE KEY UPDATE 处理重复打卡场景
     INSERT INTO attendance (emp_id, att_date, clock_in)
     VALUES (?, ?, ?)
     ON DUPLICATE KEY UPDATE clock_in = VALUES(clock_in);
```

### 错误 3：递归 CTE 无限循环

```
问题：部门层级表中的数据形成了环（A 的 parent 是 B，B 的 parent 是 A），
     递归 CTE 无限循环。

解决：
  WITH RECURSIVE cte AS (
    ...
    UNION ALL
    SELECT ... WHERE depth < 50  -- 限制最大深度
  )
  
  更重要的是：通过应用逻辑或触发器防止数据形成环
```

### 错误 4：触发器中的 SIGNAL 未被正确使用

```
问题：在 BEFORE INSERT 触发器中使用 SIGNAL 抛出错误，
     但忘记指定正确的 SQLSTATE 值（必须为 45xxx 系列）。

正确做法：
  SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '错误信息';
  必须以 45 开头，表示用户自定义异常。
```
