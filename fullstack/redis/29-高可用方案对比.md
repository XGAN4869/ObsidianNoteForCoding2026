# 第29章：高可用方案对比

## 29.1 三种方案对比

| 特性 | 主从 | Sentinel | Cluster |
|------|------|---------|---------|
| 读扩展 | ✅ | ✅ | ✅ |
| 写扩展 | ❌ | ❌ | ✅ |
| 自动故障转移 | ❌ | ✅ | ✅ |
| 数据分片 | ❌ | ❌ | ✅ |
| 复杂度 | 低 | 中 | 高 |
| 最小节点数 | 2 | 3 | 6（3主3从） |
| 适合数据量 | < 16GB | < 16GB | > 16GB |

---

## 29.2 选型指南

```
数据量 < 单机内存（如 16GB）？
├── 是 → 需要自动故障转移？
│   ├── 是 → Sentinel（推荐）
│   └── 否 → 主从
└── 否 → Cluster（数据分片）

并发写瓶颈？
├── 是 → Cluster（多 Master 分担写压力）
└── 否 → Sentinel 够用
```

---

## 29.3 各方案架构图

```
主从架构：            Sentinel：              Cluster：
Master                Sentinel×3              M1  M2  M3
  ├─Slave1            Master                    ├S1 ├S2 ├S3
  └─Slave2              ├─Slave1               
                         └─Slave2             
```

---

## 本章小结
- 数据量 < 16GB + 需要自动切换 → Sentinel
- 数据量 > 16GB → Cluster
- 简单场景 → 主从（手动切换）
